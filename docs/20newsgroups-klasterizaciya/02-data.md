# 2. Данные и утечки

Корпус выглядит безобидно, пока не начнёшь проверять. В этом уроке — аудит
данных и утечек, которые легко пропустить.

!!! abstract "Артефакт урока"
    Data audit: размер, классы, дубли, утечки, ограничения, этические риски.

## Как думает senior

Он проверяет корпус как контракт: что удалено, что осталось, какие риски
переносятся в результат. Особенно если результат увидят пользователи.

## Твоя очередь

## Шаг 1 · Загрузи и посмотри

```python
from sklearn.datasets import fetch_20newsgroups

data = fetch_20newsgroups(
    subset="all",
    remove=("headers", "footers", "quotes"),
    random_state=42,
)
print(len(data.data), len(data.target_names))
print(data.target_names)
```

!!! question "Сделай"
    Сколько документов? Классы сбалансированы?

??? success "Проверить"
    Около `18 846` документов, `20` классов. Классы примерно сбалансированы, но
    самый большой больше самого маленького в `2–3` раза.

## Шаг 2 · Проверь дубли

```python
import hashlib

hashes = [hashlib.md5(t.encode()).hexdigest() for t in data.data]
print("уникальных:", len(set(hashes)), "из", len(hashes))
```

!!! question "Сделай"
    Есть ли точные дубли? Почему это важно для кластеризации?

??? success "Проверить"
    Точных дублей обычно немного, но они есть. Дубли искажают центроиды:
    один документ может «перевесить» кластер.

## Шаг 3 · Проверь утечки

Главные утечки в этом датасете:

- **headers/footers/quotes** — содержат название группы и цитаты;
- **метаданные** в тексте (подписи, email);
- **`target`** — нельзя использовать при обучении.

```python
print(data.data[0][:500])
```

!!! question "Сделай"
    Что осталось в тексте после `remove=("headers", "footers", "quotes")`?
    Есть ли что-то, что выдаёт класс?

??? success "Проверить"
    Обычно остаётся тело сообщения. Но иногда в тексте есть упоминания группы
    или характерные подписи. Их стоит искать глазами, а не только по
    параметрам загрузки.

## Шаг 4 · Посмотри на длину и язык

```python
import numpy as np

lengths = np.array([len(t.split()) for t in data.data])
print(lengths.min(), np.median(lengths), lengths.max())
print("коротких (<20 слов):", (lengths < 20).sum())
```

!!! question "Сделай"
    Есть ли очень короткие документы? Как они повлияют на TF-IDF?

??? success "Проверить"
    Есть. Короткие документы дают шумные векторы: мало слов — много нулей.
    Возможно, их стоит отфильтровать и объяснить это решение.

## Шаг 5 · Оцени этические риски

Датасет содержит тексты 1990-х, включая спорные и оскорбительные материалы.
Для кластеризации это важно:

- кластеры могут отражать не темы, а токсичность;
- выводы нельзя переносить на современные данные;
- в отчёте нужно указать ограничения.

!!! warning "Ловушка"
    Игнорировать содержимое и считать, что «это просто данные». Senior
    фиксирует ограничения и риски, особенно если результат пойдёт пользователям.

## Шаг 6 · Data audit

```md
# Data audit: 20 newsgroups

## Размер
18 846 документов, 20 классов.

## Очистка
remove=("headers", "footers", "quotes").

## Проблемы
- дубли: N;
- короткие документы: N;
- дисбаланс классов: max/min ≈ 2–3;
- спорный контент: есть.

## Решение
- дубли не удаляем / удаляем (объяснить);
- короткие документы: оставить / отфильтровать (объяснить);
- target не используем при обучении.

## Ограничения
Данные 1990-х, английский, темы пересекаются, возможна токсичность.
```

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| headers/footers/quotes | метаданные, удаляются |
| дубли | одинаковые документы |
| длина | число слов |
| этический риск | спорный контент |

## Критерии приёмки

- [ ] описаны ограничения и риски;
