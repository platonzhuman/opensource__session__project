# 1. Бриф и протокол

Кластеризация без критерия — это генератор красивых картинок. Senior сначала
отвечает: **какое решение примет заказчик по результату**.

!!! abstract "Артефакт урока"
    ADR и протокол: метрики, baseline, seeds, stop rule.

## Как думает senior

Он не начинает с «какой алгоритм взять». Он спрашивает: какое решение примет
заказчик, что будет считаться доказательством и когда результат нельзя
использовать.

## Твоя очередь

## Шаг 1 · Сформулируй решение

Плохо: «кластеризовать 20 newsgroups».

Хорошо: «Понять, можно ли без разметки выделить темы достаточно устойчиво, чтобы
использовать кластеры для навигации по корпусу». Здесь есть решение
(навигация), условие (без разметки), критерий (устойчивость).

```text
Решение: показывать пользователю группы похожих документов.
Вопрос: устойчивы ли кластеры между запусками и параметрами?
Успех: ARI/NMI заметно выше случайного, кластеры стабильны по seeds,
        размеры кластеров не вырождены.
Провал: результат сильно зависит от seed или k; кластеры неинтерпретируемы.
Вне рамок: онлайн-обновление, многоязычность, иерархия тем.
```

!!! question "Сделай"
    Почему «устойчивость» важнее «максимального ARI»?

??? success "Проверить"
    Максимальный ARI можно случайно получить на одном seed. Если при смене seed
    всё рассыпается, использовать кластеры нельзя.

## Шаг 2 · Выбери метрики

| Метрика | Использует метки | Что показывает |
| --- | --- | --- |
| Silhouette | нет | внутренняя разделимость |
| Davies–Bouldin | нет | компактность/разделимость |
| ARI | да | согласие с разметкой |
| NMI | да | информация о классах |
| Homogeneity | да | чистота кластеров |
| Completeness | да | полнота классов |

Основные: **Silhouette** (выбор `k` без меток) и **ARI/NMI** (проверка после).
Важно: Silhouette и ARI отвечают на разные вопросы и могут расходиться.

!!! warning "Ловушка"
    Выбирать `k` по ARI. Это использование `target` при обучении. `k`
    выбирается по внутренним метрикам и стабильности, ARI — только отчёт.

## Шаг 3 · Определи baseline

Baseline для кластеризации:

1. **Случайное разбиение** на `k` групп — показывает уровень шума.
2. **KMeans на сыром TF-IDF без LSA** — проверка, нужна ли LSA.
3. **KMeans на LSA** — основная модель.

Сначала загрузи данные — они понадобятся и дальше.

```python
from sklearn.datasets import fetch_20newsgroups
from sklearn.metrics import adjusted_rand_score
import numpy as np

data = fetch_20newsgroups(
    subset="all",
    remove=("headers", "footers", "quotes"),
    random_state=42,
)

rng = np.random.default_rng(0)
random_labels = rng.integers(0, 20, size=len(data.target))
print("ARI random:", adjusted_rand_score(data.target, random_labels))
```

!!! question "Сделай"
    Чему равен ARI случайного разбиения? Почему это полезно знать?

??? success "Проверить"
    Около `0`. Это точка отсчёта: любое значение выше нуля — уже сигнал, но
    надо смотреть, насколько выше и стабильно ли.

## Шаг 4 · Зафиксируй протокол

```text
Данные: 20 newsgroups, remove=("headers", "footers", "quotes").
Признаки: TF-IDF, min_df=5, max_df=0.5, stop_words="english".
Снижение: TruncatedSVD(100) + Normalizer.
Кластеризация: KMeans, k = 10…30.
Seeds: 0…4 для каждого k.
Метрики: silhouette (выбор k), ARI/NMI/homogeneity/completeness (отчёт).
Stop rule: если разброс ARI по seeds больше разницы между k — выбор k не
           обоснован, фиксируем нестабильность.
```

!!! question "Сделай"
    Почему `seeds` обязательны для KMeans?

??? success "Проверить"
    KMeans зависит от инициализации. Один запуск может дать хороший ARI
    случайно. Нужны несколько запусков и разброс.

## Шаг 5 · ADR

```md
# ADR-001: подход к кластеризации

## Контекст
Корпус без разметки; нужно понять, годятся ли кластеры для навигации.

## Варианты
1. TF-IDF + KMeans без LSA.
2. TF-IDF + LSA + KMeans.
3. Эмбеддинги + HDBSCAN.

## Решение
Начать с (2): быстро, интерпретируемо, есть baseline (1).

## Последствия
LSA теряет часть информации; KMeans предполагает сферические кластеры.
Если результат нестабилен — перейти к (3).

## Условия пересмотра
Разброс ARI по seeds > 0.1 или кластеры неинтерпретируемы.
```

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| решение | зачем кластеризация |
| внутренняя метрика | без меток |
| внешняя метрика | с метками, только отчёт |
| baseline | случайное разбиение / без LSA |
| stability | разброс по seeds |
