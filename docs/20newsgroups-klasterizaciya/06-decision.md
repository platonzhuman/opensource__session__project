# 6. Решение

Финальный шаг: провести ревью и написать memo. Кластеризация либо годится для
конкретного решения, либо нет — и это надо сказать явно.

!!! abstract "Артефакт урока"
    Memo с рекомендацией, ревью по рубрике и условия пересмотра.

## Как думает senior

Он говорит «годится для навигации, не годится для модерации», а не «работает».
Решение всегда с условиями и ограничениями.

## Твоя очередь

## Шаг 1 · Проверь воспроизводимость

- [ ] ноутбук запускается сверху вниз;
- [ ] seeds зафиксированы;
- [ ] версии `sklearn` указаны;
- [ ] данные скачиваются по коду;
- [ ] все графики строятся из одного прогона;
- [ ] результаты повторяются.

!!! warning "Ловушка"
    «У меня ARI 0.4» без seed и версии. Через месяц результат не воспроизведётся.

## Шаг 2 · Пройди рубрику

[Рубрика](../standards/review-rubric.md). Типичные замечания:

- `[blocker]` `target` использован при выборе `k`;
- `[major]` нет baseline;
- `[major]` нет stability;
- `[major]` нет error analysis;
- `[minor]` нет размеров кластеров;
- `[nit]` графики без подписей.

## Шаг 3 · Напиши memo

```md
# Решение: iterate

## Вопрос
Можно ли использовать кластеры для навигации по корпусу без разметки?

## Доказательства
- baseline (no LSA): ARI 0.18
- LSA + KMeans, k=20: ARI 0.31 ± 0.04
- stability между seeds: 0.72
- homogeneity 0.42, completeness 0.38
- max cluster share: 0.14

## Интерпретация
Кластеры устойчивее случайных, но нестабильны между seeds и смешивают
политические/религиозные темы. Для навигации — ограниченно годится;
для автоматической модерации — нет.

## Ограничения
- английский, 1990-е;
- TF-IDF не понимает смысл;
- KMeans предполагает сферические кластеры;
- спорный контент.

## Решение
Iterate: попробовать эмбеддинги и HDBSCAN, сравнить stability.

## Когда пересмотреть
Если появятся современные данные или требования к многоязычности.
```

!!! question "Сделай"
    Почему «ограниченно годится» — нормальный вывод?

??? success "Проверить"
    Потому что решение имеет условия. Senior не делит мир на «работает» и «не
    работает»; он говорит, при каких условиях и с какими рисками.

## Шаг 4 · Подготовь защиту

1. Почему этот подход, а не эмбеддинги?
2. Откуда знаешь, что кластеры осмысленны?
3. Что сломается первым?

!!! question "Сделай"
    Ответь на три вопроса, используя числа и ограничения.

??? success "Проверить"
    Хороший ответ: «TF-IDF + LSA даёт ARI 0.31 против 0.18 у baseline, но
    stability 0.72 и смешение политики с религией. Для навигации — да, для
    модерации — нет».

## Шаг 5 · Что приложить

- ADR;
- протокол;
- журнал;
- ноутбук;
- stability report;
- error report;
- memo;
- ревью.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| memo | решение с условиями |
| stability | воспроизводимость |
| ограничения | где вывод не работает |
| условия пересмотра | когда вернуться |

## Критерии приёмки

- [ ] ноутбук воспроизводится;
- [ ] memo содержит числа;
- [ ] решение явное;
- [ ] ограничения описаны;
- [ ] ревью пройдено;
- [ ] защита готова.
