## Что будет в заходе

1. **Картинка как числа.** 20×20×3 — это 1200 чисел, нормализация и flatten.
2. **Train/test.** 40 картинок, проверка на тех, которые модель не видела.
3. **Четыре модели.** Дерево, SVM, PCA+дерево и ансамбль.
4. **Accuracy.** Одно число и отчёт по классам.
5. **Атака.** Один пиксель меняет ответ модели.

## Что сдаёшь

- ноутбук, который запускается сверху вниз;
- 20 кошек и 20 собак, `X` и `y`;
- четыре обученные модели с accuracy;
- результат атаки одним пикселем;
- короткий вывод на 5 предложений.

Готовые ответы не сдаются. Если преподаватель просит отчёт по классам, добавь
`classification_report` после accuracy.

## Что понадобится

- Python 3, `numpy`, `scikit-learn`;
- `matplotlib`, если хочешь приложить картинки;
- базовые списки, циклы и функции;
- 45 минут без переключения на другие задачи.
