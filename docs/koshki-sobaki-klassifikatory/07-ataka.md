# 7. Атака одним пикселем

Цель: взять картинку, которую дерево угадывает, и поменять **один** пиксель так, чтобы
дерево ошиблось.

## Шаг 1 · Идея

Пробуем по очереди все `400` пикселей: меняем пиксель на чёрный (`0`) или белый (`255`)
и смотрим, изменился ли ответ. Как только ответ перевернулся — атака удалась.

## Шаг 2 · Код с объяснением каждой строки

```pyplay
import numpy as np
from sklearn.tree import DecisionTreeClassifier

np.random.seed(0)
X, y = [], []
for i in range(20):
    cat = np.random.randint(0, 60, (20, 20)); cat[:3] = 255
    X.append(cat); y.append(0)
    dog = np.random.randint(0, 60, (20, 20)); dog[:, :3] = 255
    X.append(dog); y.append(1)
X = np.array(X).reshape(40, 400); y = np.array(y)

tree = DecisionTreeClassifier(random_state=0).fit(X, y)   # обучи дерево
pred = tree.predict(X)                                   # его ответы

found = None
for i in range(40):                    # пройди по всем 40 картинкам
    if pred[i] != y[i]:
        continue                       # если тут ошибка уже есть — пропусти
    base = X[i].copy()                 # копия картинки (оригинал не трогаем)
    target = 1 - y[i]                  # нужный противоположный ответ
    for p in range(400):               # по каждому пикселю
        for v in (0, 255):             # попробуй 0 и 255
            if base[p] == v:
                continue               # там уже такое значение — менять нечего
            f = base.copy()            # копия
            f[p] = v                   # поменяй РОВНО один пиксель
            if tree.predict(f[None, :])[0] == target:
                found = (i, p, v)      # запомни: картинка, пиксель, значение
                break
        if found:
            break
    if found:
        break

print("сломал:", found)
print("строка, столбец:", found[1] // 20, found[1] % 20)
```

| Строка | По-русски |
| --- | --- |
| `tree.predict(X)` | ответы дерева на все 40 картинок |
| `if pred[i] != y[i]: continue` | пропусти картинки, где модель и так ошибается |
| `base = X[i].copy()` | копия картинки (копия — чтобы не испортить `X`) |
| `target = 1 - y[i]` | противоположный ответ: `0→1`, `1→0` |
| `for p in range(400):` | перебери все пиксели |
| `for v in (0, 255):` | попробуй чёрный и белый |
| `f = base.copy(); f[p] = v` | поменяй один пиксель на копии |
| `f[None, :]` | преврати строку `400` в таблицу `1 × 400` (так ждёт `predict`) |
| `found = (i, p, v)` | атака удалась — запоминаем и выходим |

??? success "Проверить"

## Шаг 3 · Почему это работает

Дерево различает кошку и собаку по полосе. Мы подделали ровно один пиксель этой полосы
— и признак перевесил в другую сторону.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `.copy()` | копия картинки |
| `f[p] = v` | поменять пиксель `p` на значение `v` |
| `1 - y[i]` | противоположный класс |
| `p // 20, p % 20` | номер пикселя → строка и столбец |
| `f[None, :]` | `predict` ждёт таблицу, а не строку |

## Наивные вопросы

!!! question "Почему перебираем только `0` и `255`?"
    Для простой задачи хватает крайних значений (чёрный/белый). Если не помогло —
    можно перебрать и промежуточные.

!!! question "Атака портит саму модель?"
    Нет. Модель та же, испорчена только одна картинка.

!!! question "Почему `found[1] // 20`?"
    Номер пикселя `0…399` переводим в строку картинки: `// 20` — строка, `% 20` —
    столбец.
