# 2. Рисуем 20 кошек и 20 собак

Цель: сделать таблицу `X` (картинки) и `y` (ответы).

## Шаг 1 · Чем кошка отличается от собаки

Придумаем простой признак, который модель сможет заметить:

- **кошка** — яркая полоса **сверху**;
- **собака** — яркая полоса **сбоку**.

Фон тёмный, полоса белая (`255`). Больше ничего различать не нужно.

## Шаг 2 · Сделай картинку-кошку

Сначала одна картинка. Запусти и посмотри.

```pyplay
import numpy as np
np.random.seed(0)

cat = np.random.randint(0, 60, (20, 20))   # тёмная картинка со слабым шумом
cat[:3] = 255                              # верхние 3 строки белые
print(cat.shape)
print(cat[0])                              # верхняя строка — белая
print(cat[10])                             # середина — тёмная
```

| Строка | По-русски |
| --- | --- |
| `np.random.seed(0)` | зафиксируй случайность, чтобы результат повторялся |
| `np.random.randint(0, 60, (20, 20))` | таблица `20 × 20` из случайных чисел `0…59` |
| `cat[:3] = 255` | строки `0, 1, 2` сделай белыми |
| `cat[0]` | первая строка |

!!! question "Сделай"
    У кошки сколько белых строк и где?

??? success "Проверить"
    Три строки (`0, 1, 2`) — **сверху**.

## Шаг 3 · Сделай картинку-собаку

У собаки полоса не сверху, а сбоку. `cat[:, :3]` — это «все строки, первые три
столбца».

```pyplay
import numpy as np
np.random.seed(0)
dog = np.random.randint(0, 60, (20, 20))
dog[:, :3] = 255      # первые 3 СТОЛБЦА белые
print(dog[0])         # теперь в каждой строке первые 3 числа белые
```

| Запись | По-русски |
| --- | --- |
| `cat[:3]` | строки с `0` по `2` |
| `dog[:, :3]` | все строки, столбцы `0, 1, 2` |

!!! question "Сделай"
    Чем `cat[:3]` отличается от `dog[:, :3]`?

??? success "Проверить"
    `cat[:3]` — белые **строки** (полоса сверху). `dog[:, :3]` — белые **столбцы**
    (полоса сбоку).

## Шаг 4 · Собери 20 и 20 в таблицу

Теперь в цикле делаем так `20` раз и складываем всё в `X` и `y`.

```pyplay
import numpy as np
np.random.seed(0)

X, y = [], []                      # пустые списки
for i in range(20):                # повтори 20 раз
    cat = np.random.randint(0, 60, (20, 20))
    cat[:3] = 255
    X.append(cat); y.append(0)     # кошка: картинка + ответ 0
    dog = np.random.randint(0, 60, (20, 20))
    dog[:, :3] = 255
    X.append(dog); y.append(1)     # собака: картинка + ответ 1

X = np.array(X).reshape(40, 400)   # 40 картинок → строки по 400 чисел
y = np.array(y)
print(X.shape, y.shape)
print("кошек:", (y == 0).sum(), "собак:", (y == 1).sum())
```

| Строка | По-русски |
| --- | --- |
| `X, y = [], []` | два пустых списка |
| `for i in range(20):` | повтори тело цикла 20 раз |
| `X.append(cat)` | добавь картинку в список `X` |
| `y.append(0)` | добавь ответ `0` (кошка) в `y` |
| `np.array(X).reshape(40, 400)` | из списка картинок сделай таблицу `40 × 400` |
| `np.array(y)` | ответы в массив |

!!! tip "Правило"
    Порядок важен: `X` и `y` должны лежать в одном порядке. Сначала `X.append`,
    сразу за ним `y.append`.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `X` | таблица картинок `40 × 400` |
| `y` | ответы: `0` кошка, `1` собака |
| `X.append(...)` | добавить картинку |
| `y.append(...)` | добавить ответ |
| `.reshape(40, 400)` | развернуть каждую картинку в `400` чисел |

## Наивные вопросы

!!! question "Зачем `np.random.seed(0)`?"
    Чтобы при каждом запуске случайные картинки были одни и те же — результат
    повторяется.

!!! question "Почему фон тёмный, а полоса белая?"
    Чтобы «белое» было однозначным: полоса — явный признак, не спутаешь с фоном.

!!! question "Почему ответы `0` и `1`, а не «кошка»/«собака»?"
    Модели нужны числа. `0` и `1` — самые простые.
