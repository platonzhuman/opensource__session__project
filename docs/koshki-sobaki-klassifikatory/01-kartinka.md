# 1. Картинка — это числа

Цель: понять, что увидит модель. Никаких моделей тут нет.

## Шаг 1 · Пиксель — это число

Картинка `20 × 20` — сетка клеток. Клетка называется **пиксель** и хранит число:
`0` — чёрный, `255` — белый.

!!! question "Сделай"
    Сколько пикселей в сетке `20 × 20`?

??? success "Проверить"
    `20 × 20 = 400`.

## Шаг 2 · Картинка — это таблица

В `numpy` картинка — таблица `(20, 20)`. Сделаем чёрную картинку и белую полосу сверху.

Запусти и прочитай, что делает каждая строка:

```pyplay
import numpy as np

img = np.zeros((20, 20))   # чёрная картинка 20×20 (все нули)
img[:3] = 255              # верхние 3 строки закрась белым
print(img.shape)           # размер картинки
print(img[0])              # первая строка (все 255)
```

| Строка | По-русски |
| --- | --- |
| `import numpy as np` | подключи библиотеку чисел, называй `np` |
| `np.zeros((20, 20))` | создай таблицу `20 × 20` из нулей |
| `img[:3] = 255` | строки с `0` по `2` сделай равными `255` |
| `img.shape` | размер таблицы |
| `img[0]` | первая строка |

!!! question "Сделай"
    Что напечатает `img[0]`? А `img[5]`?

??? success "Проверить"
    `img[0]` — двадцать чисел `255` (полоса). `img[5]` — двадцать нулей (чёрное).

## Шаг 3 · Для модели — строка из 400 чисел

Модель не понимает квадрат. `reshape` разворачивает `20 × 20` в строку из `400` чисел.

```pyplay
import numpy as np
img = np.zeros((20, 20))
img[:3] = 255
vec = img.reshape(400)     # разверни в строку из 400 чисел
print(vec.shape)
print(vec[:5])             # первые 5 чисел
```

!!! tip "Правило"
    Одна картинка для модели — **строка из `400` чисел**. Одно число называется
    **признак**.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `np.zeros((20, 20))` | чёрная картинка `20 × 20` |
| `img[:3] = 255` | закрасить первые `3` строки |
| `.reshape(400)` | развернуть в строку из `400` чисел |
| `.shape` | размер: `(строки, столбцы)` |
