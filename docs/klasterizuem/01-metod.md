## Песочница: допиши пропуски

```pyplay
# @mode fix
# @expect 3 2
# @hint rows = len(X), cols = len(X[0])
# заполни пропуски так, чтобы вышло 3 2
X = [[1, 2], [3, 4], [5, 6]]
rows = len(___)
cols = len(X[___])
print(rows, cols)   # ожидаем 3 2
```

??? success "Проверить"
    `rows = len(X)` → `3`. `cols = len(X[0])` → `2`. Печатает `3 2`.
    `len(...)` возвращает количество; `X[0]` — первая строка.

## Главное

- Не пиши всё сразу. **2–3 строки → запустил → проверил.**
- Не знаешь команду — это не «не умею», это «не нашёл». Ищи в [словаре](cheatsheet.md).
- Каждый кусок в конце оборачиваешь в `def ...: return`.
