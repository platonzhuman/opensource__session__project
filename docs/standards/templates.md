# Шаблоны артефактов

Четыре документа, которые senior пишет до, во время и после работы. Не для
красоты: они заставляют думать до кода и оставляют след, по которому решение
можно проверить.

## 1. ADR — Architecture Decision Record

```md
# ADR-001: <решение>

## Статус
proposed | accepted | superseded by ADR-XXX

## Контекст
Какая задача, какие ограничения, что известно, что неизвестно.

## Рассмотренные варианты
1. Вариант A — плюсы, минусы, стоимость.
2. Вариант B — плюсы, минусы, стоимость.
3. Вариант C — плюсы, минусы, стоимость.

## Решение
Что выбрано и почему. Одно-два предложения.

## Последствия
Что станет проще, что сложнее, что придётся поддерживать.

## Условия пересмотра
При каких данных или событиях решение надо пересмотреть.
```

## 2. Журнал экспериментов

Одна строка = один запуск. Без журнала невозможно отличить улучшение от шума.

| id | дата | гипотеза | изменение | split | метрика | значение | стоимость | вывод |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| e01 | | baseline | — | val | RMSE | | | точка отсчёта |
| e02 | | больше лагов | p=6 | val | RMSE | | | лучше/хуже/шум |

Правила:

- меняем **одно** за раз;
- фиксируем seed и версии;
- записываем не только удачные запуски;
- вывод формулируем до следующего эксперимента.

## 3. Отчёт об ошибках (error analysis)

```md
# Error analysis: <модель>

## Что измеряли
Метрика, split, размер выборки.

## Где ошибаемся
| срез | n | метрика | комментарий |
| --- | --- | --- | --- |

## Типы ошибок
1. ...
2. ...

## Гипотезы причин
- ...

## Что проверить дальше
- ...
```

## 4. Decision memo

```md
# Решение: <ship / iterate / stop>

## Вопрос
Какое решение принимается.

## Доказательства
- baseline: ...
- модель: ...
- разница: ... (значима / в пределах шума)
- стоимость: ...

## Ограничения
- ...

## Риски и мониторинг
- что сломается первым;
- как это заметить;
- когда переобучать.

## Решение и следующий шаг
```

## 5. Ревью-комментарий

```md
[severity] Краткое название
Где: файл, шаг
Почему: ...
Как проверить: ...
```

Severity: `blocker`, `major`, `minor`, `nit`. Подробнее —
[рубрика](review-rubric.md).
