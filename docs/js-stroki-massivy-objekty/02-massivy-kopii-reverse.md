# 2. Копии массива и разворот двумя способами

Цель урока: скопировать массив двумя способами и развернуть порядок тоже двумя
способами. Это задание 2.2.

## Массив — это список по порядку

Массив хранит значения по номерам, счёт с нуля:

| Индекс | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| `[9, 8, 7, 6]` | `9` | `8` | `7` | `6` |

| Код | Результат |
| --- | --- |
| `arr[0]` | первый элемент |
| `arr.length` | сколько элементов |
| `arr[arr.length - 1]` | последний элемент |

## Главная ловушка: имя ≠ копия

Массив — это «коробка». Переменная хранит **адрес коробки**, а не её содержимое.
Запись `let b = a` кладёт в `b` тот же адрес. Теперь `a` и `b` — два имени одной
коробки. Изменишь через `b` — изменится и `a`.

**Следствие:** `.reverse()` переворачивает массив **на месте**. Если вызвать его на
оригинале, оригинал испортится. Поэтому сначала делаем копию, потом разворачиваем
копию.

| Способ копии | Код | Почему работает |
| --- | --- | --- |
| spread | `[...arr]` | раскрывает элементы в новый массив |
| slice | `arr.slice()` | без аргументов возвращает новый массив целиком |

| Способ разворота | Код | Особенность |
| --- | --- | --- |
| встроенный | `arr.reverse()` | меняет массив на месте |
| вручную | цикл с конца + `push` | создаём новый массив заново |

## Что здесь что

| Выражение | Фраза | Результат |
| --- | --- | --- |
| `[...arr]` | разложи элементы в новый массив | копия |
| `arr.slice()` | отрежь с начала до конца | копия |
| `arr.reverse()` | переверни на месте | тот же массив перевёрнут |
| `arr.push(x)` | положи `x` в конец | новая длина массива |

## Механизм ручного разворота

Идём по массиву **с конца к началу** и складываем встреченные элементы в новый
массив. Первым попадёт последний элемент — он и встанет первым.

`[9, 8, 7]`, `i` от `2` до `0`:

| Шаг | `arr[i]` | `res` после `push` |
| --- | --- | --- |
| `i=2` | `7` | `[7]` |
| `i=1` | `8` | `[7, 8]` |
| `i=0` | `9` | `[7, 8, 9]` |

## Песочница: две копии, два разворота

```jsplay
let arr = [3, 1, 4, 1, 5];

let c1 = [...arr];          // копия способ 1
c1.___();                   // разворот способ 1

let c2 = arr.___();         // копия способ 2
let rev = [];               // разворот способ 2 — вручную
for (let i = c2.length - 1; i >= 0; i--) rev.___(c2[i]);
c2 = rev;

console.log(arr.join(' '));
console.log(c1.join(' '));
console.log(c2.join(' '));
```

??? success "Проверить"
    `c1.reverse()` переворачивает первую копию. `arr.slice()` — вторая копия,
    `rev.push(c2[i])` собирает разворот с конца. Вывод:
    `3 1 4 1 5`, потом `5 1 4 1 3`, потом снова `5 1 4 1 3`. Оригинал `arr`
    остался нетронутым, потому что разворот шёл на копиях.

## Наивные вопросы

- **Почему первый вывод не перевёрнут?** Потому что мы разворачивали `c1` и `c2`,
  а `arr` не трогали. В этом и смысл копий.
- **`[...arr]` и `arr.slice()` — есть разница?** Оба дают полную копию. `slice`
  ещё умеет отрезать кусок (`arr.slice(1, 3)`), а `...` просто раскрывает всё.
- **Можно ли развернуть одним `arr.reverse()` без копии?** Для вывода — да, но
  тогда `arr` уже не оригинал. Домашка просит **две копии**, значит копируем.
- **Почему в ручном цикле `i--`, а не `i++`?** Идём с последнего индекса вниз, к
  нулю. `arr.length - 1` — это последний индекс.
