# 4. Дни недели: объект, `this` и текущий день

Цель урока: завести объект «дни недели» с ключами-номерами и метод, который
возвращает сегодняшний день. Это задание 2.4.

## Объект умеет хранить не только данные

Мы уже видели объект-словарь: `{ ключ: значение }`. Значением может быть и
**функция**. Функция внутри объекта называется **метод**.

```js
let days = {
  1: 'Понедельник',
  2: 'Вторник',
  3: 'Среда',
  4: 'Четверг',
  5: 'Пятница',
  6: 'Суббота',
  7: 'Воскресенье'
};
```

Ключи — числа, но пишутся без кавычек: `1:`, `2:`. Обращение — через скобку:
`days[1]` → `'Понедельник'`. По заданию понедельник — первый, значит `days[1]`
даёт понедельник, `days[7]` — воскресенье.

## `this` — «этот самый объект»

Метод — обычная функция, но когда её вызывают как `days.today()`, внутри доступно
слово **`this`**, и оно указывает на сам объект `days`. Значит `this[n]` — взять
свойство с ключом `n` у этого объекта.

| Код | Что это |
| --- | --- |
| `days.today()` | вызов метода |
| `this` внутри метода | сам объект `days` |
| `this[n]` | свойство с номером `n` |

## Текущий день: `new Date()`

`new Date()` создаёт объект с текущими датой и временем. Метод `.getDay()` отдаёт
**номер дня недели** — но с хитрой нумерацией:

| День | `getDay()` |
| --- | --- |
| воскресенье | `0` |
| понедельник | `1` |
| … | … |
| суббота | `6` |

А нам нужен понедельник = `1`, воскресенье = `7`. Переведём формулой:

```
n = (getDay() + 6) % 7 + 1
```

Проверим по числам:

| День | `getDay()` | `(d+6)%7+1` | `days[n]` |
| --- | --- | --- | --- |
| понедельник | 1 | `(7)%7+1 = 1` | Понедельник |
| пятница | 5 | `(11)%7+1 = 5` | Пятница |
| воскресенье | 0 | `(6)%7+1 = 7` | Воскресенье |
| суббота | 6 | `(12)%7+1 = 6` | Суббота |

## Что здесь что

| Код | Фраза | Результат |
| --- | --- | --- |
| `new Date()` | возьми текущую дату | объект даты |
| `.getDay()` | номер дня с воскресенья=0 | `0…6` |
| `(d + 6) % 7 + 1` | переведи к понедельнику=1 | `1…7` |
| `this[n]` | свойство объекта по ключу `n` | название дня |
| `method() { ... }` | короткая запись метода | функция внутри объекта |

## Песочница: объект и метод «сегодня»

```jsplay
let days = {
  1: 'Понедельник', 2: 'Вторник', 3: 'Среда', 4: 'Четверг',
  5: 'Пятница', 6: 'Суббота', 7: 'Воскресенье',
  today: function () {
    let d = new Date().___();      // (1) номер дня с воскресенья
    let n = (d + 6) % 7 + ___;     // (2) понедельник = 1
    return ___[n];                 // (3) свойство этого объекта
  }
};

console.log('Сегодня:', days.today());
console.log('Проверка формулы:', (0 + 6) % 7 + 1, (1 + 6) % 7 + 1);
```

??? success "Проверить"
    `new Date().getDay()` даёт `0…6`. Формула `(d + 6) % 7 + 1` переводит к
    `1…7`, `this[n]` возвращает название. Вторая строка печатает `7 1` — это
    проверка формулы на воскресенье (0 → 7) и понедельник (1 → 1).

## Наивные вопросы

- **Почему ключи без кавычек?** Числовые ключи в литерале объекта можно писать
  как числа. Доступ всё равно через скобку: `days[1]`.
- **Зачем `% 7`?** Остаток по модулю 7 заворачивает диапазон. `(6+6)` даёт 12, а
  после `% 7` — снова 5.
- **Почему `+ 1` в конце, а не в начале?** Сдвигаем вправо: понедельник должен
  стать 1, а не 0. Сложение в конце задаёт нужный старт.
- **Обязательно `this`?** Внутри метода да, иначе имя `days` жёстко вшито. С `this`
  метод работает у любого объекта с такими же ключами.
