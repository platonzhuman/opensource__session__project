## Что будет в заходе

1. **Строки.** `kebab-case` → `camelCase` через `split`, `at`, `toUpperCase`, `join`.
2. **Массивы.** Копия через spread или `slice`, разворот через `reverse` или цикл.
3. **Словарь.** Перевод фразы по объекту-словарю.
4. **Дни недели.** Объект, `this`, `new Date()` и формула для понедельника.
5. **Персонал и предметы.** Копия объекта, `JSON.stringify`, `split`/`join`, `push`/`splice`.

## Что сдаёшь

- шесть программ 2.1–2.6 в одном `.js` или `.html`;
- вывод каждой программы в консоль;
- исходный массив в 2.2 и объект в 2.5 не изменены;
- список предметов обновляется без дубликатов;
- решения написаны самостоятельно, без копирования `answers.md`.

## Что понадобится

- `let`, `const`, `console.log`, `if`, `for`, `function` из первой домашки;
- браузер или Node.js для запуска;
- 45 минут без переключения на другие задачи.
