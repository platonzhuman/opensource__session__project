# 3. Ассоциативный массив: перевод по словарю

Цель урока: по слову находить его перевод из таблицы. Это задание 2.3.

## Ассоциативный массив — это словарь

Обычный массив ищет по **номеру**: `arr[0]`, `arr[1]`. Ассоциативный массив ищет
по **имени**:

| Ключ (имя) | Значение |
| --- | --- |
| `привет` | `hello` |
| `мир` | `world` |
| `книга` | `book` |
| `спасибо` | `thanks` |

В JavaScript такой словарь — это **объект** в фигурных скобках:

```js
let en = { привет: 'hello', мир: 'world', книга: 'book', спасибо: 'thanks' };
```

`en['мир']` вернёт `'world'`. Можно и через точку: `en.мир`, но если ключ лежит в
переменной, работает только скобка: `en[key]`.

## Ключа может не быть

Если запросить несуществующий ключ, ошибки не будет — вернётся специальное
значение `undefined` («не определено»). Это удобно для перевода: нет в словаре —
оставляем слово как есть.

| Код | Результат |
| --- | --- |
| `en['мир']` | `'world'` |
| `en['стол']` | `undefined` |
| `'стол' in en` | `false` |
| `'мир' in en` | `true` |

Проверка `dict[w] !== undefined` означает «в словаре есть слово `w`».

## Механизм перевода фразы

Фраза — это слова, разделённые пробелом. Разберём её тем же приёмом, что в уроке 1,
только наоборот:

1. `.split(' ')` — разрезать фразу на массив слов.
2. Для каждого слова взять перевод из словаря (или оставить слово).
3. Сложить результаты в массив-выход.
4. `.join(' ')` — сшить обратно с пробелами.

`'привет мир'` в словаре `en`:

| Шаг | Действие | Результат |
| --- | --- | --- |
| 1 | `split(' ')` | `['привет', 'мир']` |
| 2 | перевод каждого | `['hello', 'world']` |
| 3 | `join(' ')` | `'hello world'` |

## Что здесь что

| Код | Фраза | Результат |
| --- | --- | --- |
| `{ ключ: значение }` | заведи словарь | объект |
| `dict[w]` | возьми значение по слову `w` | перевод или `undefined` |
| `dict[w] !== undefined` | есть ли это слово в словаре | `true` / `false` |
| `cond ? a : b` | если `cond`, то `a`, иначе `b` | одно из двух |

## Песочница: словарь и функция перевода

```jsplay
let en = { привет: 'hello', мир: 'world', книга: 'book', спасибо: 'thanks' };
let de = { привет: 'hallo', мир: 'welt', книга: 'buch', спасибо: 'danke' };

function translate(text, lang) {
  let dict = lang ___ 'de' ? de : en;   // (1) какой знак: === ?
  let words = text.___(' ');            // (2) как разрезать на слова?
  let out = [];
  for (let i = 0; i < words.length; i++) {
    out.___(dict[words[i]] !== undefined ? dict[words[i]] : words[i]); // (3) как добавить?
  }
  return out.___(' ');                  // (4) как сшить?
}

console.log(translate('привет мир', 'en'));
console.log(translate('привет мир', 'de'));
console.log(translate('привет стол', 'en'));
```

??? success "Проверить"
    `lang === 'de'` выбирает немецкий словарь. `split(' ')` режет фразу,
    `push(...)` добавляет перевод (или само слово, если его нет в словаре),
    `join(' ')` сшивает. Вывод: `hello world`, `hallo welt`, `привет стол` —
    слово «стол» отсутствует, поэтому осталось без перевода.

## Наивные вопросы

- **Почему для `words[i]` не подходит `dict.words[i]`?** `dict.words[i]` сначала
  ищет свойство `words` у объекта, а его там нет. Нужен перевод **значения**
  элемента: `dict[words[i]]`.
- **Что делает `? ... : ...`?** Тернарный оператор: «если условие истинно — первое,
  иначе — второе». Короткая запись `if/else`.
- **Зачем хранить два словаря?** «Необходимый язык» из задания: выбрали немецкий —
  берём `de`, иначе `en`.
- **А если фраза с двумя пробелами?** `split(' ')` даст пустой кусок. Для домашки
  достаточно одинарных пробелов.
