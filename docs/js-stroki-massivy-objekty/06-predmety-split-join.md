# 6. «Предметы»: `split`, `join`, `push`, `splice`

Цель урока: объект со списком предметов одной строкой и двумя методами —
добавить и удалить. Это задание 2.6.

## Предметы хранятся строкой через запятую

```js
let predmety = {
  list: 'Математика, Физика, Информатика'
};
```

Строка удобна для вывода, но добавлять в неё с середины нельзя. Поэтому работаем
через массив: **разрезали → изменили → сшили**.

| Шаг | Код | Результат |
| --- | --- | --- |
| разрез | `this.list.split(', ')` | `['Математика', 'Физика', 'Информатика']` |
| сшивка | `arr.join(', ')` | `'Математика, Физика, Информатика'` |

Обрати внимание на разделитель: после запятой стоит **пробел**, поэтому режем и
склеиваем по `', '`.

## Поиск: `indexOf`

`arr.indexOf(x)` возвращает **номер** элемента `x` в массиве или `-1`, если его
там нет.

| Код | Результат |
| --- | --- |
| `['А','Б'].indexOf('Б')` | `1` |
| `['А','Б'].indexOf('В')` | `-1` |

Условие «предмета ещё нет» — это `arr.indexOf(x) === -1`.

## Добавление: `push`

`arr.push(x)` кладёт элемент в **конец** массива. Добавляем только если его нет:

```
if (arr.indexOf(subject) === -1) { arr.push(subject); }
```

## Удаление: `splice`

`splice(i, 1)` удаляет **1 элемент** начиная с позиции `i`, передвигая хвост.
Номер `i` берём у `indexOf`. Условие «предмет уже есть» — `i !== -1`.

| Код | Что делает |
| --- | --- |
| `arr.splice(1, 1)` | удалить один элемент с позиции 1 |
| `arr.splice(1, 2)` | удалить два элемента начиная с позиции 1 |
| `arr.splice(1, 0, 'x')` | вставить `'x'` перед позицией 1, ничего не удаляя |

## `this`, как в прошлом уроке

Метод живёт внутри объекта, поэтому к списку обращаемся через `this.list`.
После правок массив сшиваем обратно и записываем в `this.list`.

## Что здесь что

| Код | Фраза | Результат |
| --- | --- | --- |
| `this.list.split(', ')` | разрежь список на предметы | массив |
| `arr.indexOf(x)` | где стоит `x` | номер или `-1` |
| `arr.push(x)` | добавь `x` в конец | новый массив |
| `arr.splice(i, 1)` | удали элемент номер `i` | массив без него |
| `arr.join(', ')` | сшей предметы обратно | строка |
| `this.list = ...` | запиши результат объекту | список обновлён |

## Наивные вопросы

- **Почему `splice(i, 1)`, а не `splice(i)`?** Без второго аргумента удалится всё
  начиная с `i`. Нам нужен ровно один элемент — отсюда `1`.
- **Почему `=== -1`, а не `!==`?** Могут быть разные условия: для добавления нам
  нужен случай «нет» (`=== -1`), для удаления — «есть» (`!== -1`).
- **Что делает `join(', ')`?** Собирает массив в строку, вставляя `', '` между
  предметами. Запятую с пробелом, как в исходном списке.
- **Почему через `this`, а не через `predmety`?** Метод не привязан к имени
  переменной и работает у любого похожего объекта.
