# 1. Строка в camelCase: `split`, `at`, `toUpperCase`

Цель урока: превратить `слово-слово-слово` в `словоСловоСлово`, используя ровно
четыре метода строки. Это задание 2.1.

## Зачем это нужно

В CSS имена пишут через дефис: `font-size`, `border-top-width`. В JavaScript
свойство записывают без дефиса, а слово после дефиса начинают с большой буквы:
`fontSize`, `borderTopWidth`. Такой стиль зовут **camelCase** — «горб верблюда».

Почему нельзя оставить дефис? Потому что в JS дефис — это знак минус. Запись
`obj.font-size` компьютер прочитает как «отними от `obj.font` переменную `size`».
Дефис в имени — авария.

## Строка — это последовательность символов

Строка `'cat'` — три символа подряд. Каждый символ стоит на своей позиции, и
счёт идёт **с нуля**:

| Позиция | 0 | 1 | 2 |
| --- | --- | --- | --- |
| символ | `c` | `a` | `t` |

Метод `.at(i)` берёт символ на позиции `i`:

| Код | Результат |
| --- | --- |
| `'cat'.at(0)` | `'c'` |
| `'cat'.at(2)` | `'t'` |
| `'cat'.at(-1)` | `'t'` — с конца |

`.toUpperCase()` поднимает регистр: `'c'.toUpperCase()` → `'C'`.

## Механизм по шагам

Чтобы убрать дефис и поднять буквы, строку сначала **разрезают на слова**, потом
склеивают. Цепочка «почему»:

1. **Зачем резать?** Строка — один кусок. Пока она целая, к её «букве после дефиса»
   не подобраться: непонятно, где эта буква.
2. **Чем резать?** `.split('-')` бьёт строку по дефису и отдаёт **массив слов**.
3. **Что оставить?** Первое слово не трогаем. У остальных первую букву поднимаем.
4. **Как поднять одну букву?** `.at(0)` — первый символ, `.toUpperCase()` — в
   верхний регистр, `.slice(1)` — остаток слова без первой буквы. Склеиваем `+`.
5. **Как вернуть строку?** `.join('')` сшивает массив обратно, `''` — пустой
   разделитель, чтобы между словами ничего не вставлялось.

Проверим на числах. `'font-size-weight'`:

| Шаг | Код | Результат |
| --- | --- | --- |
| 1 | `'font-size-weight'.split('-')` | `['font', 'size', 'weight']` |
| 2 | `words[1] = 'size'.at(0).toUpperCase() + 'size'.slice(1)` | `'Size'` |
| 3 | `words[2] = 'weight'.at(0).toUpperCase() + 'weight'.slice(1)` | `'Weight'` |
| 4 | `['font', 'Size', 'Weight'].join('')` | `'fontSizeWeight'` |

## Что здесь что

| Метод | Фраза | Пример |
| --- | --- | --- |
| `.split(x)` | разрежь строку по `x` | `'a-b'.split('-')` → `['a','b']` |
| `.at(i)` | возьми символ номер `i` | `'ab'.at(0)` → `'a'` |
| `.toUpperCase()` | подними регистр | `'ab'.toUpperCase()` → `'AB'` |
| `.slice(1)` | возьми всё, кроме первого символа | `'ab'.slice(1)` → `'b'` |
| `.join(x)` | склей массив в строку через `x` | `['a','b'].join('')` → `'ab'` |

## Песочница: допиши пропуски

```jsplay
// @mode fix
// @expect borderTopWidth
// @hint split('-'), toUpperCase(), join('')
function toCamel(s) {
  let words = s.split('___');                 // (1) по какому символу режем?
  for (let i = 1; i < words.length; i++) {
    words[i] = words[i].at(0).___() + words[i].slice(1);  // (2) что поднимает регистр?
  }
  return words.join('___');                   // (3) что между словами?
}
console.log(toCamel('border-top-width'));     // ожидаем borderTopWidth
```

??? success "Проверить"
    `s.split('-')` → `['border','top','width']`. Внутри цикла
    `words[i].at(0).toUpperCase() + words[i].slice(1)` делает `'top' → 'Top'`, а
    `'width' → 'Width'`. `words.join('')` собирает `'border' + 'Top' + 'Width'` =
    `borderTopWidth`. Первое слово стоит на позиции `0` и цикл им не тронут.

## Наивные вопросы

- **Почему цикл начинается с `i = 1`, а не с `0`?** Первое слово уже с маленькой
  буквы, его трогать не надо. Позиция `0` — первое слово.
- **Зачем `+` между `at(...)` и `slice(...)`?** Это склейка двух строк в одну:
  `'S' + 'ize'` → `'Size'`.
- **`'background-color'` — а если дефисов нет?** `split('-')` вернёт массив из
  одного куска, цикл не выполнится, `join('')` вернёт строку как была.
- **`at` и квадратные скобки `[0]` — одно и то же?** Почти. `[0]` тоже берёт
  первый символ, но `at` понимает отрицательные номера (`at(-1)` — последний).
