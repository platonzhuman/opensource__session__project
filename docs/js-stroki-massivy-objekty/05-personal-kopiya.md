# 5. Объект «персонал» и его копия

Цель урока: скопировать объект, поменять имена в копии и вывести оба объекта
строками с переносами. Это задание 2.5.

## Объект хранит пары «должность — имя»

```js
let personal = { директор: 'Иван', менеджер: 'Пётр', инженер: 'Сергей' };
```

Ключ — должность, значение — имя. `personal['директор']` → `'Иван'`, а через точку
`personal.директор` — то же самое. Точкой удобно **менять** значение:

```js
personal.директор = 'Ольга';
```

## Копия объекта — та же ловушка, что у массива

`let p2 = personal` не копирует, а даёт второе имя той же коробки: меняешь `p2` —
меняется `personal`. Настоящая копия:

| Способ | Код |
| --- | --- |
| spread | `let p2 = { ...personal };` |
| assign | `let p2 = Object.assign({}, personal);` |

После этого `p2.директор = 'Ольга'` меняет только копию, оригинал цел.

## Объект → строка: `JSON.stringify`

`console.log` показывает объект как угодно браузеру. Чтобы получить **строку**,
объект пропускают через `JSON.stringify`:

| Код | Результат |
| --- | --- |
| `JSON.stringify({a: 1})` | `'{"a":1}'` |
| `JSON.stringify({a: 1}, null, 2)` | строки с отступами и переносами |

Второй вариант принимает `null` (фильтр ненужных полей) и `2` — сколько пробелов
отступа. Именно он расставляет символы переноса строки `\n` между полями.

## Знак переноса строки

`'\n'` — это **один** символ «перевод строки». Когда он внутри строки, следующий
текст печатается с новой строки:

| Код | Что напечатает |
| --- | --- |
| `console.log('a\nb')` | `a` и `b` на разных строках |

## Что здесь что

| Код | Фраза | Результат |
| --- | --- | --- |
| `{ ...obj }` | разложи поля в новый объект | копия |
| `obj.key = v` | замени значение поля | объект с новым значением |
| `JSON.stringify(obj, null, 2)` | объект в красивую строку | строка с `\n` |
| `'\n'` | перевод строки | один символ |

## Песочница: копия и вывод строкой

```jsplay
let staff = { повар: 'Аня', водитель: 'Борис', врач: 'Вера' };
let staff2 = { ___staff };               // (1) как скопировать поля?

staff2.повар = 'Галина';
staff2.водитель = 'Дмитрий';
staff2.врач = 'Елена';

console.log('Штат:\n' + JSON.stringify(staff, null, ___));   // (2) отступ
console.log('Штат 2:\n' + JSON.stringify(staff2, null, 2));
```

??? success "Проверить"
    `{ ...staff }` создаёт копию, поэтому правки `staff2` не задевают `staff`.
    Второй аргумент `2` включает отступ и переносы строк. Первый вывод показывает
    Аню, Бориса, Веру, второй — Галину, Дмитрия, Елену.

## Наивные вопросы

- **Почему `{ ...personal }`, а не `[ ...personal ]`?** Квадратные скобки делают
  массив, фигурные — объект. Нам нужен объект.
- **Что такое `null` во втором аргументе?** Заглушка «фильтр не нужен». Третий
  аргумент без второго не задать, поэтому пишут `null`.
- **Можно менять поля прямо в оригинале?** Можно, но тогда копия не нужна. Смысл
  задания — показать, что копия живёт отдельно.
- **`\n` внутри строки — это два символа?** Нет, это запись одного символа
  «новая строка». В коде их два знака, а результат — один.
