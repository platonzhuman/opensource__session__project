# Дополнительная практика

Здесь только аналоги домашки — на других словах и числах. Решай сам, ответы
смотри в [answers.md](answers.md).

## Разминка: строки

Переведи в camelCase. Пиши функцию сам, потом открывай подсказку.

- `'data-test-id'`
- `'web-style-name'`
- `'main-header-block'`

??? success "Ответ"
    `dataTestId`, `webStyleName`, `mainHeaderBlock`.

## Разминка: массивы

Дан `[1, 2, 3, 4, 5]`. Сделай две копии двумя способами и разверни каждую своим
способом (встроенным и циклом). Оригинал должен остаться нетронутым.

??? success "Ответ"
    Обе копии после разворота: `[5, 4, 3, 2, 1]`. Оригинал — `[1, 2, 3, 4, 5]`.

## Разминка: словарь

Сделай словарь `fr` из четырёх слов и функцию перевода на французский. Незнакомое
слово возвращай без изменений.

??? success "Ответ"
    `bonjour / monde / livre / merci`. Незнакомое слово выводится как есть.

## Финальное задание (это и есть домашка)

Напиши и запусти каждую программу сам:

1. **2.1** — функция `kebabToCamel(s)` методами `split`, `at`, `toUpperCase`.
   Проверь на `'background-color'`.
2. **2.2** — массив `[9,8,7,6,5,4,3,2,1]`: две копии двумя способами, разворот
   двумя способами, вывод трёх массивов.
3. **2.3** — объект-словарь на 4 слова и функция перевода на нужный язык.
4. **2.4** — объект «дни недели» с ключами `1…7` и методом текущего дня.
5. **2.5** — объект «персонал», его копия, смена имён, вывод обоих строкой с
   переносами.
6. **2.6** — объект «предметы» с методами `add` (split/join/push) и `remove`
   (splice).

Решения и разборы — в [answers.md](answers.md). Открывай после попытки.
