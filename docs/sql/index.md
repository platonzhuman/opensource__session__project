## Как проходить подтему

Одна подтема — 3–5 дней, а не один заход на 90 минут. Исключение — «Front: разведка базы»: она рассчитана на один заход примерно на час, потому что домашка срочная.

- [ ] **День 1.** Жизненный пример → теория → диагностика. Если меньше 80%,
      вернись к одному месту, а не перечитывай всё.
- [ ] **День 2.** Практика с каркасом: починить, дополнить, сопоставить.
- [ ] **День 3.** Куски своей домашки: три маленькие проверки.
- [ ] **День 4.** Половина модуля: соединение кусков.
- [ ] **День 5.** Полный модуль и объяснение решения.
- [ ] **Дальше.** Возврат через 1, 3, 7, 14 и 30 дней.

В курсах с автопроверкой (`@expect`) результат проверяется сразу после запуска.
