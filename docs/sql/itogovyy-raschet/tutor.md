# Репетитор в песочнице

На задачах `write` / `fix` с `@id` рядом с **Запустить** появляются **Спросить** и **В чат**.
Основной путь без API: кнопка копирует готовый русский промпт (миссия, `@id`, сид, твой SQL, результат `@expect`) — вставь его в чат Cursor Auto. На сайте сразу видно «Скопировано — вставь в чат Cursor» и превью текста. Мост на `:8765` не обязателен.

!!! warning "Граница"
    **Репетитор только по этому ДЗ. Готовое решение целиком не выдаёт.**
    После 3 неудачных попыток по одному `@id` можно получить частичный намёк — не весь homework.
    Код для PR пишешь сам. Ответы репетитора эфемерны.

## Как пользоваться (без ключа)

1. Открой [Итоговый расчёт](index.md), дойди до задачи с `@id`.
2. Напиши SQL → **Запустить** (чтобы была проверка).
3. **Спросить** или **В чат** — текст в буфере + превью под песочницей.
4. Вставь скопированное в чат Cursor Auto в IDE.

Сайт MkDocs: `./serve.sh` → `http://127.0.0.1:8000`. Ключ Cursor и `tutor_bridge` для этого пути не нужны.

## Опционально: локальный мост (--demo / API)

Если мост уже запущен, **Спросить** дополнительно попробует получить ответ на сайте. Это удобно для `--demo`, но не happy path.

```bash
# Без API-ключа: demo-ответы под виджетом
./scripts/tutor_bridge.sh --demo

# С настоящим Cursor-агентом:
#   .venv/bin/pip install -r requirements-tutor.txt
#   export CURSOR_API_KEY=cursor_...
./scripts/tutor_bridge.sh
```

Мост: `http://127.0.0.1:8765`. Правила агента (в репо, не на сайте): `learner/tutor-rules.md`.

Прогресс «где застрял» пишется в `localStorage` и попадает в скопированный промпт / payload моста.

## Динамика курса

Агент **может** подправить только `@hint` / каркас застрявшего `@id` в
`docs/sql/itogovyy-raschet/index.md`. Не трогает остальные курсы.
При `mkdocs serve` правки обычно подхватываются сами; иначе обнови страницу.
`answers.md` репетитор в чат не выкладывает.
