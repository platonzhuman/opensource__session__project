# 2. Реальные данные из ТЗ

Берём типы оборудования и параметры из технического задания, а не придумываем.
После урока у тебя будет готовый список значений для `INSERT`.

## Типы оборудования

В ТЗ (`_Docs/Artillery/TechnicalTask.md`) режим расчёта задаётся оборудованием:

- **ДМК** — десантный метеокомплект;
- **ВР** — ветровое ружьё.

Других типов в задании нет. Значит, в `equipment_types` только эти две записи.

## Параметры

Входные данные метеобюллетеня:

| Код | Параметр | Ед. | По умолч. |
|-----|----------|-----|-----------|
| 1 | Высота метеопоста | м | 100 |
| 2 | Температура воздуха на высоте метеопоста | °C | 15 |
| 3 | Давление атмосферы на высоте метеопоста | мм рт. ст. | 750 |
| 4 | Направление ветра в приземном слое воздуха | б. д. у. | 00 |
| 5 | Скорость ветра в приземном слое воздуха | м/с | 0 |
| 6 | Дальность сноса пуль | м | 0 |

!!! note "ДМК или ВР"
    Пятая строка отличается по оборудованию: для `ДМК` — «Скорость ветра», для
    `ВР` — «Дальность сноса пуль». Оба параметра оставляем в справочнике.

## Диапазоны из ТЗ

Пригодятся при проверке данных:

| Параметр | Тип значения | Диапазон |
|----------|--------------|----------|
| Высота метеопоста | целое, любой знак | — |
| Температура | дробное, 1 знак | −58…58 |
| Давление | целое ≥ 0 | 500…900 |
| Направление ветра | 2 разряда | 0…59 |
| Скорость ветра | целое ≥ 0 | 0…15 |
| Дальность сноса пуль | целое ≥ 0 | 0…150 |

## Значения, а не только названия

Замечание преподавателя: «где значения параметров?». Поэтому у параметра два
смысла, которые нельзя путать:

- **название** — что измеряем (`Температура воздуха…`);
- **значение** — сколько измерено (`15`).

В таблице это два разных столбца:

```sql
name  varchar(150) not null,   -- что измеряем
value numeric(10,2) not null   -- сколько
```

!!! warning "Ошибка"
    Записать значение в столбец `name`. Тогда `name = '15'` — бессмыслица,
    название потеряно.
