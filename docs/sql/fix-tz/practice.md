## Задание 1 (урок 2)

Выпиши типы оборудования из ТЗ. Сколько их и как называются?

**Требуется:** список для `INSERT INTO equipment_types`.

## Задание 2 (урок 2)

Для параметра «Давление атмосферы на высоте метеопоста» укажи название, единицу
измерения и значение по умолчанию.

**Требуется:** три значения для строки `INSERT INTO parameters`.

## Задание 3 (урок 3)

Дана таблица со связью:

```sql
create table packs (
    id                integer not null,
    user_id           integer not null,
    equipment_type_id integer not null,
    constraint pk_packs primary key (id),
    constraint fk_packs_user foreign key (user_id) references users (id),
    constraint fk_packs_type foreign key (equipment_type_id) references equipment_types (id)
);
```

Перепиши её без связей, сохранив уникальный код.

**Требуется:** `CREATE TABLE` без `FOREIGN KEY`.

## Задание 4 (урок 4)

Создай таблицу `parameters` для значений параметров пачки: код, код пачки,
название, единица, значение. Первичный ключ — на `id`.

**Требуется:** `CREATE TABLE` с пятью столбцами.

## Задание 5 (урок 4)

Вставь две пачки: одну с `ДМК`, одну с `ВР`. Для каждой — набор параметров.

**Требуется:** `INSERT` в `packs` и `parameters` без висячих ссылок.

## Задание 6 (урок 5)

Напиши `SELECT`, который объединяет все пять таблиц и выводит: код пачки, дату,
ФИО, должность, тип оборудования, название параметра, единицу и значение.

**Требуется:** запрос с четырьмя `JOIN ... ON` и `ORDER BY`.

## Задание 7 (урок 6)

Перечисли, что должно быть в PR и какие пункты проверить перед сдачей.

**Требуется:** минимум пять пунктов чек-листа.
