# 6. Сдача: .sql, скриншот, PR

Последний урок — оформление. После него домашка готова к отправке.

## Три пункта задания

1. **Файл `.sql`** — скрипт целиком, с расширением `.sql`.
2. **Скриншот** — результат `SELECT` с объединением всех таблиц.
3. **Pull Request** — в своём репозитории, работа в отдельной ветке.

## Проверка перед сдачей

- [ ] Скрипт запускается дважды без ошибок.
- [ ] У каждой таблицы есть `PRIMARY KEY`.
- [ ] `FOREIGN KEY` нет нигде.
- [ ] В `parameters` есть столбец `value` со значениями.
- [ ] Типы оборудования — `ДМК` и `ВР`, не выдуманные.
- [ ] `SELECT` возвращает данные из всех пяти таблиц.
- [ ] Сделан скриншот результата.
- [ ] Файл имеет расширение `.sql`.
- [ ] Работа в отдельной ветке, создан Pull Request.

## Git

```bash
git checkout -b homework_one
git add homework.sql
git commit -m "Fix homework: real equipment types, parameter values, no FKs"
git push -u origin homework_one
```

Затем на GitHub нажми **Compare & pull request**, заполни описание, создай PR.

## Что приложить в PR

- Файл `homework.sql`.
- Скриншот результата.
- Короткое описание: какие таблицы создал, что взял из ТЗ.

## Частые ошибки

!!! warning "Ошибка"
    Сдать файл без расширения `.sql`. Преподаватель ждёт SQL-файл.

!!! warning "Ошибка"
    Оставить в PR посторонние файлы: тестовые скрипты, правки `docker-compose`.
    PR должен содержать только домашку.
