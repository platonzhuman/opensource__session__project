# 5. SELECT с объединением

Соединяем все пять таблиц по обычным столбцам. Связей в схеме нет, но в запросе
объединение делается так же. После урока ты соберёшь результат для скриншота.

## Запрос

```sql
select p.id           as pack_id,
       p.created_on,
       u.full_name,
       pos.name       as position,
       et.name        as equipment_type,
       par.name       as parameter,
       par.unit,
       par.value
from packs p
join users u            on p.user_id = u.id
join positions pos      on u.position_id = pos.id
join equipment_types et on p.equipment_type_id = et.id
join parameters par     on par.pack_id = p.id
order by p.id, par.id;
```

## Разбор цепочки

- `from packs p` — основа, пачки;
- `join users u on p.user_id = u.id` — пользователь каждой пачки;
- `join positions pos on u.position_id = pos.id` — должность пользователя;
- `join equipment_types et on p.equipment_type_id = et.id` — тип оборудования;
- `join parameters par on par.pack_id = p.id` — параметры внутри пачки.

Каждый `JOIN` цепляет новую таблицу к уже подключённой. Условия `on` те же, что
были бы при `FOREIGN KEY`, просто ограничение не объявлено в схеме.

## Почему строк станет больше

У пачки несколько параметров. Поэтому каждая пачка повторится столько раз,
сколько в ней строк в `parameters`.

| pack_id | equipment_type | parameter | value |
|---------|----------------|-----------|-------|
| 1 | ДМК | Высота метеопоста | 100 |
| 1 | ДМК | Температура воздуха… | 15 |
| 1 | ДМК | Давление атмосферы… | 750 |
| 1 | ДМК | Направление ветра… | 0 |
| 1 | ДМК | Скорость ветра… | 0 |
| 2 | ВР | Высота метеопоста | 100 |
| 2 | ВР | Температура воздуха… | 12 |
| 2 | ВР | Давление атмосферы… | 760 |
| 2 | ВР | Направление ветра… | 20 |
| 2 | ВР | Дальность сноса пуль | 45 |

Итог — 10 строк. Это и есть «объединение всех таблиц» для скриншота.

!!! warning "Ошибка"
    Соединять `parameters` напрямую с `users` или `equipment_types` в обход
    `packs`. Общего столбца у них нет. Параметры принадлежат пачке, а пачка —
    пользователю и типу.
