# 4. Формула линейной интерполяции

Четыре числа есть. Осталось главное — посчитать поправку для температуры между
ними. Выведем формулу сами, чтобы её не пришлось запоминать.

!!! abstract "Цель урока"
    Ты сам выведешь формулу линейной интерполяции и посчитаешь по ней 26°.

## Шаг 1 · Что значит «интерполировать»

Таблица даёт точки. Между соседними точками считаем, что поправка меняется
**по прямой линии**. Найти `y` для `x` между точками — значит встать на эту
прямую ровно над `x`.

## Шаг 2 · Доля пути

Возьмём 26° и отрезок `[25 .. 30]`. Температура прошла от 25 до 26:

```text
25 --------->|------------------ 30
        26
доля = (26 − 25) / (30 − 25) = 1 / 5 = 0.2
```

Мы прошли **20% отрезка** по температуре.

## Шаг 3 · Та же доля — у поправки

Раз поправка меняется по прямой, она проходит ту же долю:

```text
2 ---------->|------------------ 3.5
             ?
y = 2 + 0.2 · (3.5 − 2) = 2 + 0.3 = 2.3
```

Для 26° интерполированная поправка — **2.3**.

## Шаг 4 · Формула целиком

```text
y = y0 + (x − x0) · (y1 − y0) / (x1 − x0)
```

Расшифровка:

| обозначение | что это | для 26° |
| --- | --- | --- |
| `x0`, `y0` | нижняя граница: температура и поправка | 25, 2 |
| `x1`, `y1` | верхняя граница | 30, 3.5 |
| `x` | искомая температура | 26 |

Проверка формулы на краях: при `x = x0` получается `y0`, при `x = x1` — `y1`.
Если формула на краях не даёт крайние значения — где-то ошибка.

!!! question "Сделай"
    Посчитай поправку для 27.5° на том же отрезке.

??? success "Проверить"
    Доля `(27.5 − 25) / 5 = 0.5`; `y = 2 + 0.5 · 1.5 = 2.75`.

## Шаг 5 · Пример из ТЗ: 23°

Пример из ТЗ: для измеренной температуры 23° интерполированная поправка равна
`1.8`. Проверим: отрезок `[20 .. 25]`, по ТЗ-таблице `y0 = 1.5`, `y1 = 2`:

```text
y = 1.5 + (23 − 20) / (25 − 20) · (2 − 1.5) = 1.5 + 0.6 · 0.5 = 1.8
```

Сходится. Но обрати внимание: в таблице из класса для 20° стоит `1.0`, а не
`1.5` — тогда для 23° получится `1.6`. Формула одна и та же, а числа зависят
от данных таблицы.

!!! warning "Два источника чисел"
    ТЗ (Таблица 1) говорит: ниже 0 → 0; 20 → 1.5. Таблица из класса:
    начинается с 0 → 0.5, и 20 → 1.0. Из-за этого пример ТЗ для 23° даёт 1.8
    только с ТЗ-таблицей. Уточни у учителя, какая таблица эталонная; на код это
    не влияет, на числа в проверках — влияет.

## Откуда числа

Отрезок и пример 26° — из задания. Пример 23° → 1.8 — из ТЗ (пример 1).
Значения таблицы — как в базе.

## Наивные вопросы

!!! question "А если `x` вне отрезка?"
    Формула честно продолжит прямую дальше — это уже экстраполяция. Поэтому
    «выходы за таблицу» мы обрабатываем отдельно (урок 6), а не отдаём формуле.

!!! question "Почему именно прямая?"
    Так устроена таблица корректировок: между её точками поправка меняется
    линейно. Для соседних точек это стандартный и самый простой вид
    интерполяции.

## Чекпоинт

!!! question "Проверка"
    1. **Предскажи:** какую долю пути пройдёт температура 39° на отрезке `[30 .. 40]`?
    2. **Объясни**, почему в формуле три раза встречаются числа с индексами 0 и 1.
    3. **Посчитай** поправку для 21° по таблице из класса.

??? success "Проверить"
    1. `(39 − 30) / (40 − 30) = 0.9`.
    2. `x0/y0` и `x1/y1` — концы отрезка; формула берёт разницу от нижнего конца
       и добавляет долю от общего изменения.
    3. `1 + (21 − 20) / 5 · (2 − 1) = 1.2`.
