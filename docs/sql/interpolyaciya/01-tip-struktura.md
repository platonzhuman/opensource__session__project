# 1. Зачем тип-структура

Функция в Postgres возвращает **одно** значение. А задание просит вернуть сразу
четыре: две температуры-границы и две поправки. Как вернуть четыре числа одним
значением? Ответ — свой тип.

!!! abstract "Цель урока"
    Ты поймёшь, зачем нужен `create type interpolation_type as (...)` и как
    полями такого типа пользоваться.

## Шаг 1 · Варианты вернуть четыре числа

1. **Четыре отдельные функции**: `t_min(t)`, `c_min(t)`, `t_max(t)`, `c_max(t)`.
   Минус: четыре раза дёргаем таблицу, значения могут разъехаться.
2. **Параметры `out`**: `create function f(t numeric, out x0 numeric, ...)`.
   Работает, но сигнатура разрастается, а вызывать неудобно.
3. **Композитный тип**: одно значение, внутри — четыре именованных поля.

В классе выбрали третий. Он же прописан в задании: `x0, y0, x1, y1`.

## Шаг 2 · Композитный тип

!!! note "Определение"
    **Композитный тип** — свой тип данных из нескольких именованных полей.
    Создаётся через `create type ... as (...)`.

```sql
create type public.interpolation_type as (
	x0 numeric, y0 numeric,   -- нижняя граница: температура и поправка
	x1 numeric, y1 numeric    -- верхняя граница
);
```

После этого `interpolation_type` — полноценный тип: из него можно объявить
переменную, и его можно вернуть из функции.

!!! question "Сделай"
    Сколько полей у типа `interpolation_type` и какого они типа?

??? success "Проверить"
    Четыре поля типа `numeric`: `x0`, `y0`, `x1`, `y1`.

## Шаг 3 · Поля достаются через точку

В PL/pgSQL поле переменной — через точку:

```sql
do $$
declare
	v interpolation_type;
begin
	v.x0 := 25;                       -- записали поле
	raise notice 'x0 = %', v.x0;      -- прочитали поле
end $$;
```

В обычном SQL у значения структуры — скобки и звёздочка (все поля) или имя поля:

```sql
select (get_interpolation_type_correction(26)).*;     -- x0 | y0 | x1 | y1
select (get_interpolation_type_correction(26)).y1;    -- только y1
```

!!! question "Сделай"
    Как прочитать только поле `y1` из результата функции?

??? success "Проверить"
    `select (get_interpolation_type_correction(26)).y1;`

## Шаг 4 · Почему имена именно такие

Задание фиксирует контракт: `x0 — y0` — нижняя граница, `x1 — y1` — верхняя.
`x` — температура, `y` — поправка. Вторая функция принимает эту структуру и
возвращает уже одно число — интерполированную поправку.

## Откуда числа

Имена `x0, y0, x1, y1` — из задания. Пример «25–2 и 30–3.5» — для температуры
26° (задание, `History20261014.md`).

## Наивные вопросы

!!! question "Почему не массив `numeric[4]`?"
    У массива нет имён полей: `arr[3]` ни о чём не говорит. А `x1` — сразу
    понятно: верхняя температура.

!!! question "Тип — это как таблица?"
    Похоже: тоже «набор полей». Но таблица хранит строки в базе, а тип — это
    форма значения переменной или результата функции.
