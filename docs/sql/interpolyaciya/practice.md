## Разминка

### Задание 1 (урок 1)

Напиши `create type` для интерполяционной структуры.

??? success "Ответ"
    `create type public.interpolation_type as (x0 numeric, y0 numeric, x1 numeric, y1 numeric);`

### Задание 2 (урок 1)

Как достать поле `y0` из результата функции в обычном SQL?

??? success "Ответ"
    `select (get_interpolation_type_correction(26)).y0;`

### Задание 3 (урок 2)

Напиши пары «нижняя-верхняя» из `calc_temperature_correction` через `lead`.

??? success "Ответ"
    ```sql
    select temperature as x0,
           correction  as y0,
           lead(temperature) over (order by temperature) as x1,
           lead(correction)  over (order by temperature) as y1
    from calc_temperature_correction;
    ```

### Задание 4 (урок 2)

Какой отрезок найдётся для 33°? А для 21°?

??? success "Ответ"
    33° — `(30, 3.5, 40, 4.5)`. 21° — `(20, 1, 25, 2)`.

### Задание 5 (урок 3)

Классный запрос для 30° вернёт `(30, 3.5)` или `(40, 4.5)`? Почему?

??? success "Ответ"
    `(40, 4.5)`: условие путало корректировку с температурой, и побеждала строка
    с максимальной корректировкой.

### Задание 6 (урок 4)

Посчитай интерполированную поправку для 38.5° (по таблице из класса).

??? success "Ответ"
    Отрезок `[30 .. 40]`: доля `(38.5 − 30) / 10 = 0.85`;
    `y = 3.5 + 0.85 · 1 = 4.35`.

### Задание 7 (урок 5)

Почему `interpolate(40, ...)` не падает с ошибкой деления?

??? success "Ответ"
    У последней строки `x1 = NULL`, а функция в этом случае возвращает `y0`
    (защита от деления).

### Задание 8 (урок 5)

Напиши защиту от деления на ноль внутри `interpolate`.

??? success "Ответ"
    `if par_segment.x1 is null or par_segment.x1 = par_segment.x0 then return par_segment.y0; end if;`

### Задание 9 (урок 6)

Что вернут проверки для -5° и для 45°?

??? success "Ответ"
    -5° → 0 (правило ТЗ «ниже 0»), 45° → 4.5 (последняя точка таблицы).

### Задание 10 (урок 7)

Напиши проверку: `y(30)` должен быть равен `3.5`.

??? success "Ответ"
    `if interpolate(30, get_interpolation_type_correction(30)) is distinct from 3.5 then raise exception 'FAIL y(30)'; end if;`
