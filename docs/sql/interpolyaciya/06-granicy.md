# 6. Границы: ниже 0 и выше 40

Задание подчёркивает: «Обязательно должны учитываться граничные условия.
Температура выше 40 градусов и температура ниже 0 градусов». Разбираем оба края.

!!! abstract "Цель урока"
    Ты поймёшь, что происходит на краях таблицы, добавишь правило ТЗ для
    «ниже 0» и проверишь все четыре граничные температуры.

## Шаг 1 · Что сказано в источниках

- **ТЗ (Таблица 1):** при температуре **ниже 0** виртуальная поправка равна **0**.
- **Таблица корректировок:** самое большое значение — `40 → 4.5`; выше 40 в
  таблице ничего нет.
- **Задание:** оба края должны быть обработаны, функция не имеет права
  «сломаться» или вернуть мусор.

## Шаг 2 · Что уже работает само

`t = 45`. Условие поиска из урока 2:

- `x0 <= 45` — проходят все строки;
- `x1 > 45` — ни одна; но есть спасательное `x1 is null` — подходит последняя
  строка `(40, 4.5, NULL, NULL)`.

Вторая функция увидит `x1 is null` и вернёт `y0 = 4.5`. **Верхний край закрыт.**

## Шаг 3 · Что сломано — нижний край

`t = -5`. Условие `x0 <= -5` не пропускает ни одну строку. `select ... into`
не находит ни строки — и переменная остаётся пустой: все поля `NULL`.

Дальше `interpolate` получит структуру из `NULL` и вернёт `NULL` — мусор.

## Шаг 4 · Правило для «ниже 0»

По ТЗ поправка равна 0. Значит, функция должна вернуть отрезок, на котором
любая интерполяция даст 0. Проще всего — вырожденный отрезок из нулей:

```sql
if par_temperature < 0 then
	v.x0 := 0; v.y0 := 0;
	v.x1 := 0; v.y1 := 0;
	return v;
end if;
```

Почему сработает: у вырожденного отрезка `x1 = x0`, а `interpolate` на этом
случае (урок 5) возвращает `y0 = 0`.

!!! tip "Правило"
    Верхний край — «последняя точка таблицы» (`x1 is null` → возвращаем `y0`).
    Нижний край — правило ТЗ: вырожденный нулевой отрезок.

## Шаг 5 · Проверь все края и стыки

| `t` | отрезок | `y(t)` |
| --- | --- | --- |
| -5 | (0, 0) – (0, 0) | 0 |
| 0 | (0, 0.5) – (5, 0.5) | 0.5 |
| 40 | (40, 4.5) – (NULL, NULL) | 4.5 |
| 45 | (40, 4.5) – (NULL, NULL) | 4.5 |

!!! warning "Расхождение данных"
    В таблице из класса нет строки «ниже 0», а для 20° стоит `1.0` (в ТЗ — `1.5`).
    Структура кода от этого не меняется, а числа в проверках — да: пример ТЗ для
    23° даст `1.8` только с ТЗ-таблицей, с класс-таблицей — `1.6`. Спроси у
    учителя, какая таблица эталонная.

## Откуда числа

Правило «ниже 0 → 0» — Таблица 1 ТЗ. Значение 4.5 — последняя строка таблицы
корректировок.

## Наивные вопросы

!!! question "Почему для -5 не вернуть 0.5 (крайнюю поправку)?"
    Потому что ТЗ прямо говорит: ниже 0 поправка равна 0. Крайняя поправка
    таблицы (0.5) — это уже для температур от 0 и выше.

!!! question "Почему для 45 не продолжить прямую вверх?"
    Выше 40 таблица значений не определена — продолжать нечего. Зажимаем на
    последней точке: 4.5.
