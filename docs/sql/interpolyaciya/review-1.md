# Повторение 1

Повторяем уроки 1–3: тип-структура, выбор отрезка, классная ошибка. Нового
материала нет.

## Разминка

### Задание 1 (урок 1)

Зачем нужен тип `interpolation_type`, почему не вернуть четыре отдельных числа?

??? success "Ответ"
    Функция возвращает одно значение. Тип-структура — это «одно значение из
    четырёх полей»: именованный контракт, один вызов вместо четырёх.

### Задание 2 (урок 1)

Напиши `create type` для полей `x0, y0, x1, y1` типа `numeric`.

??? success "Ответ"
    `create type interpolation_type as (x0 numeric, y0 numeric, x1 numeric, y1 numeric);`

### Задание 3 (урок 2)

Что вернёт `lead(correction) over (order by temperature)` для последней строки
таблицы корректировок?

??? success "Ответ"
    `NULL` — следующей строки нет.

### Задание 4 (урок 2)

Напиши условие `where`, которое находит отрезок для температуры `t`.

??? success "Ответ"
    `where x0 <= t and (x1 > t or x1 is null) order by x0 desc limit 1;`

### Задание 5 (урок 2)

Какой отрезок найдётся для 23°? А для 40°?

??? success "Ответ"
    23° — `(20, 1, 25, 2)`. 40° — `(40, 4.5, NULL, NULL)`.

### Задание 6 (урок 3)

Почему классный запрос возвращал для 26° строку `(40, 4.5)`, а не `(25, 2)`?

??? success "Ответ"
    В условии сравнивалась корректировка (`x1`) с температурой: «температура ≥ 26
    и корректировка ≤ 26». Побеждала строка с самой большой корректировкой —
    `(40, 4.5)`.

### Задание 7 (урок 3)

Что нужно сделать перед тем, как доверять сложному `where`?

??? success "Ответ"
    Проговорить условие словами (с учётом смысла столбцов) и прогнать
    трассировку на одной конкретной температуре.

### Задание 8 (урок 3)

Классная версия для 2° «случайно» выдавала верный отрезок. Почему?

??? success "Ответ"
    Условие «корректировка ≤ 2» отсекало все строки, кроме `(25, 2)` — та самая
    нужная. Это совпадение, а не работающее правило.

## Проверь себя

Собери по памяти мини-запрос: из `calc_temperature_correction` получи пары
«нижняя-верхняя» (x0, y0, x1, y1) с помощью `lead`.

??? success "Ответ"
    ```sql
    select temperature as x0,
           correction  as y0,
           lead(temperature) over (order by temperature) as x1,
           lead(correction)  over (order by temperature) as y1
    from calc_temperature_correction;
    ```
