# 2. Проверка 1: одинаковое число измерений

Первый вопрос анализа: **у каждого пользователя одинаковое количество измерений?**

!!! abstract "Цель урока"
    Ты научишься считать строки по группам (`GROUP BY`, `COUNT`) и отвечать на
    вопрос «одинаково ли у всех».

## Шаг 1 · Посчитай пачки одного пользователя

`COUNT(*)` считает строки. Чтобы посчитать **по каждому** пользователю, нужен
`GROUP BY` — он разбивает строки на группы.

```sqlplay
-- @seed artillery_my
select user_id, count(*) as packs
from packs
group by user_id
order by user_id;
```

!!! question "Сделай"
    Что делает `group by user_id`?

??? success "Проверить"
    Собирает строки в группы по одинаковому `user_id`. Дальше `count(*)` считает
    строки **внутри каждой** группы.

## Шаг 2 · Добавь имя пользователя

Число `user_id` непонятно человеку. Присоединим `users` и возьмём имя.

```sqlplay
-- @seed artillery_my
select u.full_name, count(p.id) as packs
from packs p
join users u on u.id = p.user_id
group by u.full_name
order by packs;
```

!!! question "Сделай"
    Почему `count(p.id)`, а не `count(*)`?

??? success "Проверить"
    Оба считают строки. `count(p.id)` нагляднее: считаем именно **пачки** `p`,
    а не все строки результата.

## Шаг 3 · Не потеряй пользователя без пачек

`join` (внутренний) выбрасывает пользователя, у которого нет ни одной пачки.
Чтобы он остался, нужен `left join`.

```sqlplay
-- @seed artillery_my
select u.full_name, count(p.id) as packs
from users u
left join packs p on p.user_id = u.id
group by u.full_name
order by packs;
```

!!! question "Сделай"
    Что вернёт `count(p.id)` для пользователя без пачек?

??? success "Проверить"
    `0` — строк-пачек нет, `count` не считает `NULL`.

## Шаг 4 · Ответь на вопрос

Вопрос «одинаково ли?» — это «сколько **разных** значений `packs` в результате?».
Если одно — одинаково, если больше — нет.

```sqlplay
-- @seed artillery_my
select count(distinct cnt) as разных_значений
from (
	select count(p.id) as cnt
	from users u
	left join packs p on p.user_id = u.id
	group by u.id
) t;
```

!!! question "Сделай"
    Что означает результат `1`? А `2`?

??? success "Проверить"
    `1` — у всех одинаковое число пачек. Больше `1` — есть различия, вопрос
    «одинаково?» → **нет**.

## Шаг 5 · Проверь на своих данных

!!! question "Сделай"
    Запусти запрос из шага 3 и выпиши, у кого сколько пачек.

??? success "Проверить"
    У Иванова и Петрова по `3`, у Сидорова `2`. Значит, **нет** — количество
    измерений разное.

!!! tip "Правило"
    «Одинаково ли у всех?» = «одно ли уникальное число значений счётчика?».
    Считаешь по группам, потом смотришь `count(distinct)`.

## Чекпоинт

!!! question "Проверка"
    1. **Предскажи:** сколько строк вернёт `select user_id, count(*) from packs group by user_id;`?
    2. **Объясни**, зачем `left join`, а не `join`.
    3. **Напиши** запрос: имя пользователя и число его пачек.

??? success "Проверить"
    1. По одной строке на каждого пользователя, у которого есть пачки.
    2. Чтобы пользователи **без** пачек не исчезли из результата.
    3. `select u.full_name, count(p.id) from users u left join packs p on p.user_id = u.id group by u.full_name;`
