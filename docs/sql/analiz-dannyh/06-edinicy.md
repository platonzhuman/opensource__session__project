# 6. Проверка 5: единицы измерения

Последний вопрос: **все единицы измерения верны и корректны по отношению к
указанным параметрам?** У каждого параметра должна быть своя единица.

!!! abstract "Цель урока"
    Ты научишься сверять единицу с ожидаемой для параметра.

## Шаг 1 · Ожидаемые единицы

| параметр | единица |
|----------|---------|
| высота метеопоста | м |
| температура | °C |
| давление | мм рт. ст. |
| направление ветра | б. д. у. |
| скорость ветра | м/с |
| дальность сноса пуль | м |

!!! question "Сделай"
    Где хранится единица параметра?

??? success "Проверить"
    В `parameter_types.unit_id` → таблица `units` (`short_name`).

## Шаг 2 · Выведи параметр и его единицу

```sqlplay
-- @seed artillery_my
select pt.id, pt.name, un.short_name
from parameter_types pt
join units un on un.id = pt.unit_id
order by pt.id;
```

!!! question "Сделай"
    У какого параметра единица выглядит подозрительно?

??? success "Проверить"
    `id = 7`, «температура воздуха», единица `м/с`. Для температуры ожидается `°C`.

## Шаг 3 · Сверь с ожидаемым

`like 'температура%'` — имя начинается с «температура». Если единица не `°C` —
это ошибка.

```sqlplay
-- @seed artillery_my
select pt.id, pt.name, un.short_name
from parameter_types pt
join units un on un.id = pt.unit_id
where (pt.name like 'высота%' and un.short_name <> 'м')
   or (pt.name like 'температура%' and un.short_name <> '°C')
   or (pt.name like 'давление%' and un.short_name <> 'мм рт. ст.')
   or (pt.name like 'направление%' and un.short_name <> 'б. д. у.')
   or (pt.name like 'скорость%' and un.short_name <> 'м/с')
   or (pt.name like 'дальность%' and un.short_name <> 'м');
```

!!! question "Сделай"
    Что нашёл запрос?

??? success "Проверить"
    Параметр `7` («температура воздуха») с единицей `м/с`. Вопрос «единицы верны?» → **нет**.

!!! tip "Правило"
    «Правильная ли единица?» = сравнить `units.short_name` с ожидаемым для
    параметра. Ошибка — когда не совпадает.

## Чекпоинт

!!! question "Проверка"
    1. **Предскажи:** что вернёт запрос, если все единицы верны?
    2. **Объясни**, почему проверка идёт по `name like`, а не по `id`.
    3. **Напиши** условие: у давления единица не `мм рт. ст.`.

??? success "Проверить"
    1. Ничего (ноль строк).
    2. Имена читаемее и не зависят от того, какие `id` выдал ИИ.
    3. `pt.name like 'давление%' and un.short_name <> 'мм рт. ст.'`
