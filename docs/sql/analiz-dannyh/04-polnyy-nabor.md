# 4. Проверка 3: полный набор параметров

Третий вопрос: **каждая пачка содержит полное количество параметров (5 шт)?**
Полный набор — 5 измерений в пачке.

!!! abstract "Цель урока"
    Ты научишься фильтровать **группы** через `having`.

## Шаг 1 · Посчитай параметры в каждой пачке

```sqlplay
-- @seed artillery_my
select p.id as pack_id, count(par.id) as cnt
from packs p
left join parametrs par on par.pack_id = p.id
group by p.id
order by p.id;
```

!!! question "Сделай"
    У каких пачек `cnt` не равно `5`?

??? success "Проверить"
    Пачка `4` — `4` измерения, пачка `8` — `0`. У остальных по `5`.

## Шаг 2 · Почему `where` не подходит

`where` фильтрует **строки до** группировки. А нам надо отбросить **группы** по
значению `count`. Для этого есть `having`.

```sqlplay
-- @seed artillery_my
select p.id as pack_id, count(par.id) as cnt
from packs p
left join parametrs par on par.pack_id = p.id
group by p.id
having count(par.id) <> 5
order by p.id;
```

!!! question "Сделай"
    Чем `having` отличается от `where`?

??? success "Проверить"
    `where` — фильтр строк **до** `group by`. `having` — фильтр групп **после**.
    По агрегату (`count`, `sum`) фильтруют только `having`.

## Шаг 3 · Оставь только «плохие» пачки

`having count(par.id) <> 5` оставляет ровно те пачки, где параметров не 5.
Если результат **пустой** — все пачки полные.

!!! question "Сделай"
    Запусти запрос и назови проблемные пачки.

??? success "Проверить"
    Пачки `4` и `8`. Значит, вопрос «полный ли набор?» → **нет**.

!!! tip "Правило"
    «В каждой группе ровно N строк?» = `group by ... having count(*) <> N`.

## Чекпоинт

!!! question "Проверка"
    1. **Предскажи:** что вернёт запрос, если во всех пачках по 5 параметров?
    2. **Объясни**, почему `count` пишут внутри `having`, а не в `where`.
    3. **Напиши** запрос: пачки, где измерений меньше 5.

??? success "Проверить"
    1. Ничего (ноль строк) — «плохих» пачек нет.
    2. `where` выполняется до группировки, когда `count` ещё не посчитан.
    3. `select p.id from packs p left join parametrs par on par.pack_id = p.id group by p.id having count(par.id) < 5;`
