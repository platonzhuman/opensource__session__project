## Финальное задание: домашка

Собери скрипт анализа сам. Он должен отвечать на 5 вопросов:

1. У каждого пользователя одинаковое количество измерений?
2. Есть ли пустые пачки измерения?
3. В каждой пачке полный набор параметров (5 шт)?
4. Все значения в допустимых диапазонах?
5. Все единицы измерения верны для своих параметров?

**Критерии готовности:**

- [ ] отдельный DML-скрипт с данными (от ИИ) + промт в PR;
- [ ] пять запросов, каждый отвечает на свой вопрос;
- [ ] запросы используют `join`, `group by`, `having`, `where`;
- [ ] к каждому запросу — скриншот;
- [ ] оформлен отдельный Pull Request.
