# Повторение 1

Повторяем уроки 1–4: блоки `do $$`, транзакции и первые две транзакции. Нового
материала нет.

## Разминка

### Задание 1 (урок 1)

Что вернёт этот блок?

```sql
do $$
begin
	create table t(id integer);
	insert into t values (10);
end $$;
```

??? success "Ответ"
    Ничего не выведет, но создаст таблицу `t` со строкой `id = 10`.

### Задание 2 (урок 1)

Напиши каркас анонимного блока без команд внутри.

??? success "Ответ"
    `do $$ begin end $$;`

### Задание 3 (урок 2)

Сколько транзакций в скрипте, где три раза встречается `begin; … commit;`?

??? success "Ответ"
    Три.

### Задание 4 (урок 2)

Почему внутри одного `do $$` нельзя сделать `commit`?

??? success "Ответ"
    Потому что один блок всегда выполняется в одной транзакции.

### Задание 5 (урок 3)

Сколько счётчиков у схемы из восьми таблиц?

??? success "Ответ"
    Восемь — по одному на каждую таблицу с `id`.

### Задание 6 (урок 3)

Напиши создание счётчика и привязку для таблицы `packs`.

??? success "Ответ"
    `create sequence seq_packs;` и `alter table packs alter column id set default nextval('seq_packs');`

### Задание 7 (урок 4)

Почему при вставке не указывают `id`?

??? success "Ответ"
    Его подставит счётчик через `nextval`.

### Задание 8 (урок 4)

Напиши вставку оборудования `ДМК` и `ВР`.

??? success "Ответ"
    `insert into eq_types (name) values ('ДМК'), ('ВР');`

## Проверь себя

Собери по памяти каркас скрипта из трёх транзакций (без заполнения команд):

??? success "Ответ"
    ```
    begin; do $$ begin end $$; commit;
    begin; do $$ begin end $$; commit;
    begin; do $$ begin end $$; commit;
    ```
