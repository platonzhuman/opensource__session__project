# 1. PL/pgSQL и блок `do $$ … $$`

Обычный SQL — это отдельные команды. PL/pgSQL — это **язык блоков**, где команды
можно собрать в один кусок с переменными и логикой.

!!! abstract "Цель урока"
    Ты поймёшь, что такое PL/pgSQL и как устроен анонимный блок `do $$ … $$`.

## Шаг 1 · Зачем процедурный язык

SQL умеет: выбрать, вставить, изменить. Но не умеет «сделай это 10 раз» или
«если таблица есть — пропусти». Для этого в Postgres есть **PL/pgSQL**.

!!! note "Определение"
    **PL/pgSQL** (Procedural Language/PostgreSQL) — процедурное расширение SQL:
    переменные, условия (`if`), циклы (`for`), обработка ошибок.

!!! question "Сделай"
    Чем PL/pgSQL отличается от обычного SQL?

??? success "Проверить"
    PL/pgSQL — это «код вокруг SQL»: он умеет переменные, ветвления и циклы, а
    обычный SQL — только отдельные команды.

## Шаг 2 · Блок начинается с `do $$`

Анонимный блок выполняется **один раз** и ничего не создаёт в базе. Его каркас:

```sql
do $$
begin
	-- здесь команды
end $$;
```

`$$` — это «кавычки» для тела блока. Между ними PL/pgSQL-код.

!!! question "Сделай"
    Что делают два знака `$$`?

??? success "Проверить"
    Обрамляют тело блока — как кавычки. Внутри пишется код на PL/pgSQL.

## Шаг 3 · Между `begin` и `end`

Тело блока — между `begin` и `end`. Каждая команда заканчивается `;`.

```sql
do $$
begin
	create table demo(
		id integer primary key,
		name varchar(50)
	);
	insert into demo values (1, 'первая');
end $$;
```

!!! question "Сделай"
    Что произойдёт при выполнении этого блока?

??? success "Проверить"
    Создастся таблица `demo` и вставится одна строка. Блок выполняется один раз,
    как обычная команда.

## Шаг 4 · Переменные через `declare`

Если нужны переменные — их объявляют в `declare` перед `begin`:

```sql
do $$
declare
	n integer := 5;
begin
	raise notice 'n = %', n;
end $$;
```

`raise notice` печатает сообщение (в pgAdmin — во вкладке **Messages**).

!!! question "Сделай"
    Где объявляется переменная `n`?

??? success "Проверить"
    В секции `declare`, между `$$` и `begin`. Значение задаётся через `:=`.

## Шаг 5 · Почему это «анонимный» блок

У блока нет имени, и его нельзя вызвать повторно. Он выполняется ровно тогда,
когда ты нажал «выполнить». Для повторного использования есть `create function`,
но в этой домашке нужен именно `do $$ … $$`.

!!! question "Сделай"
    Чем `do $$ … $$` отличается от `create function`?

??? success "Проверить"
    Блок безымянный и не сохраняется в базе — выполнился и всё. Функция
    сохраняется и вызывается по имени.

!!! tip "Правило"
    `do $$ begin … end $$;` — каркас. Внутри — обычные SQL-команды и PL/pgSQL-код.

## Откуда числа

`n := 5` и `raise notice` — примеры, числа придуманы для демонстрации. В домашке
в блоках будут `create table`, `insert` и `alter table`.

## Наивные вопросы

!!! question "Почему не писать просто SQL?"
    Для трёх транзакций одной структуры хватило бы и SQL. PL/pgSQL нужен, потому
    что так просит задание и потому что блок удобно собрать «шаги» в одном месте.

!!! question "`$$` можно заменить?"
    Да, на любой тег, например `$body$ … $body$`. Но `$$` — общепринятый вариант.

## Чекпоинт

!!! question "Проверка"
    1. **Предскажи:** что выведет блок `do $$ begin raise notice 'hi'; end $$;`?
    2. **Объясни**, зачем `begin … end` внутри `$$`.
    3. **Напиши** каркас блока, который создаёт таблицу `t(id integer)`.

??? success "Проверить"
    1. Сообщение `hi` во вкладке Messages.
    2. Это границы тела блока: код между ними и есть то, что выполняется.
    3. `do $$ begin create table t(id integer); end $$;`

Блоки умеем. Теперь — **транзакции**: зачем и почему их нужно три.
