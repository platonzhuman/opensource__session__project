# 8. Сдача: файлы и Pull Request

Все части готовы. Собираем и оформляем сдачу.

!!! abstract "Цель урока"
    Ты соберёшь файлы домашки и откроешь отдельный Pull Request.

## Шаг 1 · Собери файлы

В `_Infra/scripts/`:

| Файл | Что это |
| --- | --- |
| `home_work_four` | PL/pgSQL-скрипт (3 транзакции + таблица температуры) |
| `home_work_four_metadata` | скрипт метаданных (`information_schema`) |
| `home_work_four_erd.png` | скриншот ER-диаграммы (и/или файл диаграммы) |

!!! question "Сделай"
    Сколько файлов должно уйти в PR?

??? success "Проверить"
    Три: основной скрипт, скрипт метаданных и диаграмма.

## Шаг 2 · Проверь запуск

Порядок на **чистой** базе:

1. выполнить `home_work_four` (три транзакции пройдут по очереди);
2. выполнить `home_work_four_metadata` — должна выйти таблица «№ / Наименование / Тип»;
3. открыть ERD Tool и убедиться, что связи на месте.

!!! question "Сделай"
    Что должно появиться после основного скрипта?

??? success "Проверить"
    Таблицы со счётчиками, тестовые данные, связи и ограничения, плюс таблица
    `temperature_correction` с семью строками.

## Шаг 3 · Скриншоты

Задание просит приложить ER-диаграмму. Сделай скриншот холста ERD Tool со всеми
таблицами и связями.

!!! question "Сделай"
    Что обязано быть видно на скриншоте диаграммы?

??? success "Проверить"
    Все таблицы и линии связей между ними (по внешним ключам).

## Шаг 4 · Ветка и Pull Request

```bash
git checkout main
git pull
git checkout -b homework_four

git add _Infra/scripts/home_work_four
git add _Infra/scripts/home_work_four_metadata
git add _Infra/scripts/home_work_four_erd.png
git commit -m "homework four: plpgsql, metadata, erd"
git push -u origin homework_four
```

Затем на GitHub: **Compare & pull request** → base `main`, compare `homework_four`.

!!! question "Сделай"
    Что проверить перед коммитом?

??? success "Проверить"
    `git status` — чтобы в коммит шли только нужные файлы, без лишнего.

!!! tip "Правило"
    Одна домашка — одна ветка — один Pull Request. Лишние файлы не добавляй
    (учитель это уже отмечал).

## Откуда числа

Три файла — из задания: основной скрипт, скрипт метаданных, диаграмма. Порядок
запуска — из зависимостей: сначала структура, потом данные, в конце связи.

## Наивные вопросы

!!! question "Почему ER-диаграмму прикладывают картинкой?"
    Чтобы учитель увидел схему без запуска pgAdmin.

!!! question "Можно объединить скрипт и метаданные в один файл?"
    Задание просит **отдельный** скрипт метаданных — значит, два файла.

!!! question "Что если в PR попадёт лишний файл?"
    Учитель это уже отмечал — лишнее убирай. В PR ровно три файла.
