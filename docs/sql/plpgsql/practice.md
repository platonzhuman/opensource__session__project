## Разминка

### Задание 1 (урок 1)

Напиши блок, который печатает `привет` в Messages.

??? success "Ответ"
    `do $$ begin raise notice 'привет'; end $$;`

### Задание 2 (урок 1)

Сколько раз выполнится `do $$ … $$`, если нажать «выполнить» один раз?

??? success "Ответ"
    Один.

### Задание 3 (урок 2)

Дан скрипт:
```
begin; insert into t values (1); commit;
begin; insert into t values (2); rollback;
```
Сколько строк окажется в `t`?

??? success "Ответ"
    Одна (значение `2` откатилось).

### Задание 4 (урок 3)

Сколько счётчиков нужно для таблиц `users` и `packs`?

??? success "Ответ"
    Два — `seq_users` и `seq_packs`.

### Задание 5 (урок 3)

Почему первая транзакция не вставляет данные?

??? success "Ответ"
    Она отвечает только за структуру. Данные — вторая транзакция.

### Задание 6 (урок 4)

Напиши вставку сотрудника `Сидоров` с должностью `3`.

??? success "Ответ"
    `insert into users (full_name, position_id) values ('Сидоров', 3);`

### Задание 7 (урок 5)

Напиши `foreign key` для `parametrs.pack_id → packs.id`.

??? success "Ответ"
    `alter table parametrs add foreign key (pack_id) references packs (id);`

### Задание 8 (урок 6)

Какая таблица `information_schema` хранит столбцы?

??? success "Ответ"
    `information_schema.columns`.

### Задание 9 (урок 7)

Сколько строк `ΔT_V` в Таблице 1 из ТЗ?

??? success "Ответ"
    Семь.
