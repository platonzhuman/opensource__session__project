# 1. Требования домашки и ANSI-92

Разбираем, что именно просит преподаватель, и почему в задании стоит «ANSI 92».
После урока ты будешь понимать каждое слово в условии.

## Что от тебя хотят

Домашка состоит из трёх частей.

1. **SQL-скрипт** — файл `.sql`, который создаёт таблицы, наполняет их данными и
   может быть запущен повторно.
2. **`SELECT` с объединением всех таблиц** — запрос, который одним результатом
   показывает данные из всех пяти таблиц, и скриншот этого результата.
3. **Pull Request** — работа в отдельной ветке репозитория, затем слияние через PR.

!!! note "Скрипт — это программа"
    `.sql` — обычный текстовый файл. СУБД выполняет его сверху вниз, команда за
    командой. Поэтому порядок команд в файле имеет значение.

## Что такое ANSI-92

**ANSI-92** (он же SQL-92) — стандарт языка SQL, принятый в 1992 году. Он
описывает синтаксис, который должны поддерживать все реляционные СУБД.

Зачем стандарт в задании: код, написанный по ANSI-92, переносится между
PostgreSQL, MySQL, MS SQL и другими без переделки. Ты пишешь не «под MySQL», а
«на стандартном SQL».

!!! warning "Не всё одинаково стандартно"
    `DROP TABLE IF EXISTS` и `AUTO_INCREMENT` — это расширения конкретных СУБД,
    а не ANSI-92. В задании их обычно принимают, но знать разницу нужно. Разбор —
    в уроках 2 и 3.

## Три части скрипта

Скрипт делится на два вида команд:

| Группа | Команды | Что делает |
|--------|---------|------------|
| DDL | `CREATE TABLE`, `DROP TABLE` | создаёт и удаляет структуру |
| DML | `INSERT` | добавляет данные |

`SELECT` в конце скрипта — проверка: показывает, что данные легли правильно.

## Как выглядит готовый скрипт

Порядок блоков в файле:

```text
1. DROP TABLE   — очистка перед повторным запуском
2. CREATE TABLE — создание пяти таблиц
3. INSERT       — тестовые данные
4. SELECT ... JOIN — проверка объединения
```

Каждый блок разбираем в отдельных уроках.

## Частые ошибки

!!! warning "Ошибка"
    Писать `INSERT` до `CREATE TABLE`. Таблицы ещё нет — команда упадёт.
    Сначала структура, потом данные.

!!! warning "Ошибка"
    Создавать таблицу с внешним ключом раньше таблицы, на которую он ссылается.
    Порядок создания разбирается в уроке 4.
