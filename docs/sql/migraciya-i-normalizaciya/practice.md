## Финальное задание: домашка

Собери второй миграционный скрипт сам. Он должен:

1. Добавить справочники **Базовые единицы измерения**, **Единицы измерения**,
   **Типы параметров** и заполнить типовыми данными.
2. Связать таблицу параметров с новыми справочниками.
3. Удалить старые ненужные структуры (`DDL`) и старые данные (`DML`).
4. Переписать итоговый запрос в синтаксисе `ANSI-92`.

Запрос должен вернуть:

| Дата измерения | Номер пачки | ФИО сотрудника | Наименование параметра и ед. измерения | Значение |

**Критерии готовности:**

- [ ] скрипт запускается после первого без ошибок;
- [ ] есть три справочника с `primary key` и `foreign key`;
- [ ] `measurment_input_params` имеет четыре столбца: `id`, `measurment_bath_id`,
      `parameter_type_id`, `value`;
- [ ] данные перенесены, а не потеряны;
- [ ] итоговый запрос использует `inner join ... on`;
- [ ] результат совпадает с ожидаемым (5 строк для одной пачки);
- [ ] оформлен отдельный Pull Request.
