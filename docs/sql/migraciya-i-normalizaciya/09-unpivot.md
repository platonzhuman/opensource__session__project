# 9. Unpivot: пять столбцов превращаем в пять строк

Самый важный технический приём домашки. Широкая таблица параметров должна стать
набором строк «одна строка = один параметр».

!!! abstract "Цель урока"
    Ты научишься разворачивать столбцы в строки через `UNION ALL` и переносить данные
    в новую таблицу без потерь.

## Шаг 1 · Что значит «развернуть»

Было: одна строка с пятью значениями. Стало: пять строк с одним значением каждая.

```sqlplay
-- @seed base
select 'было' as вид, id, height, temperature from measurment_input_params
union all
select 'стало', id, 1, height from measurment_input_params;
```

!!! question "Сделай"
    Что делает `union all` в этом запросе?

??? success "Проверить"
    Приклеивает строки второго `select` под строки первого. Получаем один общий
    результат из двух наборов.

## Шаг 2 · UNION ALL — склейка результатов

!!! tip "Правило"
    `UNION ALL` соединяет два `select` в один список строк. Важно: у обоих `select`
    должно быть **одинаковое число столбцов** и совместимые типы.

```sqlplay
-- @seed base
select id, height as значение from measurment_input_params
union all
select id, temperature from measurment_input_params
order by id, значение;
```

!!! question "Сделай"
    Почему во втором `select` столбец назван не `height`, а `temperature`?

??? success "Проверить"
    Названия берутся из **первого** `select`. Второй просто должен дать такой же
    набор столбцов по типу. Имя `значение` задано в первом `select` через `as`.

## Шаг 3 · Приём на постороннем примере

Пусть есть контакты, где телефон дома и на работе в разных столбцах. Развернём их.

```sqlplay
-- @seed base
create table person (id integer, name text, phone_home text, phone_work text);
insert into person values (1, 'Иванов', '11-11', '22-22');

create table person_phones (
    id        integer not null,
    person_id integer not null,
    kind      text not null,
    phone     text not null,
    constraint pk_person_phones primary key (id)
);

insert into person_phones (id, person_id, kind, phone)
select (id - 1) * 2 + 1, id, 'home', phone_home from person
union all
select (id - 1) * 2 + 2, id, 'work', phone_work from person;

select * from person_phones order by id;
```

!!! question "Сделай"
    Сколько строк получилось из одной строки `person` и почему именно столько?

??? success "Проверить"
    Две — по числу разворачиваемых столбцов (`phone_home`, `phone_work`). Каждый
    `select` в `union all` даёт по строке.

## Шаг 4 · Как не запутаться в кодах

В примере `id` считался как `(id - 1) * 2 + 1` и `+ 2`. Это способ выдать уникальные
коды новым строкам без `serial`. Для пяти параметров формула будет `(id - 1) * 5 + n`.

!!! question "Сделай"
    Проверь формулу: для старой строки `id = 2` какие коды получат её пять параметров?

??? success "Проверить"
    `(2 - 1) * 5 + 1 = 6`, `+2 = 7`, `+3 = 8`, `+4 = 9`, `+5 = 10`. Диапазон `6…10`
    ни с чем не пересекается.

## Шаг 5 · Задание: разверни параметры артиллерии

!!! question "Сделай"
    В базе `base` создай таблицу `measurment_input_params_new` с полями
    `(id, measurment_bath_id, parameter_type_id, value)` и ключами, затем перенеси
    туда данные из старой таблицы через `union all` (пять `select` — по одному на
    столбец). Типы параметров: `1` — высота, `2` — температура, `3` — давление,
    `4` — направление ветра, `5` — скорость ветра.

    Подсказка: коды считай как `(id - 1) * 5 + n`, где `n` — номер параметра.

??? success "Проверить"
    Проверь число строк: `select count(*) from measurment_input_params_new;` должно
    быть в пять раз больше, чем строк в старой таблице. Полное решение — в `answers.md`.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `union all` | приклеить строки второго запроса к первому |
| `select ... from ... union all select ... from ...` | несколько наборов в один |
| `as значение` | имя столбца берётся из первого `select` |
| `(id - 1) * 5 + n` | формула уникальных кодов для развёрнутых строк |
| `insert into ... select ...` | перенос данных из одного места в другое |

## Откуда числа

`5` — число разворачиваемых параметров первого скрипта. `2` в примере с телефонами —
число столбцов `phone_home`/`phone_work`. Формула даёт уникальные коды, потому что
диапазоны для разных исходных строк не пересекаются.

## Наивные вопросы

!!! question "Чем `UNION ALL` отличается от `UNION`?"
    `UNION` убирает дубликаты и поэтому медленнее, `UNION ALL` оставляет всё как есть.
    Нам дубли убирать не нужно — каждая строка своя.

!!! question "Почему `insert into ... select`, а не руками?"
    Строк может быть много. `insert ... select` переносит их одной командой и не
    требует ручного ввода.

!!! question "Что если параметр был `NULL`?"
    В первом скрипте у столбцов есть `default 0`, поэтому пустых значений нет. В общем
    случае `NULL` перенёсся бы как `NULL`, и `not null` на `value` не дал бы вставить —
    это повод проверить данные.
