# 2. Таблица, строка, столбец, тип

Этот урок — про устройство таблицы и первые команды чтения. Дальше ты будешь
обращаться к таблицам постоянно.

!!! abstract "Цель урока"
    Ты научишься читать данные: выбирать столбцы, фильтровать строки и сортировать
    результат.

## Шаг 1 · Строка — это одна запись

Посмотри на таблицу сотрудников целиком.

```sqlplay
-- @seed artillery
select * from employees;
```

`*` значит «все столбцы». Каждая строка — один сотрудник.

!!! question "Сделай"
    Сколько строк в результате и что означает каждая строка?

??? success "Проверить"
    3 строки. Каждая строка — один сотрудник: `Воловиков`, `Петров`, `Сидоров`.

## Шаг 2 · Столбец — это свойство с типом

Столбцы — свойства записи, и у каждого свой **тип данных**.

!!! tip "Правило"
    Тип данных задаёт, что можно хранить в столбце: `integer` — целое, `numeric(8,2)`
    — дробное с двумя знаками, `character varying(150)` — строка до 150 символов,
    `timestamp` — дата и время.

```sqlplay
-- @seed artillery
select id, name, birthday, military_rank_id from employees;
```

!!! question "Сделай"
    Какого типа столбец `birthday`? А `military_rank_id`?

??? success "Проверить"
    `birthday` — `timestamp` (дата и время), `military_rank_id` — `integer` (целый
    код должности).

## Шаг 3 · WHERE — отобрать строки

`WHERE` оставляет только строки, для которых условие истинно.

```sqlplay
-- @seed artillery
select id, name
from employees
where military_rank_id = 2;
```

!!! question "Сделай"
    Выведи имя сотрудника с кодом должности `3`.

??? success "Проверить"
    `Сидоров Сидор Сидорович`. Запрос:
    `select name from employees where military_rank_id = 3;`

## Шаг 4 · ORDER BY — отсортировать

`ORDER BY` задаёт порядок строк. `asc` — по возрастанию (по умолчанию), `desc` —
по убыванию.

```sqlplay
-- @seed artillery
select id, name, birthday
from employees
order by birthday desc;
```

!!! question "Сделай"
    Кто в результате оказался первым и почему?

??? success "Проверить"
    Первым идёт `Воловиков` (`1978-06-24`) — это самый поздний год рождения среди
    трёх, а сортировка по убыванию ставит большие значения вперёд.

## Шаг 5 · Собери запрос из частей

Порядок частей `SELECT` фиксирован: сначала `select`, потом `from`, потом `where`,
потом `order by`.

!!! question "Сделай"
    Выведи `name` и `birthday` сотрудников, у которых `military_rank_id` не равен 1,
    отсортировав по имени.

??? success "Проверить"
    ```sql
    select name, birthday
    from employees
    where military_rank_id <> 1
    order by name;
    ```
    `<>` — «не равно». В результат попадут `Воловиков` и `Сидоров`.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `select *` | вывести все столбцы |
| `select id, name` | вывести только столбцы `id` и `name` |
| `from employees` | читаем из таблицы `employees` |
| `where ...` | фильтр строк |
| `=`, `<>` | равно, не равно |
| `order by ... desc` | сортировка по убыванию |

## Откуда числа

Коды должностей `1`, `2`, `3` — из таблицы `military_ranks`. Даты рождения — из
`employees.birthday`. Значения не вычисляются, а берутся из данных.

## Наивные вопросы

!!! question "Чем `*` хуже явного списка столбцов?"
    `*` тянет всё, даже лишнее, и порядок столбцов может измениться при правке
    таблицы. Явный список надёжнее и понятнее.

!!! question "Почему строка сортировки идёт последней?"
    Так устроен язык: сначала выбираем таблицу и строки, только потом упорядочиваем
    готовый результат.

!!! question "Что вернёт запрос без `where`?"
    Все строки таблицы. `where` — необязательная часть.

## Чекпоинт

!!! question "Проверка"
    1. **Предскажи:** что вернёт `select name from employees order by name asc;` первым?
    2. **Объясни**, чем строка отличается от столбца.
    3. **Напиши** запрос: имена сотрудников, родившихся после `1980-01-01`.

??? success "Проверить"
    1. `Воловиков Александр Сергеевич` — по алфавиту `В` раньше `П` и `С`.
    2. Строка — одна запись (один сотрудник), столбец — одно свойство всех записей
       (все имена).
    3. `select name from employees where birthday > '1980-01-01';` — вернёт `Петров`
       и `Сидоров`.
