# Шпаргалка: Таблицы 2 и 3

## Что откуда

| Источник | Вход | Выход | ДМК / ВР |
| --- | --- | --- | --- |
| Таблица 2 | высота Y, Δτ | среднее отклонение температуры | одинаковая |
| Таблица 3, скорость | высота Y + V0 или Дг | скорость среднего ветра | разный вход |
| Таблица 3, направление | высота Y | приращение Δα | разные значения |

## Схема (как у учителя)

| Таблица | Зачем |
| --- | --- |
| `calc_correction_heights` | 9 стандартных высот, свой `id` |
| `calc_correction_types` | дерево типов + `header_values integer[]` |
| `calc_correction` | `height_id` + `type_id` + `row_values integer[]` |
| `measurment_equipment` | уже есть: 1 = ДМК, 2 = ВР |

Одна строка картинки = один массив. Не строка на каждую ячейку.

## Массив

```sql
array[4, 6, 8, 9]     -- запись
row_values[1]         -- первый элемент (счёт с 1)
row_values[4]         -- четвёртый
```

## Обязательно

- всё в `do $$` с вложенными `begin … end;`
- свой `id` + sequence у каждой новой таблицы
- `insert` со списком колонок
- `comment on`
- ER-картинка + описание своими словами
- ссылка на PR в Forlabs

## Нельзя

- свой `eq_types` вместо `measurment_equipment`
- высота числом в каждой таблице без справочника
- `on conflict`, `serial`, `create table` вне `do $$`
- файлы курса / `prompt.md` в PR
