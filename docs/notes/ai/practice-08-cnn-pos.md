# Свёрточные сети и PoS-разметка

## О чём эта запись

Практика состоит из двух больших частей. Сначала разбирается, как устроена свёрточная сеть: зачем она нужна, если полносвязная сеть на изображении 1000×1000 требует сотен гигабайт весов, как работают ядро, шаг, padding и dilation, и как всё это выглядит в Keras на датасете MNIST. По дороге преподаватель показывает, как добавить dropout, batch normalization и другую функцию активации, чтобы выжать из модели ещё немного качества.

Вторая часть — перенос тех же идей на текст. Нужно предсказать часть речи для каждого слова в русском предложении, используя только вид слова, без соседей. Слово кодируется посимвольно, каждый символ превращается в обучаемый вектор, из этих векторов получается матрица, которую обрабатывает свёртка. В начале записи также разбирается BPE — способ разбивать текст на частые куски, который лежит в основе токенизации современных языковых моделей.

## Главные идеи

- Полносвязная сеть на изображении 1000×1000 требует около $10^{11}$ весов — это сотни гигабайт. Свёртка заменяет это маленьким ядром с общими весами.
- Свёртка — это нейрон, который скользит по изображению: умножить окно на ядро, сложить, записать в новую карту.
- Без padding размер изображения уменьшается на $k-1$; `padding='same'` сохраняет размер, `strides` прореживает, `dilation` расширяет ядро без роста числа вычислений.
- Каждый фильтр даёт свою карту признаков; глубокие слои собирают из простых признаков сложные (уши, усы, глаза → «это кошка»).
- Выходной слой полностью определяется задачей: регрессия — один нейрон и линейная активация; два класса — один нейрон и sigmoid; много классов — столько нейронов, сколько классов, и softmax.
- Переобучение лечится dropout, batch normalization, ранней остановкой и `restore_best_weights`.
- BPE решает проблему слов вне словаря: частые пары символов заменяются новыми токенами, пока текст не перестанет сжиматься.
- PoS-разметка по одному слову — это классификация матрицы «длина слова × размер эмбеддинга»; свёртка ищет в ней характерные буквосочетания.

## Полный разбор

### 1. Проблема Word2Vec: слово, которого нет в словаре

Прошлая тема закончилась на эмбеддингах. Word2Vec обучается на большом корпусе и выдаёт вектор для каждого слова из словаря. Но если в тексте встретится слово, которого модель не видела, Word2Vec честно отвечает: такого слова нет, вектор построить не могу. Для русского языка это частая ситуация: формы, опечатки, новые термины, имена.

Идея, которая это лечит, — разбить слово на более мелкие единицы. Если модель знает не слова, а куски, то незнакомое слово можно собрать из знакомых кусков.

### 2. FastText: слово как сумма n-грамм

Первый вариант — n-граммы символов. Слово разбивается на все подстроки длины $n$; для $n=2$ это биграммы. В записи приводится оценка: различных биграмм немного, порядка $60^2 \approx 3600$, потому что алфавит ограничен. Значит, словарь биграмм можно построить полностью, и почти любая биграмма в нём найдётся.

Слово «мама» разбивается на `ма`, `ам`, `ма`. Каждая биграмма получает свой вектор. Вектор слова считается суммой векторов его биграмм:

$$
v(\text{мама}) = v(\text{ма}) + v(\text{ам}) + v(\text{ма}).
$$

Такой подход называется FastText. Он позволяет получить вектор для слова, которого не было в обучающем корпусе, если его биграммы встречались. В записи отмечено, что FastText иногда используется и в современных моделях, но уже реже: он не очень экономный по памяти.

### 3. BPE: как устроен кодировщик пар байтов

Более экономный способ — BPE, Byte Pair Encoding, кодировщик пар байтов. Идея: не навязывать заранее, что является единицей языка (слово, биграмма, морфема), а найти самые частые куски прямо в тексте.

Алгоритм:

1. Разбить текст на символы (или на байты).
2. Посчитать частоты всех пар соседних символов.
3. Взять самую частую пару и заменить её новым токеном.
4. Повторить: теперь пары считаются уже с учётом новых токенов.

Пример из записи. Есть слово «мама-мала-рама». Самая частая биграмма — `ма`. Заменяем её на `x1`, получаем `x1x1-мала-рама`. Потом самой частой становится другая пара, например `мы` в другом тексте; она получает `x2`. Постепенно частые куски становятся короткими кодами, и текст сжимается.

Результат работы — таблица соответствия: `ма → x1`, `мы → x2`, `ло → x3`, `x1x1 → x4` и т. д. Если потом встретится слово «мамаша», оно кодируется через `x4` и остаток. Таблица растёт, текст сокращается. Когда таблица и текст вместе начинают занимать больше места, чем исходный текст, пора остановиться. Другие критерии остановки: все пары встречаются одинаково часто (нечего выделять) или просто надоело.

В записи подчёркнуто: в реальной реализации коды занимают не два символа, а один байт, поэтому замена двух байт на один действительно уменьшает объём. В ноутбуке для наглядности используются цифры 0–9: первые десять самых частых биграмм заменяются на цифры.

```python
def generate_ngrams(text, N=3):
    chars = list(text)
    output = []
    for i in range(len(chars) - N + 1):
        output.append(''.join(chars[i:i + N]))
    return output

d = {}
with open('files/bpe.txt.short') as f:
    s = f.read()

res = generate_ngrams(text=s, N=2)
for e in res:
    if e not in d:
        d[e] = 0
    d[e] += 1

d2 = sorted(d.items(), key=lambda x: x[1], reverse=True)
print(d2)
print('самая частая биграмма:', d2[0])

for i in range(10):
    s = s.replace(d2[i][0], str(i))
print(s)
```

Здесь `d2` — список пар «биграмма — частота», отсортированный по убыванию. Цикл заменяет десять самых частых биграмм цифрами. Это ещё не полноценный BPE (в настоящем BPE после каждой замены частоты пересчитываются), но принцип виден: частые куски получают короткие коды.

### 5. Зачем нужна свёртка: цена полносвязного слоя

Теперь про изображения. Пусть есть картинка 1000×1000, то есть $10^6$ пикселей. Если подать её в полносвязную сеть, на первом слое придётся поставить порядка $10^5$–$10^6$ нейронов. Каждый нейрон первого слоя связан со всеми входами, значит, весов будет

$$
10^6 \times 10^5 = 10^{11}
$$

или больше, если нейронов $10^6$. При 4 байтах на вес это сотни гигабайт. Ноутбук и Colab такое не выдержат.

Свёртка решает проблему двумя способами. Первый — локальные связи: нейрон смотрит не на всё изображение, а на маленькое окно $3\times3$. Второй — разделение весов: одно и то же ядро скользит по всем позициям. Вместо миллиона отдельных весов на каждую позицию используется один набор из девяти чисел.

### 6. Свёртка в одномерном случае

Преподаватель сначала объясняет одномерный случай. Есть ряд чисел. Берём окно из трёх элементов, умножаем на веса $k_1, k_2, k_3$, складываем, записываем результат в новую строку. Сдвигаем окно на один элемент, повторяем. Получается новая строка, в которой каждая точка — взвешенная комбинация соседей.

Это обычный нейрон с тремя входами и одним выходом, который применяется к каждому окну. Веса у всех окон общие — это и есть разделение весов. В записи подчёркнуто: чтобы сократить ряд в 10 раз, нужно всего 10 коэффициентов, а не миллион. Коэффициенты можно подобрать обучением.

Дальше — важный переход к прореживанию. После свёртки соседние точки сильно коррелируют: если сигнал был гладким, то и после усреднения он гладкий. Значит, половину точек можно выбросить почти без потерь. Так появляется идея stride: не считать свёртку в каждой позиции, а шагать через одну.

### 7. Свёртка в двумерном случае и три канала

В двумерном случае ядро — прямоугольник $3\times3$. Оно скользит по изображению, на каждом шаге умножает пиксели на веса, суммирует и записывает результат в новое изображение. Формула:

$$
y_{ij} = \sum_{m=0}^{k-1}\sum_{n=0}^{k-1} x_{i+m,\,j+n}\, K_{mn}.
$$

Если ядро $3\times3$, а padding нет, то по каждой оси размер уменьшается на 2: $n_{out} = n - k + 1$. Для 28×28 получается 26×26.

Цветное изображение — это три матрицы: R, G, B. Для каждого канала своё ядро, но фильтр один: три свёртки складываются в одну карту. Если хочется получить несколько карт признаков, ставят несколько фильтров, у каждого свои три ядра. В ноутбуке это выглядит как `Conv2D(filters=8, ...)`: восемь фильтров, на выходе восемь карт.

В записи это объясняется через нейроны: на каждое окно каждого канала ставится нейрон, результаты складываются, получается один выходной пиксель одной карты. Для второй карты — другой набор нейронов с другими весами.

### 8. Параметры свёртки: padding, stride, dilation

**Padding.** Свёртка уменьшает изображение. Если нужно сохранить размер, по краям добавляют рамку из нулей. В TensorFlow `padding='same'` подбирает рамку автоматически так, чтобы выход совпал с входом. В PyTorch ширину рамки часто приходится считать руками. Для ядра $3\times3$ нужен padding 1.

**Stride.** Шаг, с которым ядро двигается по изображению. `strides=2` уменьшает размер примерно вдвое. Это эквивалентно «свернуть, а потом проредить», но дешевле: не нужно вычислять свёртку в тех позициях, которые всё равно выбросим.

**Dilation.** Расширение ядра: между значимыми элементами вставляются нули. Ядро $3\times3$ с dilation 3 занимает площадь $7\times7$, но ненулевых элементов всё равно девять. Это позволяет «видеть» более широкий контекст, не увеличивая число умножений. В записи приводится оценка: свёртка $3\times3$ — это примерно 20 арифметических операций на один выходной элемент (9 умножений, 9 сложений, активация), а большое плотное ядро $100\times100$ потребовало бы 20 тысяч операций. Dilation даёт широкое ядро по цене маленького.

### 9. Иерархия признаков

Один свёрточный слой ищет простые признаки: края, пятна, линии. Следующий слой смотрит уже на карты признаков, а не на исходные пиксели, и может собрать из краёв угол, из углов — контур, из контуров — часть объекта. В записи это объясняется на кошке: одна карта реагирует на усы, другая на уши, третья на глаза. На следующем уровне сеть ищет область, где есть два глаза и шесть усов, и по совокупности решает, что перед ней кошка.

Именно поэтому свёрточные сети хорошо работают на изображениях: признаки иерархичны, и локальность с разделением весов соответствуют структуре картинки.

### 10. Свёрточная сеть на MNIST

Сначала преподаватель показывает полносвязную сеть на `load_digits` — игрушечном датасете из scikit-learn, где изображения 8×8 развёрнуты в 64 числа. Такая сеть работает, но быстро упирается в переобучение: параметров много, данных мало.

Затем берётся настоящий MNIST из TensorFlow: 60 000 изображений 28×28 в обучении и 10 000 в тесте. Это стандартный бенчмарк, поэтому у всех одинаковые train/test — иначе сравнивать результаты нельзя.

Первая свёрточная модель:

```python
from tensorflow.keras.datasets import mnist
from keras.models import Sequential
from keras.layers import Input, Reshape, Conv2D, Flatten, Dense
import tensorflow as tf

(X_train, Y_train), (X_test, Y_test) = mnist.load_data()
print(X_train.shape, Y_train.shape, X_test.shape, Y_test.shape)
# (60000, 28, 28) (60000,) (10000, 28, 28) (10000,)

model = Sequential()
model.add(Input(shape=(28, 28)))
model.add(Reshape((28, 28, 1)))
model.add(Conv2D(8, kernel_size=3, strides=2))
model.add(Conv2D(16, kernel_size=3, strides=2))
model.add(Conv2D(16, kernel_size=3, strides=1))
model.add(Conv2D(16, kernel_size=3, strides=1))
model.add(Flatten())
model.add(Dense(10, activation='softmax'))

model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])
cb = tf.keras.callbacks.EarlyStopping(monitor='val_loss', mode='min',
                                      patience=3)
model.fit(X_train, Y_train, validation_split=0.2, epochs=10000,
          callbacks=[cb])
model.evaluate(X_test, Y_test)
```

`Reshape((28, 28, 1))` добавляет канал: MNIST — чёрно-белые картинки, но свёртка ожидает трёхмерный тензор. Дальше идут четыре свёртки. Размеры: 28 → 13 → 6 → 4 → 2. На выходе 2×2×16 = 64 числа, которые `Flatten` превращает в вектор и передаёт в решающий слой на 10 классов.

Модель даёт около 98% точности, но у неё есть неприятное свойство: она «громоздкая». Преподаватель предлагает улучшить её: поставить `padding='same'`, ядро 5×5, больше фильтров, batch normalization, dropout и другую активацию.

### 11. Переобучение, dropout, batch normalization

У улучшенной модели около 863 тысяч параметров, а данных — 60 тысяч изображений. Когда параметров больше, чем данных, сеть склонна запоминать обучающий набор: на train качество почти 100%, на тесте ниже. Это переобучение.

**Dropout.** На каждом шаге обучения случайно обнуляется часть связей (например, 20–30%). Сеть не может «положиться» на конкретный нейрон и учится использовать разные пути. После обучения dropout отключается, а веса масштабируются так, чтобы средний уровень активаций сохранился. В записи объяснение чуть другое: «часть коэффициентов обнуляется, а потом заполняется средним значением по остальным». Смысл тот же: регуляризация, которая мешает запоминать.

**Batch normalization.** Проблема в том, что после слоёв значения признаков имеют разный масштаб: одни в диапазоне −100…100, другие 0…0,01. Поверхность функции потерь получается вытянутой «траншеей», и оптимизатору трудно найти минимум. Batch normalization вычитает среднее и делит на стандартное отклонение по батчу, приводя все признаки примерно к одному масштабу, а затем добавляет два обучаемых коэффициента — масштаб и сдвиг. После этого поверхность становится более круглой, и любой оптимизатор сходится лучше. В записи это иллюстрируется котлованом: если яма круглая, в неё легко скатиться с любой стороны.

```python
model = Sequential()
model.add(Input(shape=(28, 28)))
model.add(Reshape((28, 28, 1)))
model.add(Conv2D(64, kernel_size=5, padding='same', strides=2,
                 activation='silu'))
model.add(BatchNormalization())
model.add(Dropout(0.2))
model.add(Conv2D(128, kernel_size=5, padding='same', strides=2,
                 activation='silu'))
model.add(Dropout(0.2))
model.add(Conv2D(128, kernel_size=5, padding='same', strides=2,
                 activation='silu'))
model.add(Conv2D(64, kernel_size=5, padding='same', strides=2,
                 activation='silu'))
model.add(Flatten())
model.add(Dense(128, activation='relu'))
model.add(Dense(64, activation='relu'))
model.add(Dense(10, activation='softmax'))
```

**Early stopping.** Обучение останавливается, когда `val_loss` перестаёт улучшаться в течение `patience` эпох. Но после остановки веса соответствуют последней эпохе, а не лучшей. `restore_best_weights=True` возвращает веса с минимальным `val_loss`. В записи отмечен компромисс: хранение лучших весов требует памяти, и для очень больших моделей это может быть проблемой.

**Функция активации.** Вместо ReLU можно попробовать SiLU, GELU, ELU и другие. В записи сформулировано правило: функция не должна расти слишком быстро; экспоненту использовать не советуют, а всё, что растёт не быстрее степенной функции, допустимо. ReLU хороша, но на глубоких сетях может «умирать»: нейрон с отрицательным входом навсегда выдаёт ноль. SiLU и GELU сглаживают этот переход.

### 12. Задача PoS-разметки и датасет

Вторая половина практики — часть речи по слову. В первом приближении часть речи определяется самим словом: «стол» — существительное, «бежать» — глагол. Соседи нужны для сложных случаев вроде «мыла» (существительное или глагол), но начинать проще с одного слова.

Данные — Universal Dependencies, русский корпус SynTagRus в формате CoNLL-U. Файлы скачиваются командами:

```bash
mkdir -p ./datasets/
wget -O ./datasets/ru_syntagrus-ud-train.conllu \
  https://raw.githubusercontent.com/UniversalDependencies/UD_Russian-SynTagRus/master/ru_syntagrus-ud-train-a.conllu
wget -O ./datasets/ru_syntagrus-ud-dev.conllu \
  https://raw.githubusercontent.com/UniversalDependencies/UD_Russian-SynTagRus/master/ru_syntagrus-ud-dev.conllu
```

Читаются они библиотекой `pyconll`:

```python
import pyconll

full_train = pyconll.load_from_file('./datasets/ru_syntagrus-ud-train.conllu')
full_test = pyconll.load_from_file('./datasets/ru_syntagrus-ud-dev.conllu')

for sent in full_train[:2]:
    for token in sent:
```

```python
MAX_ORIG_TOKEN_LEN = max(len(str(token.form))
```

Теперь каждое слово превращается в вектор длины 33. В позиции 0 — начало слова, в позиции 1…len — коды символов, остальное — нули:

```python
def words2array(sentences, char2id, label2id, max_token_len):
    inputs, targets, words = [], [], []
    for sent in sentences:
        for token in sent:
            targets.append(label2id.get(token.upos, 0))
            charray = np.zeros(max_token_len + 2)
            if token.form:
                for char_i, char in enumerate(token.form.lower()):
                    charray[char_i + 1] = char2id.get(char, 0)
            inputs.append(charray)
            words.append(token.form)
    return (np.array(inputs).astype(int),
            np.array(targets).astype(int),
            np.array(words))

train_inputs, train_labels, words = words2array(
    full_train, char_vocab, label2id, MAX_ORIG_TOKEN_LEN)
test_inputs, test_labels, words2 = words2array(
    full_test, char_vocab, label2id, MAX_ORIG_TOKEN_LEN)
```

Получается примерно 426 тысяч векторов по 33 числа. Метки — целые числа от 0 до 17.

### 14. Модель для PoS

Модель использует обучаемый `Embedding`. Это матрица размера «число символов × размер эмбеддинга»; каждая строка — вектор символа, и эти векторы подбираются при обучении. В ноутбуке размер эмбеддинга равен 3.

```python
EMBSIZE = 3

model = tf.keras.models.Sequential()
model.add(tf.keras.layers.Input(shape=(MAX_ORIG_TOKEN_LEN + 2,)))
model.add(tf.keras.layers.Embedding(MAX_UNIQUE_CHARS, EMBSIZE,
                                    input_length=MAX_ORIG_TOKEN_LEN + 2))
model.add(tf.keras.layers.Reshape(
    (MAX_ORIG_TOKEN_LEN + 2, EMBSIZE, 1)))
model.add(tf.keras.layers.Conv2D(20, kernel_size=3, activation='relu'))
model.add(tf.keras.layers.Dropout(rate=0.3))
model.add(tf.keras.layers.Flatten())
model.add(tf.keras.layers.Dense(MAX_UNIQUE_TAGS, activation='softmax'))

model.compile(optimizer='adam', loss='categorical_crossentropy',
              metrics=[tf.keras.metrics.AUC(curve='PR', name='aucpr')])
```

Что происходит по шагам:

1. На вход приходят 33 целых числа — коды символов.
2. `Embedding` превращает каждое число в вектор из трёх чисел. Получается матрица 33×3.
3. `Reshape` добавляет измерение канала: 33×3×1. Теперь это «изображение» с одним каналом, и к нему применима свёртка.
4. `Conv2D(20, kernel_size=3)` с ядром 3×3 уменьшает размеры: 33 → 31, 3 → 1. Получается 31×1×20. Свёртка ищет характерные сочетания соседних символов и их эмбеддингов.
5. `Dropout(0.3)` отбрасывает 30% связей, чтобы сеть не запоминала.
6. `Flatten` превращает 31×1×20 в вектор из 620 чисел.
7. `Dense(18, softmax)` выдаёт вероятности 18 классов.

В модели около 11,5 тысяч параметров, и почти все они приходятся на решающий слой: $620\times18=11\,160$. Эмбеддинг занимает всего $92\times3=276$ параметров.

На этом сборка модели заканчивается: обучение и оценка разбираются уже на следующей практике. Там метки переводятся в категориальный вид, модель обучается 4 эпохи, а качество считается по AUC-PR, а не по accuracy. Причина в том, что части речи встречаются очень неравномерно, и accuracy может быть высокой даже у модели, которая всегда предсказывает существительное. AUC-PR устойчивее к дисбалансу; подробнее это разбирается на следующем занятии.

## Код

Минимальная свёрточная сеть для MNIST:

```python
import tensorflow as tf
from keras.models import Sequential
from keras.layers import Input, Reshape, Conv2D, Flatten, Dense

(X_train, Y_train), (X_test, Y_test) = tf.keras.datasets.mnist.load_data()

model = Sequential([
    Input(shape=(28, 28)),
    Reshape((28, 28, 1)),
    Conv2D(8, kernel_size=3, strides=2),
    Conv2D(16, kernel_size=3, strides=2),
    Conv2D(16, kernel_size=3, strides=1),
    Conv2D(16, kernel_size=3, strides=1),
    Flatten(),
    Dense(10, activation='softmax'),
])
model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])
model.fit(X_train, Y_train, validation_split=0.2, epochs=20)
model.evaluate(X_test, Y_test)
```

### Что делает код

- `Input(shape=(28, 28))` — батч изображений без канала.
- `Reshape((28, 28, 1))` — добавляет канал, получается 28×28×1.
- Первая `Conv2D(8, 3, strides=2)`: 8 фильтров, ядро 3×3, шаг 2. Размер: $\lfloor(28-3)/2\rfloor+1=13$. Выход 13×13×8.
- Вторая: 16 фильтров, 13 → 6. Выход 6×6×16.
- Третья и четвёртая: шаг 1, 6 → 4 → 2. Выход 2×2×16.
- `Flatten` — 64 числа.
- `Dense(10, softmax)` — вероятности десяти цифр.
- `sparse_categorical_crossentropy` — метки целыми числами, без one-hot.

## Формулы

| Величина | Формула | Смысл |
|---|---|---|
| Свёртка 2D | $y_{ij}=\sum_{m,n} x_{i+m,j+n}K_{mn}$ | Ядро скользит по изображению |
| Размер выхода | $n_{out}=\left\lfloor\frac{n-k+2p}{s}\right\rfloor+1$ | $k$ — ядро, $p$ — padding, $s$ — stride |
| Число весов свёртки | $k_h k_w C_{in} C_{out}$ | Общие веса для всех позиций |
| Полносвязный слой | $(n_{in}+1)n_{out}$ | $+1$ — смещение на каждый нейрон |
| Softmax | $p_i=\dfrac{e^{z_i}}{\sum_j e^{z_j}}$ | Превращает логиты в распределение |
| Кросс-энтропия | $L=-\sum_i y_i\log p_i$ | Штраф за неправильный класс |
| Эмбеддинг слова | $E\in\mathbb{R}^{L\times d}$ | $L$ — длина слова, $d$ — размер вектора |
| BPE-замена | $\text{пара}\to\text{новый токен}$ | Самая частая пара получает короткий код |

## Что спросят

**1. Почему свёрточная сеть экономнее полносвязной?**
Из-за локальных связей и разделения весов. Одно ядро скользит по всем позициям, поэтому число параметров зависит от размера ядра и числа каналов, а не от числа пикселей.

**2. Как меняется размер изображения и зачем нужен padding?**
Без padding — на $k-1$ меньше по каждой оси. С `padding='same'` размер сохраняется, а края не «съедаются». Со stride $s$ изображение уменьшается примерно в $s$ раз.

**3. Что делает dilation?**
Расширяет ядро, вставляя нули между весами. Ядро покрывает большую область, но вычислений столько же, сколько у маленького.

**4. Что такое карта признаков?**
Выход одного фильтра. Каждый фильтр реагирует на свой шаблон; несколько фильтров дают несколько карт, которые становятся входом следующего слоя.

**5. Как выбрать выходной слой?**
По задаче. Регрессия — один нейрон, линейная активация, MSE/MAE. Два класса — один нейрон, sigmoid, бинарная кросс-энтропия. Больше двух классов — столько нейронов, сколько классов, softmax, категориальная кросс-энтропия.

**6. Зачем dropout и batch normalization?**
Dropout мешает сети запоминать обучающий набор, обнуляя случайные связи. Batch normalization выравнивает масштаб признаков, делая поверхность потерь удобнее для оптимизатора.

**7. Как из слова сделать вход для свёртки?**
Закодировать символы числами, превратить каждый в вектор через `Embedding`, получить матрицу «длина × размер эмбеддинга», добавить измерение канала и обработать `Conv2D`.

**8. Что такое BPE?**
Алгоритм, который ищет самые частые пары соседних символов и заменяет их новым токеном. Повторяется, пока текст сжимается. Так получаются токены для языковых моделей.
