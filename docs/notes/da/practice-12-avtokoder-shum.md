# Автоэнкодер: сжатие, шум и аномалии

## О чём эта запись

Практика про автоэнкодеры: сеть учится сжимать изображение в короткий вектор и
восстанавливать его обратно. Сначала — на Fashion-MNIST, потом — удаление шума,
затем — поиск аномалий на электрокардиограммах. Главная идея: автоэнкодер не
предсказывает метку класса, он учится **восстанавливать вход**, а полезное
представление появляется в бутылочном горлышке.

## Главные идеи

- Автоэнкодер = encoder + bottleneck + decoder.
- Loss считается между входом и восстановлением: MSE или MAE.
- Бутылочное горлышко заставляет сеть хранить только главное.
- На шумных данных автоэнкодер может работать как фильтр.
- Аномалия — то, что восстанавливается хуже обычного.
- Порог аномалии ставится по распределению ошибок на нормальных данных.
- Слишком узкое горлышко — недообучение; слишком широкое — сеть просто копирует вход.

## Полный разбор

### 1. Зачем сжимать изображение

Изображение 28×28 — это 784 числа. Если подать их в модель как есть, она может
выучить почти всё, включая шум. Автоэнкодер ставит посередине узкий слой:
например, 64 числа. Через него проходит только сжатое описание изображения.
Декодер должен по этим 64 числам восстановить 784.

Если восстановление похоже на вход, значит, в 64 числах удалось сохранить
существенные признаки: форму, контур, тип одежды. Это и есть обучение без
учителя: метки классов не нужны.

### 2. Архитектура

```python
import tensorflow as tf
from tensorflow.keras import layers, losses

latent_dim = 64

class Autoencoder(tf.keras.models.Model):
    def __init__(self, latent_dim):
        super().__init__()
        self.latent_dim = latent_dim
        self.encoder = tf.keras.Sequential([
            layers.Input((28, 28,)),
            layers.Flatten(),
            layers.Dense(latent_dim, activation='relu'),
        ])
        self.decoder = tf.keras.Sequential([
            layers.Input((latent_dim,)),
            layers.Dense(784, activation='sigmoid'),
            layers.Reshape((28, 28))
        ])

    def call(self, x):
        encoded = self.encoder(x)
        decoded = self.decoder(encoded)
        return decoded
```

Что здесь важно:

- `Flatten` превращает 28×28 в вектор длины 784.
- `Dense(latent_dim)` — бутылочное горлышко.
- `Dense(784)` — восстановление.
- `sigmoid` на выходе даёт числа от 0 до 1, как нормализованные пиксели.
- `call` связывает encoder и decoder в одну модель.

### 3. Обучение

```python
autoencoder.compile(optimizer='adam', loss=losses.MeanSquaredError())
autoencoder.fit(x_train, x_train, epochs=10, shuffle=True,
                validation_split=0.2)
```

Обрати внимание: `x_train` подаётся и как вход, и как цель. Это главное отличие
автоэнкодера от обычной классификации. `validation_split=0.2` нужен, чтобы
видеть, не переобучается ли сеть.

MSE:

$$
L = \frac{1}{N}\sum_{i=1}^{N}(x_i - \hat{x}_i)^2
$$

Чем меньше loss, тем точнее восстановление.

### 4. Что показывает бутылочное горлышко

```python
encoded_imgs = autoencoder.encoder(x_test).numpy()
decoded_imgs = autoencoder.decoder(encoded_imgs).numpy()
```

`encoded_imgs` — это сжатые представления. Их можно нарисовать, если размерность
2, или подать в кластеризацию. В этой практике размерность 64, поэтому для
картинки её приходится дополнительно уменьшать.

Визуализация обычно строится в три ряда: оригинал, сжатое представление,
восстановление. Если восстановление размытое, горлышко слишком узкое или сеть
мало обучалась.

### 5. Удаление шума

```python
noise_factor = 0.2
x_train_noisy = x_train + noise_factor * tf.random.normal(shape=x_train.shape)
x_test_noisy = x_test + noise_factor * tf.random.normal(shape=x_test.shape)
x_train_noisy = tf.clip_by_value(x_train_noisy, 0., 1.)
x_test_noisy = tf.clip_by_value(x_test_noisy, 0., 1.)
```

Шум добавляется как нормальный случайный сигнал. `clip_by_value` возвращает
пиксели в диапазон 0…1. Если обучить автоэнкодер на шумных входах, а целью
оставить чистые изображения, он научится удалять шум. В ноутбуке модель обучалась
на чистых данных, поэтому на шумных входах восстановление показывает, насколько
сеть устойчива, а не идеальный denoising.

### 6. Аномалии на ЭКГ

```python
dataframe = pd.read_csv(
    'http://storage.googleapis.com/download.tensorflow.org/data/ecg.csv',
    header=None)
raw_data = dataframe.values
labels = raw_data[:, -1]
data = raw_data[:, 0:-1]
```

Каждая строка — кардиограмма из 140 значений. Последний столбец — метка:
нормальный ритм или аномалия. Автоэнкодер обучается **только на нормальных
данных**. Идея: он хорошо восстановит то, что видел, и плохо — то, чего не видел.

```python
class AnomalyDetector(tf.keras.models.Model):
    def __init__(self):
        super().__init__()
        self.encoder = tf.keras.Sequential([
            tf.keras.layers.Input((140,)),
            tf.keras.layers.Dense(32, activation="relu"),
            tf.keras.layers.Dense(16, activation="relu"),
            tf.keras.layers.Dense(8, activation="relu")])
        self.decoder = tf.keras.Sequential([
            tf.keras.layers.Input((8,)),
            tf.keras.layers.Dense(16, activation="relu"),
            tf.keras.layers.Dense(32, activation="relu"),
            tf.keras.layers.Dense(140, activation="sigmoid")])

    def call(self, x):
        encoded = self.encoder(x)
        decoded = self.decoder(encoded)
        return decoded
```

Здесь горлышко 140 → 32 → 16 → 8, затем обратно 8 → 16 → 32 → 140.

### 7. Порог аномалии

```python
reconstructions = autoencoder.predict(normal_train_data)
train_loss = tf.keras.losses.mae(reconstructions, normal_train_data)

threshold = np.mean(train_loss) + 1.96 * np.std(train_loss)
```

MAE:

$$
L = \frac{1}{N}\sum_{i=1}^{N}|x_i - \hat{x}_i|
$$

Порог `mean + 1.96 * std` — это примерно верхняя граница 95% для нормальных
ошибок, если считать их нормально распределёнными. Всё, что выше порога,
считается аномалией. Это не единственный способ: можно брать квантиль 95%,
95-й перцентиль или подбирать порог по validation.

### 8. Как оценивать

Для аномалий accuracy почти бесполезна, если аномалий мало. Нужны:

- precision — сколько найденных аномалий действительно аномалии;
- recall — какую долю настоящих аномалий нашли;
- F1 — баланс;
- ROC-AUC — качество ранжирования по score.

В ноутбуке импортированы `accuracy_score`, `precision_score`, `recall_score` —
их и стоит использовать после выбора порога.

3. Обучает автоэнкодер восстанавливать вход.

5. Сравнивает оригинал и восстановление.

## Формулы

| Величина | Формула | Смысл |
|---|---|---|
| MSE | $\frac{1}{N}\sum(x-\hat{x})^2$ | сильнее штрафует большие ошибки |
| MAE | $\frac{1}{N}\sum|x-\hat{x}|$ | устойчивее к выбросам |
| Порог | $\mu + 1.96\sigma$ | верхняя граница 95% для нормальных ошибок |
| Доля аномалий | $\frac{\text{найдено}}{\text{всего}}$ | сколько объектов выше порога |

## Что спросят

1. Чем автоэнкодер отличается от обычного классификатора?
   — Он учится восстанавливать вход, а не предсказывать метку.

2. Зачем бутылочное горлышко?
   — Чтобы заставить сеть хранить сжатое описание, а не копировать вход.

3. Почему loss считается с входом и целью одновременно?
   — Потому что задача — реконструкция: цель равна входу.

4. Почему для аномалий обучают только на нормальных данных?
   — Чтобы модель хорошо восстановила норму и плохо — то, чего не видела.

5. Как выбрать порог аномалии?
   — По распределению ошибок на нормальных данных: квантиль, `mean + k*std`
   или подбор по validation.

6. Почему accuracy плохая метрика при дисбалансе?
   — Если аномалий 1%, модель «всё нормально» даст 99% accuracy, но не найдёт
   ни одной аномалии.

7. Что будет, если горлышко слишком широкое?
   — Сеть начнёт копировать вход и потеряет смысл сжатия.

8. Что будет, если горлышко слишком узкое?
   — Восстановление станет плохим, потеряются важные детали.

## Связи

- С PCA: оба метода ищут компактное представление, но PCA линейный, а автоэнкодер — нет.
- С кластеризацией: сжатые представления можно кластеризовать.
- С аномалиями: ошибка реконструкции — это score для поиска выбросов.
- С домашкой «Лица»: там автоэнкодер сжимает лица в 2D и показывает кластеры людей.
