# Доли, доверительные интервалы и множественные проверки

## О чём эта запись

Практика на датасете HR-аналитики: нужно понять, какие категории сотрудников
чаще уходят, а какие — реже. Мы работаем не со средними, а с **долями**:
какая доля сотрудников осталась в компании внутри каждой группы. Сначала
считаем долю, потом сравниваем её с общей долей через z-критерий для пропорции,
строим интервал Уилсона и, наконец, учитываем множественные проверки.

## Главные идеи

- Доля — это вероятность события в группе: $p = k/n$.
- Долю нельзя сравнивать «на глаз»: нужен интервал и тест.
- Для долей используется z-критерий, а не обычный t.
- Интервал Уилсона лучше простого нормального интервала на малых $n$.
- Если проверять много групп сразу, часть различий окажется случайной.
- Поправка Бонферрони и FDR уменьшают ложные открытия.
- Признаки с малым числом уникальных значений — кандидаты на категориальные.

## Полный разбор

### 1. Данные

```python
from pandas import read_csv
import numpy as np
import scipy.stats as ss
import matplotlib.pyplot as pp

data = read_csv('files/WA_Fn-UseC_-HR-Employee-Attrition.csv')
data.head()
```

В таблице есть колонка `Attrition`: `Yes` — сотрудник ушёл, `No` — остался.
Нас интересует доля оставшихся:

$$
p = \frac{\text{число No}}{\text{всего сотрудников}}
$$

### 2. Доля по полу

```python
data['Gender'].value_counts()

genders = list(set(data['Gender']))
coefs = []
for gender in genders:
    s1 = data.query('Gender=="' + gender + '"')
    coefs.append([
        gender,
        s1.query('Attrition == "No"').shape[0] / s1.shape[0]
    ])
```

Для каждой группы считаем свою долю оставшихся. Это описательная статистика.
Она ещё ничего не доказывает: разница может быть случайной.

### 3. Сравнение с общей долей

```python
p0 = data.query('Attrition == "No"').shape[0] / data.shape[0]
print('p0', p0)
```

`p0` — общая доля оставшихся по всей компании. Дальше проверяем гипотезу:

- $H_0$: доля в группе равна $p_0$;
- $H_1$: доля в группе отличается от $p_0$.

Статистика:

$$
z = \frac{p - p_0}{\sqrt{p_0(1-p_0)/n}}
$$

```python
z = (p - p0) / np.sqrt(p0 * (1 - p0) / n)
pval = 2 * (1 - ss.norm.cdf(abs(z)))
```

Если $p < \alpha$, различие статистически значимо. Направление смотрим по знаку
$z$ и по разнице $p - p_0$.

### 4. Интервал Уилсона

Обычный интервал $\hat p \pm z\sqrt{\hat p(1-\hat p)/n}$ плохо работает на
малых $n$ и при долях около 0 или 1. Уилсон устойчивее:

```python
from statsmodels.stats.proportion import proportion_confint

p = proportion_confint(
    data.query('Attrition == "No"').shape[0],
    data.shape[0],
    method='wilson')
```

Для каждой группы:

```python
s1 = data.query('Gender=="' + gender + '"')
s2 = s1.query('Attrition == "No"')
wilson_interval = proportion_confint(s2.shape[0], s1.shape[0], method='wilson')
```

Интервал показывает диапазон, в котором с заданной надёжностью лежит истинная
доля. Если интервалы группы и компании пересекаются, различие может быть
случайным.

### 5. Пересечение интервалов

```python
def intersect_intervals(i1, i2):
    if i2[0] <= i1[0] <= i2[1]: return True
    if i2[0] <= i1[1] <= i2[1]: return True
    if i1[0] <= i2[0] <= i1[1]: return True
    if i1[0] <= i2[1] <= i1[1]: return True
    return False
```

Это вспомогательная проверка: пересекаются ли два интервала. Она не заменяет
тест, но даёт быстрый взгляд.

### 6. Много групп — много проверок

Если проверить 10 категорий, при $\alpha=0.05$ примерно в 0.5 случаях
различие окажется ложным. Это проблема множественных гипотез.

Поправка Бонферрони:

$$
\alpha' = \frac{\alpha}{m}
$$

где $m$ — число проверок. Она консервативна: уменьшает ложные срабатывания,
но теряет мощность.

FDR (Benjamini–Hochberg) контролирует долю ложных открытий:

```python
from statsmodels.stats.multitest import multipletests

rej, pval_corr, _, _ = multipletests(
    coefs[:, 1].astype(float),
    alpha=0.05,
    method='fdr_bh')
```

`pval_corr` — скорректированные p-value. Смотреть надо на них, а не на исходные.

### 7. Автоматический поиск категориальных признаков

```python
fields = []
for col in data.columns:
    len1 = len(set(data[col]))
    if (len1 / data.shape[0] < 0.01) and (col != 'Attrition') and (len1 > 1):
        fields.append(col)
```

Идея: если уникальных значений мало относительно числа строк, признак похож на
категориальный. Порог 1% — эвристика, а не закон.

Дальше для каждого такого признака считается доля оставшихся по каждой
категории, z-статистика и p-value, а затем все p-value проходят через FDR.

## Код

```python
p0 = data.query('Attrition == "No"').shape[0] / data.shape[0]

for field in fields:
    for value in set(data[field]):
        s1 = data.query(field + '=="' + value + '"')
        s2 = s1.query('Attrition == "No"')
        p1 = s2.shape[0] / s1.shape[0]
        z = (p1 - p0) / np.sqrt(p0 * (1 - p0) / s1.shape[0])
        pval = 2 * (1 - ss.norm.cdf(abs(z)))
        print(field, value, p1, z, pval)
```

### Что делает код

1. Берёт общую долю оставшихся `p0`.
2. Для каждой категории считает долю `p1`.
3. Считает z-статистику.
4. Переводит z в двусторонний p-value.
5. Выводит категорию, долю, z и p.

## Формулы

| Величина | Формула | Смысл |
|---|---|---|
| Доля | $p = k/n$ | вероятность события в группе |
| Стандартная ошибка доли | $\sqrt{p_0(1-p_0)/n}$ | разброс доли при $H_0$ |
| z-статистика | $\frac{p-p_0}{\sqrt{p_0(1-p_0)/n}}$ | на сколько ошибок отклонились |
| Двусторонний p | $2(1-\Phi(|z|))$ | вероятность такого отклонения при $H_0$ |
| Бонферрони | $\alpha/m$ | порог на каждую из $m$ проверок |
| FDR | Бенджамини–Хохберг | контроль доли ложных открытий |

## Что спросят

1. Почему для долей не используют обычный t-критерий?
   — Потому что распределение доли биномиальное, а не нормальное; при больших
   $n$ работает z-приближение.

2. Что такое интервал Уилсона?
   — Улучшенный доверительный интервал для доли, устойчивый на малых $n$.

3. Чем опасны множественные проверки?
   — При большом числе тестов растёт вероятность ложного открытия.

4. Что делает поправка Бонферрони?
   — Делит уровень значимости на число проверок.

5. Чем FDR отличается от Бонферрони?
   — FDR контролирует долю ложных открытий, а не вероятность хотя бы одного.

6. Почему p-value не равен вероятности $H_0$?
   — Это вероятность данных при условии $H_0$, а не наоборот.

7. Почему нельзя сравнивать доли «на глаз»?
   — Разница может быть случайной; нужен интервал или тест.

8. Что значит «статистически значимо»?
   — При выбранном $\alpha$ данные достаточно редки при $H_0$, чтобы её отвергнуть.
