# 5. Error analysis

Средняя метрика скрывает всё интересное. Senior смотрит, **где** модель
ошибается и **почему**, и только потом решает, улучшать её или остановиться.

!!! abstract "Артефакт урока"
    Error report: ошибки по режимам рынка, типам месяцев, величине шока и
    устойчивости к seed.

## Как думает senior

Он смотрит не на среднюю ошибку, а на распределение ошибок: где модель
систематически врёт и что это значит для решения.

## Твоя очередь

## Шаг 0 · Собери прогноз на последнем окне

Понадобятся импорты и функции из предыдущих уроков. Если ноутбук запускается не
подряд, выполни их.

```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LinearRegression

tr, va = windows[-1]
y_tr = data["ret"].values[tr]
y_va = data["ret"].values[va]
dates_va = data["Date"].values[va]

frame_tr = make_lags(pd.Series(y_tr), 3).dropna()
frame_va = make_lags(pd.Series(y_va), 3).dropna()
cols = [f"lag_{k}" for k in range(1, 4)]
model = LinearRegression().fit(frame_tr[cols], frame_tr["y"])
pred = model.predict(frame_va[cols])
y_va = frame_va["y"].values
dates_va = pd.to_datetime(dates_va[-len(y_va):])
```

## Шаг 1 · Разложи ошибку по времени

```python
err = y_va - pred
df_err = pd.DataFrame({"date": dates_va, "err": err, "abs_err": np.abs(err)})
df_err["year"] = df_err["date"].dt.year
print(df_err.groupby("year")["abs_err"].mean().nlargest(10))
```

!!! question "Сделай"
    В какие годы ошибка максимальна? Что происходило на рынке?

??? success "Проверить"
    Обычно кризисы: `1929–1932`, `1987`, `2008`, `2020`. Модель не
    предсказывает шоки, потому что они не следуют из прошлых доходностей.

## Шаг 2 · Разложи по режимам

```python
df_err["vol_regime"] = pd.qcut(
    df_err["abs_err"].rolling(12, min_periods=1).mean(),
    q=3, labels=["low", "mid", "high"]
)
print(df_err.groupby("vol_regime")["abs_err"].agg(["mean", "count"]))
```

!!! question "Сделай"
    В каком режиме ошибка больше? Модель ошибается систематически или случайно?

??? success "Проверить"
    В режиме высокой волатильности ошибка больше. Это ожидаемо: масштаб
    доходности меняется, а модель этого не учитывает.

## Шаг 3 · Проверь знак

```python
hit = (np.sign(pred) == np.sign(y_va)).mean()
print(f"directional accuracy: {hit:.3f}")
```

!!! question "Сделай"
    Directional accuracy выше `0.5`? Насколько?

??? success "Проверить"
    Обычно около `0.5`. Это важный вывод: модель не угадывает направление
    лучше случайного. Значит, использовать её как торговый сигнал нельзя.

## Шаг 4 · Проверь устойчивость к seed и окну

```python
for seed in [0, 1, 2, 3, 4]:
    scores = evaluate_model(data["ret"].values, p=3)
    print(seed, scores["rmse"].mean())
```

Для детерминированных моделей seed не влияет, но проверь:

- разные размеры окна (`60`, `120`, `240`);
- разные горизонты (`1`, `6`, `12`);
- разные `p`.

!!! question "Сделай"
    Результат стабилен или меняется от окна к окну?

??? success "Проверить"
    Если вывод «модель лучше baseline» исчезает при смене окна — это шум.
    Стабильность важнее одного удачного запуска.

## Шаг 5 · Классифицируй ошибки

| Тип | Пример | Что делать |
| --- | --- | --- |
| шок | кризис, пандемия | признать ограничение |
| смена режима | рост волатильности | добавить режимный признак |
| шум | обычный месяц | ничего, это неустранимо |
| баг | утечка, неверный lag | исправить |

!!! warning "Ловушка"
    Называть любую ошибку «шумом». Шок и смена режима — разные вещи с разными
    действиями.

## Шаг 6 · Error report

```md

## Метрики
RMSE, MAE, directional accuracy на walk-forward.

## Худшие периоды
| период | abs error | причина |
| --- | --- | --- |

## Режимы
| режим | n | MAE | комментарий |
| --- | --- | --- | --- |

## Устойчивость
Окно 120 vs 240: вывод ...; горизонт 1 vs 12: вывод ...

## Что это значит для решения
Модель не годится как торговый сигнал; годится / не годится как ...
```

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| error slicing | разбиение ошибки по срезам |
| regime | режим волатильности |
| directional accuracy | угадан ли знак |
| robustness | устойчивость к параметрам |

## Критерии приёмки

- [ ] ошибка разложена по времени;
- [ ] ошибка разложена хотя бы по одному режиму;
- [ ] посчитан directional accuracy;
- [ ] проверена устойчивость к окну/горизонту;
- [ ] ошибки классифицированы;
- [ ] есть вывод для решения.
