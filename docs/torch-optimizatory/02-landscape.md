# 2. Ландшафт и диагностика

Прежде чем запускать оптимизаторы, нужно понять поверхность. Иначе результат
«метод пришёл в другую точку» будет выглядеть как баг.

!!! abstract "Артефакт урока"
    Карта стационарных точек и вывод о том, какие исходы считаются успехом.

## Как думает senior

Он сначала понимает задачу: где минимумы, где сёдла, насколько обусловлен
ландшафт. Без этого поведение оптимизатора невозможно интерпретировать.

## Твоя очередь

## Шаг 1 · Найди стационарные точки

\[
f(x,y) = \sin(x)\cos(y), \qquad
f_x = \cos(x)\cos(y), \quad f_y = -\sin(x)\sin(y)
\]

Стационарные точки — там, где обе производные нули.

```python
import numpy as np

def f(x, y):
    return np.sin(x) * np.cos(y)

def grad(x, y):
    return np.cos(x) * np.cos(y), -np.sin(x) * np.sin(y)

pts = []
for x in np.linspace(6, 14, 801):
    for y in np.linspace(6, 14, 801):
        gx, gy = grad(x, y)
        if abs(gx) < 0.02 and abs(gy) < 0.02:
            pts.append((round(x, 3), round(y, 3), round(f(x, y), 3)))

print(len(pts))
print(pts[:10])
```

!!! question "Сделай"
    Сколько стационарных точек в квадрате? Какие значения функции?

??? success "Проверить"
    Их несколько десятков; значения только `-1`, `0`, `+1`. Минимумы — `-1`,
    максимумы — `+1`, сёдла — `0`.

## Шаг 2 · Классифицируй точки

Для функции двух переменных смотри вторые производные (гессиан):

\[
H = \begin{pmatrix} f_{xx} & f_{xy} \\ f_{xy} & f_{yy} \end{pmatrix}
\]

```python
def hessian(x, y):
    return np.array([
        [-np.sin(x) * np.cos(y), -np.cos(x) * np.sin(y)],
        [-np.cos(x) * np.sin(y), -np.sin(x) * np.cos(y)],
    ])

for x, y, v in pts[:5]:
    eig = np.linalg.eigvalsh(hessian(x, y))
    print((x, y), "f=", v, "eig=", np.round(eig, 3))
```

!!! question "Сделай"
    Какие знаки собственных значений у минимума, максимума и седла?

??? success "Проверить"
    Минимум: оба положительные. Максимум: оба отрицательные. Седло: разные
    знаки.

## Шаг 3 · Нарисуй карту

```python
import matplotlib.pyplot as plt

xs = np.linspace(6, 14, 400)
ys = np.linspace(6, 14, 400)
X, Y = np.meshgrid(xs, ys)
Z = f(X, Y)

plt.figure(figsize=(8, 7))
plt.contourf(X, Y, Z, levels=30, cmap="viridis")
plt.contour(X, Y, Z, levels=[-1, 0, 1], colors="white", linewidths=0.8)
plt.plot(10, 10, "rx", markersize=12, label="старт")
plt.colorbar()
plt.legend()
plt.title("Ландшафт sin(x)cos(y)")
plt.show()
```

!!! question "Сделай"
    Старт `(10, 10)` — в бассейне какого минимума?

??? success "Проверить"
    Рядом с `(π/2 + 2π, 3π) ≈ (7.854, 9.425)`, где `f = -1`. Но между стартом и
    этой точкой есть сёдла, поэтому траектория не обязана быть прямой.

## Шаг 4 · Оцени обусловленность

Локально функция выглядит как квадратичная форма. Отношение собственных чисел
гессиана показывает, насколько разные направления различаются по кривизне.

```python
x0, y0 = 10.0, 10.0
eig = np.linalg.eigvalsh(hessian(x0, y0))
print("eig:", eig, "condition:", abs(eig).max() / max(abs(eig).min(), 1e-12))
```

!!! question "Сделай"
    Обусловленность близка к `1` или велика?

??? success "Проверить"
    В этой точке собственные числа близки по модулю, обусловленность порядка
    единиц. Значит, ландшафт локально почти изотропный — SGD не должен страдать
    от «оврагов».

## Шаг 5 · Сформулируй ожидания

```text
Ожидания до эксперимента:
- большинство методов должно достичь f = -1;
- разные методы могут прийти в разные минимумы;
- адаптивные методы могут остановиться раньше;
- расхождение при lr=0.1 маловероятно, но возможно.
```

!!! warning "Ловушка"
    Заранее решить, что «правильный» только один минимум. Их много, и все со
    значением `-1` валидны.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| стационарная точка | градиент ноль |
| гессиан | вторые производные |
| собственные значения | тип точки |
| обусловленность | разброс кривизны |
| бассейн | область, из которой метод идёт в конкретный минимум |

## Критерии приёмки

- [ ] найдены стационарные точки;
- [ ] точки классифицированы;
- [ ] построена карта;
- [ ] оценена обусловленность;
- [ ] ожидания записаны до эксперимента.
