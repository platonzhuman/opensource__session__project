# Шпаргалка

## Что считаем

| Величина | Формула |
| --- | --- |
| Поддержка | `100 · (рейтинг ≥ 50).mean()` |
| Средний рейтинг | `before.mean()`, `after.mean()` |
| Разница пары | `after − before` |

## Критерии

| Вопрос | Критерий | Код |
| --- | --- | --- |
| Средний изменился? | парный t | `ss.ttest_rel(after, before)` |
| Поддержка изменилась? | Мак-Немара | `Z = (c−b)/√(b+c − (b−c)²/n)` |

`p < 0.05` → изменилось. Направление — по знаку: средние или `c−b`.

## Таблица `2 × 2` для поддержки

|  | после `≥50` | после `<50` |
| --- | --- | --- |
| до `≥50` | `a` | `b` (потеряли) |
| до `<50` | `c` (получили) | `d` |

В критерий Мак-Немара входят только `b` и `c`.

## scipy: что когда

```python
import scipy.stats as ss
ss.ttest_rel(after, before)      # парный t
ss.norm.cdf(z)                    # для p Мак-Немара: 2*(1 - cdf(|Z|))
```

## Правила, которые спасают

- «До/после» на одних людях — **связанные** выборки, обычный `ttest_ind` не подходит.
- Процент сам по себе не доказывает изменение: нужна проверка значимости.
- `p` отвечает «есть ли изменение», знак — «в какую сторону».
- `b` и `c` — только те, кто поменял мнение.
- Поддержка в задаче — порог `≥ 50`, не `> 50`.

## Ответ этой домашки

- Средний рейтинг: `72.12 → 69.24`, `p ≈ 0.0005` — **изменился, вниз**.
- Поддержка: `96% → 98%`, `p ≈ 0.31` — **не изменилась** (сдвиг на одного человека).
