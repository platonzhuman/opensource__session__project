## Шаг 1 · Весь скрипт

!!! question "Сделай"
    Запусти целиком. Совпадают ли числа с предыдущими уроками?

```pyplay
import numpy as np
import scipy.stats as ss
before = np.array([66,72,99,78,72,66,60,72,54,54,63,84,66,84,60,69,81,72,78,78,72,84,60,69,72,78,72,72,48,75,78,75,78,66,93,69,69,57,69,87,90,63,78,57,87,48,78,60,81,93])
after  = np.array([69,77,100,81,71,60,56,67,58,52,61,76,63,80,51,60,71,77,77,83,73,82,55,59,60,68,68,65,42,66,84,73,84,57,86,73,70,56,60,88,90,69,66,53,79,51,69,64,79,83])

# 1) средний рейтинг — парный t
t, p_mean = ss.ttest_rel(after, before)

# 2) поддержка — критерий Мак-Немара
sb, sa = before >= 50, after >= 50
a = int((sb & sa).sum());  b = int((sb & ~sa).sum())
c = int((~sb & sa).sum()); d = int((~sb & ~sa).sum())
n = a + b + c + d
Z = (c - b) / np.sqrt((b + c) - (b - c)**2 / n)
p_sup = 2 * (1 - ss.norm.cdf(abs(Z)))

print("=== Средний рейтинг ===")
print(f"до {before.mean():.2f} -> после {after.mean():.2f}, p = {p_mean:.5f}")
print("Рейтинг изменился?" , "да" if p_mean < 0.05 else "нет",
      "| в какую сторону:", "вниз" if after.mean() < before.mean() else "вверх")

print("=== Поддержка ===")
print(f"до {100*sb.mean():.1f}% -> после {100*sa.mean():.1f}%, p = {p_sup:.4f}")
print("Поддержка изменилась?", "да" if p_sup < 0.05 else "нет")
```

??? success "Проверить"
    Средний рейтинг: `p ≈ 0.0005` — изменился, вниз. Поддержка: `p ≈ 0.31` — не
    изменилась.

## Шаг 2 · Формулируй ответ

Так делают честный вывод:

!!! note "Правило формулировки"
    1) **Средний рейтинг.** Изменился: упал с `72.12` до `69.24`. Парный
    `t`-критерий дал `p ≈ 0.0005 < 0.05`, изменение значимо. Направление — **вниз**.
    2) **Уровень поддержки.** Изменился всего на `2` пункта (`96% → 98%`), и этот
    сдвиг дал **один** человек. Критерий Мак-Немара `p ≈ 0.31 > 0.05` — изменение
    **незначимо**, поддержка осталась прежней.

!!! question "Сделай"
    Почему по поддержке ответ «не изменилась», хотя проценты разные?

??? success "Проверить"
    Потому что рост обеспечил `1` человек из `50` — это в пределах случайной
    погрешности, а не реальное изменение.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `ss.ttest_rel` | парный t-критерий среднего |
| критерий Мак-Немара | проверка изменения доли |
| `p < 0.05` | изменение значимо |
| `diff.mean()`/сравнение средних | направление изменения |

## Откуда числа

- `72.12 → 69.24` — средние рейтинги.
- `96% → 98%` — поддержка.
- `p ≈ 0.0005` и `p ≈ 0.31` — два критерия.
- `0.05` — порог.

## Наивные вопросы

    что оно незначимо — так честнее.
