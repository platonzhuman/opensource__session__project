Файл `ivaniv.dat.txt` — `50` строк. В каждой строке **два числа**: рейтинг одного

## Шаг 2 · Как заданы две величины в задаче

- **Уровень поддержки** — процент людей, у которых рейтинг `≥ 50` (скорее
  поддерживают).
- **Средний рейтинг** — обычное среднее всех выставленных чисел.

## Шаг 3 · Прочитай файл

!!! question "Сделай"
    Запусти песочницу. Здесь загружены те же `50` пар. Чему равна поддержка **до**?

```pyplay
import numpy as np

before = np.array([66,72,99,78,72,66,60,72,54,54,63,84,66,84,60,69,81,72,78,78,72,84,60,69,72,78,72,72,48,75,78,75,78,66,93,69,69,57,69,87,90,63,78,57,87,48,78,60,81,93])
after  = np.array([69,77,100,81,71,60,56,67,58,52,61,76,63,80,51,60,71,77,77,83,73,82,55,59,60,68,68,65,42,66,84,73,84,57,86,73,70,56,60,88,90,69,66,53,79,51,69,64,79,83])

support_before = 100 * (before >= 50).mean()
support_after  = 100 * (after  >= 50).mean()
print("поддержка до:", round(support_before, 1), "%")
print("поддержка после:", round(support_after, 1), "%")
print("средний до:", round(before.mean(), 2))
print("средний после:", round(after.mean(), 2))
```

??? success "Проверить"
    Поддержка до — `96%`, после — `98%`. Средний рейтинг: `72.12` → `69.24`.

## Шаг 4 · Как читать файл в Colab

В песочнице данные уже внутри. Для домашки в Colab читай файл так:

```python
before, after = d[:, 0], d[:, 1]
```

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `np.loadtxt(...)` | читает файл с числами |
| `d[:, 0]` | все «до» |
| `d[:, 1]` | все «после» |
| `(x >= 50)` | массив `True/False`: попал ли в поддержку |
| `.mean()` | доля/среднее (`True` считается за `1`) |

## Откуда числа

- `50` — число людей (строк).
- `96%` — `48` из `50` до фильма имели рейтинг `≥ 50`.
- `98%` — `49` из `50` после.
- `72.12` и `69.24` — средние рейтинги до и после.

## Наивные вопросы

!!! question "Почему поддержка — процент, а рейтинг — среднее?"
    Так договорились в условии: поддержка — доля «за» (`≥ 50`), а сила симпатии —
    средний балл.

!!! question "`.` после числа — это что?"
    Десятичный разделитель как в Python: `72.12` — «семьдесят две целых двенадцать
    сотых».
