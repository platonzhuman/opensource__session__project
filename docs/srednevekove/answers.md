## Тест самопроверки — ответы

## Финальное задание (ДЗ) — решение

Путь: читаем пары → считаем поддержку и средний рейтинг → средний проверяем парным
`t`, поддержку — Мак-Немаром → формулируем два ответа.

```python
import numpy as np
import scipy.stats as ss

d = np.loadtxt("homework/files/input/ivaniv.dat.txt")
before, after = d[:, 0], d[:, 1]

# --- поддержка ---
sb, sa = before >= 50, after >= 50

# --- 1) средний рейтинг: парный t ---
t, p_mean = ss.ttest_rel(after, before)

# --- 2) поддержка: критерий Мак-Немара ---
a = int((sb & sa).sum());  b = int((sb & ~sa).sum())
c = int((~sb & sa).sum()); e = int((~sb & ~sa).sum())
n = a + b + c + e
Z = (c - b) / np.sqrt((b + c) - (b - c) ** 2 / n)
p_sup = 2 * (1 - ss.norm.cdf(abs(Z)))

print(f"Поддержка: {100*sb.mean():.1f}% -> {100*sa.mean():.1f}%")
print(f"Средний рейтинг: {before.mean():.2f} -> {after.mean():.2f}")
print(f"Парный t: t = {t:.3f}, p = {p_mean:.5f}")
print(f"Мак-Немар: b = {b}, c = {c}, Z = {Z:.3f}, p = {p_sup:.4f}")
```

Результат:

- поддержка `96% → 98%`;
- средний рейтинг `72.12 → 69.24`;
- парный t: `p ≈ 0.0005`;
- Мак-Немар: `b=0`, `c=1`, `p ≈ 0.31`.

### Ответы

**1) Уровень поддержки.** Формально изменился: `96% → 98%`. Но сдвиг обеспечил
**один** человек из `50`. Критерий Мак-Немара (`b=0`, `c=1`) даёт `p ≈ 0.31 > 0.05` —
изменение **статистически незначимо**. Честный вывод: **уровень поддержки не
изменился** (в пределах погрешности), хотя номинально и подрос на `2` пункта.

**2) Средний рейтинг.** Изменился: упал с `72.12` до `69.24`. Парный `t`-критерий:
`p ≈ 0.0005 < 0.05` — изменение **значимо**, направление — **вниз**.

!!! warning "Частая ошибка"
    Сказать про поддержку «выросла», потому что `98 > 96`. Проценты сравнили как
    числа, не проверив значимость. Для связанных долей нужен критерий Мак-Немара.

!!! warning "Частая ошибка"
    Проверить средний обычным `ttest_ind` (для независимых групп). Для «до/после» на
    одних людях нужен `ttest_rel`.
