# 3. Средний рейтинг: парный t-критерий

Цель урока — проверить, изменился ли средний рейтинг, и в какую сторону.

!!! abstract "После урока"
    Ты умеешь посчитать парный t-критерий и сделать вывод о среднем рейтинге.

## Шаг 1 · Идея парного критерия

Мы уже считали разницу каждой пары. Теперь вопрос: средняя разница **случайно** не
ноль или она **реально** не ноль?

!!! tip "Правило"
    Нулевая гипотеза `H₀`: средняя разница равна `0` (рейтинг не изменился). Считаем
    `p`. Если `p < 0.05` — `H₀` отвергаем, рейтинг изменился.

## Шаг 2 · Формула

$$t = \frac{\overline{\Delta}}{s_\Delta / \sqrt{n}}$$

где `Δ` — разница пары `после − before`, `\overline{Δ}` — средняя разница, `s_Δ` — её
стандартное отклонение, `n = 50`. Число степеней свободы `df = n − 1 = 49`.

!!! question "Сделай"
    Что означает большая по модулю `t`?

??? success "Проверить"
    Что средняя разница далеко от нуля относительно разброса — рейтинг, скорее всего,
    изменился.

## Шаг 3 · Посчитай

!!! question "Сделай"
    Запусти песочницу. `p` меньше `0.05`? Значит рейтинг…

```pyplay
import numpy as np
import scipy.stats as ss
before = np.array([66,72,99,78,72,66,60,72,54,54,63,84,66,84,60,69,81,72,78,78,72,84,60,69,72,78,72,72,48,75,78,75,78,66,93,69,69,57,69,87,90,63,78,57,87,48,78,60,81,93])
after  = np.array([69,77,100,81,71,60,56,67,58,52,61,76,63,80,51,60,71,77,77,83,73,82,55,59,60,68,68,65,42,66,84,73,84,57,86,73,70,56,60,88,90,69,66,53,79,51,69,64,79,83])
t, p = ss.ttest_rel(after, before)
diff = after - before
print("средний до:", round(before.mean(), 2), "после:", round(after.mean(), 2))
print("средняя разница:", round(diff.mean(), 2))
print("t =", round(t, 3), " p =", round(p, 5))
print("вывод:", "рейтинг изменился" if p < 0.05 else "рейтинг не изменился")
```

??? success "Проверить"
    `p ≈ 0.0005 < 0.05` → средний рейтинг **изменился**. Средняя разница `−2.88`
    отрицательная, значит рейтинг **снизился**: `72.12 → 69.24`.

## Шаг 4 · Направление

!!! tip "Правило"
    `p` говорит, **есть ли** изменение. Сторону показывает знак средней разницы:
    `diff.mean() < 0` — снизился, `> 0` — вырос.

!!! question "Сделай"
    Если бы `diff.mean()` был `+2.88`, что изменилось бы в выводе?

??? success "Проверить"
    Только направление: средний рейтинг **вырос** бы. Значимость та же.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `ss.ttest_rel(after, before)` | парный t-критерий |
| `after, before` | порядок важен только для знака `t` |
| `t` | насколько средняя разница далека от нуля |
| `p` | вероятность такого результата при `H₀` |
| `diff.mean()` | направление изменения |

## Откуда числа

- `72.12`, `69.24` — средние до и после.
- `−2.88` — средняя разница `69.24 − 72.12`.
- `0.0005` — p-value парного теста.
- `0.05` — порог значимости.

## Наивные вопросы

!!! question "Чем парный t отличается от обычного?"
    Обычный t сравнивает две независимые группы, парный — разницы внутри пар. Для
    «до/после» на одних людях нужен парный.

!!! question "Почему `p` маленькое, хотя разница всего 2.88 балла?"
    Разницы у всех согласованно отрицательные, разброс маленький, поэтому даже
    небольшая разница надёжна.
