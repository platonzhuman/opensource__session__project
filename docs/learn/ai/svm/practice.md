# SVM: дополнительная практика

## 1. Своя граница

Возьми два признака из своих данных. Построй линейный SVM с `C=0.1` и `C=100`. Запиши accuracy на validation и число опорных векторов. Объясни разницу.

## 2. Метрики

При дисбалансе классов сравни accuracy, precision, recall и F1. Какой вывод изменится, если положительный класс редкий?

## 3. Ошибка и цена

Найди объект, который модель классифицирует неверно. Объясни, что с ним сделает большой и маленький `C`.

**Критерий:** для каждой задачи — свой код, свои числа и объяснение; готового ответа нет.
