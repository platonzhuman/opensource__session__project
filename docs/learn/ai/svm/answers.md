# SVM: разбор

**Сначала своя попытка.** Этот файл — для сверки после задач, а не текст для копирования в сдачу.

## 1. Hinge loss

Для одного объекта:

```text
loss = max(0, 1 - y * score)
```

Если `y=1`, `score=1.2`, то `1 - 1*1.2 = -0.2`, максимум с нулём даёт `0.0`. Объект правильно классифицирован и находится за пределами зазора.

## 2. Зазор

Для линейного SVM ширина зазора:

```text
margin = 2 / ||w||
```

При `w=[3,4]` норма равна `5`, зазор `0.4`.

## 3. Решающая функция

```text
score = w·x + b
prediction = 1, если score > 0, иначе 0
```

Для `x=(1,1)`, `w=(1,1)`, `b=-0.5`: score `= 1.5`, ответ `1`.

## 4. Что меняет C

- Большой `C`: ошибки дорогие, граница подстраивается под точки, зазор узкий, риск переобучения.
- Маленький `C`: ошибки дешевле, зазор шире, часть точек может оказаться в зазоре.

Сравнивай `C` на validation, не на тесте.
