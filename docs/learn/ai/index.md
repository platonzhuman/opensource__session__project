# ИИ к зачёту Бернгарда

13 подтем: от фундамента и классических моделей до CNN, текста и GAN. Каждая — один навык и один артефакт.

## Бриф курса

- **Результат:** объяснить случайный код по теме и выбрать метод под данные.
- **Артефакт:** разбор одного своего ноутбука/кода + задача без готового ответа.
- **Заходы:** 3–5 по 20–30 минут на подтему.
- **Диагностика:** 6–8 вопросов, порог 80%.
- **Формат:** ровно 7 стадий: пример → теория → диагностика → практика → куски → половина → защита.

## Как проходить

1. Один заход — один шаг, не весь модуль.
2. Сначала попытка, потом проверка; подсказка после второй.
3. В конце — защита своими словами и запись ошибки.
