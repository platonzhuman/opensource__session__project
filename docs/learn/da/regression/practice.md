# Регрессия: дополнительная практика

## 1. Объясни

Закрой конспект и объясни своими словами: МНК минимизирует сумму квадратов остатков..

## 2. Своя задача

Возьми свои данные или ноутбук. Примени метод из модуля и запиши результат, ограничение и что проверишь на новых данных.

## 3. Перенос

Придумай, где этот метод сломается. Назови признак, по которому это заметишь.

**Критерий:** свой код, свои числа, объяснение; готового ответа нет.
