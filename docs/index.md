# Learning

Персональные курсы для закрепления материала с пар. Каждый курс — это отдельная
папка в `docs/`, собранная под прохождение за 1–4 часа: теория, практика и схемы
без воды.

## Как создать курс

В opencode выполни:

```
/create-course <тема>
```

Дальше скилл сам задаст вопросы (источник материала, уровень, бюджет времени,
сколько практики) и сгенерирует курс в `docs/<slug>/`.

## Как открыть сайт

```bash
./serve.sh
```

Затем открой `http://127.0.0.1:8000`.
