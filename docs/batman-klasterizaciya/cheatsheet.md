# Шпаргалка

## Формулы

| Величина | Формула |
| --- | --- |
| Расстояние между зданиями | `√(ΔX² + ΔY² + ΔH²)` |
| Условие прыжка | `расстояние ≤ 300` |
| Число достижимых | `100 − (число шумовых)` |

## numpy: что когда

```python
import numpy as np

d = np.loadtxt("путь", skiprows=1)   # таблица чисел
d.shape            # (100, 3)
d[:, 0]            # все X
d[:, :2]           # X и Y (без высоты — так не надо)
d[2]               # координаты третьего здания
d[mask]            # строки, где mask == True
((d - target) ** 2).sum(axis=1)      # расстояния от всех до target
np.where(mask)[0]  # номера строк с True
```

## DBSCAN

```python
from sklearn.cluster import DBSCAN

labels = DBSCAN(eps=300, min_samples=2).fit_predict(d)

mask = labels == -1      # недостижимые
d[mask]                  # их координаты
```

- `eps` — длина прыжка (`300`).
- `min_samples` — сколько соседей нужно, чтобы не быть шумом (`2`).
- `-1` — метка шума.

## Правила, которые спасают

- Считаем расстояние по **всем трём** столбцам `X`, `Y`, `H`.
- `skiprows=1` — пропустить строку `X Y H`.
- Метка `-1` — это шум, а не «минус первое здание».
- Маска `labels == -1` даёт `True/False`, а не числа.
- `np.where(...)[0]` — номера строк.
- Если шум не видно на карте — рисуй его отдельными красными крестиками.
