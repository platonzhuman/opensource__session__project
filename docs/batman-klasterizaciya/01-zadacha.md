# 1. Что дано и что ищем

Цель урока — понять, что лежит в файле и как прочитать его кодом.

!!! abstract "Цель урока"
    Ты знаешь, что такое `X`, `Y`, `H`, и умеешь загрузить файл в массив `numpy`.

## Шаг 1 · Посмотри на файл

Открой `homework/files/input/buildings.dat.txt`. Первая строка — заголовок
`X Y H`, дальше `100` строк по три числа.

!!! question "Сделай"
    Сколько чисел в одной строке данных и что они, по-твоему, означают?

??? success "Проверить"
    Три числа. `X` и `Y` — положение здания на карте (вправо и вверх), `H` — высота
    здания в футах.

## Шаг 2 · Пойми, что такое одно здание

Одно здание — это **точка** из трёх чисел. Например, первое здание — `(570, 593, 926)`:

- `X = 570` — насколько здание правее начала карты;
- `Y = 593` — насколько выше;
- `H = 926` — высота крыши.

!!! question "Сделай"
    Выпиши тройку чисел для второго здания из файла.

??? success "Проверить"
    `(54, 552, 834)`. `X = 54`, `Y = 552`, `H = 834`.

## Шаг 3 · Прочитай файл кодом

`np.loadtxt` читает текстовый файл с числами в массив `numpy`.

```python
import numpy as np

d = np.loadtxt("homework/files/input/buildings.dat.txt", skiprows=1)
print(d.shape)
```

!!! question "Сделай"
    Что напечатает `print(d.shape)` и почему?

??? success "Проверить"
    `(100, 3)`. Сто строк (зданий) и три столбца (`X`, `Y`, `H`).

!!! tip "Правило"
    `skiprows=1` пропускает первую строку `X Y H`. Без этого `loadtxt` споткнётся о
    буквы — он умеет читать только числа.

## Шаг 4 · Достань столбцы

Вся таблица — это `d`. Отдельный столбец берут так: `d[:, 0]` — все строки, столбец
`0` (первый). Нумерация в Python с нуля.

!!! question "Сделай"
    Как получить высоты всех зданий из `d`?

??? success "Проверить"
    `d[:, 2]` — все строки, третий столбец `H`.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `np.loadtxt(...)` | читает файл с числами в массив |
| `"homework/..."` | путь к файлу от папки запуска |
| `skiprows=1` | пропустить первую строку с заголовком |
| `d` | таблица `100 × 3` со всеми зданиями |
| `d.shape` | размер таблицы: `(строки, столбцы)` |
| `d[:, 0]` | первый столбец `X` |

## Откуда числа

- `100` — из файла: `99` строк данных плюс заголовок, всего `100` строк.
- `3` — три столбца `X`, `Y`, `H`.
- `(570, 593, 926)` — первая строка данных.

## Наивные вопросы

!!! question "Почему путь начинается с `homework/`?"
    Код запускается из папки `Data_analytic`, а файл лежит глубже. Если запускаешь
    из другой папки — поправь путь.

!!! question "Что делать, если `loadtxt` ругается на строку `X Y H`?"
    Добавить `skiprows=1`. Буквы в числах `numpy` не понимает.

!!! question "X и Y — это широта и долгота?"
    Нет. Это просто координаты на плоской карте: `X` вправо, `Y` вверх. Единицы —
    футы, как и `H`.
