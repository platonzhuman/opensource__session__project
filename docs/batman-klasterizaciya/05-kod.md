# 5. Код: ищем недостижимое здание

Цель урока — собрать код, который сам находит здания вне главного кластера.

!!! abstract "Цель урока"
    Ты пишешь скрипт: читает файл, запускает `DBSCAN`, выводит недостижимые здания.

## Шаг 1 · Полный каркас

```python
import numpy as np
from sklearn.cluster import DBSCAN

d = np.loadtxt("homework/files/input/buildings.dat.txt", skiprows=1)

labels = DBSCAN(eps=300, min_samples=2).fit_predict(d)

unreachable = d[labels == -1]
print("недостижимых зданий:", len(unreachable))
print(unreachable)
```

!!! question "Сделай"
    Что делает строка `d[labels == -1]`?

??? success "Проверить"
    Оставляет только те строки таблицы, у которых метка равна `-1`, то есть только
    недостижимые здания.

## Шаг 2 · Разбери маску

`labels == -1` — это **маска**: массив из `True` и `False`. Где метка равна `-1` —
там `True`. `d[маска]` берёт строки, помеченные `True`.

!!! question "Сделай"
    В маске `True` стоит только у 3-го и 16-го здания (счёт с нуля: `2` и `15`).
    Что вернёт `d[labels == -1]`?

??? success "Проверить"
    Две строки — координаты этих зданий, `(100 × 3)` превратится в `(2 × 3)`.

## Шаг 3 · Найди номера зданий

Иногда нужны не координаты, а **номера строк**. Их даёт `np.where`.

```python
idx = np.where(labels == -1)[0]
print("номера зданий:", idx)
print("их координаты:\n", d[idx])
```

!!! question "Сделай"
    Чем `idx` отличается от `unreachable` из шага 1?

??? success "Проверить"
    `idx` — номера строк (например, `[2 15]`). `unreachable` — сами координаты этих
    строк.

## Шаг 4 · Посмотри, что получилось

В этой задаче `DBSCAN` даёт главный кластер из `98` зданий и **два** одиноких.
Их координаты:

```
[ 185. 1336.  892.]
[ 213.  225. 1061.]
```

!!! question "Сделай"
    Почему у главного кластера не `100`, а `98` зданий?

??? success "Проверить"
    Два здания не попали ни в один кластер, они помечены `-1`. `100 − 2 = 98`.

## Шаг 5 · Проверь себя расстоянием

Убедимся, что эти два здания и правда одиноки: посчитаем расстояние до ближайшего
соседа для самого одинокого здания.

```python
target = d[2]                       # здание (185, 1336, 892)
dist = np.sqrt(((d - target) ** 2).sum(axis=1))
dist[2] = np.inf                    # уберём расстояние до самого себя
print("до ближайшего соседа:", round(dist.min(), 1))
```

!!! question "Сделай"
    Что напечатает код и что это доказывает?

??? success "Проверить"
    `374.9`. Это больше `300`, значит ни одна крыша не в пределах прыжка — здание
    действительно недостижимо.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `labels == -1` | маска `True/False` для шума |
| `d[labels == -1]` | только строки-недостижимые здания |
| `np.where(...)[0]` | номера строк, где маска истинна |
| `target = d[2]` | координаты конкретного здания |
| `((d - target) ** 2).sum(axis=1)` | расстояния от всех зданий до `target` |
| `axis=1` | суммировать по столбцам, для каждой строки отдельно |
| `dist[2] = np.inf` | исключить расстояние здания до себя |

## Откуда числа

- `98` — число зданий в главном кластере (все связанные).
- `2` — сколько зданий оказались шумом.
- `374.9` — расстояние от здания `(185, 1336, 892)` до ближайшей крыши.
- `300` — порог прыжка, с которым сравниваем.

## Наивные вопросы

!!! question "Почему `np.where(...)[0]`, а не просто `np.where(...)`?"
    `np.where` возвращает кортеж массивов (по одному на измерение). Для одной оси
    нужен первый элемент — `[0]`.

!!! question "Что такое `np.inf`?"
    «Бесконечность». Ставим её, чтобы расстояние здания до самого себя (`0`) не
    выиграло поиск минимума.

!!! question "А если бы шум нашёлся один?"
    Код не меняется: `d[labels == -1]` вернул бы одну строку. Количество обрабатывается
    автоматически.
