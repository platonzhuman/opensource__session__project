## Финальное задание (ДЗ) — решение

Путь рассуждения: читаем три столбца → кластеризуем с длиной прыжка → шум `-1` это
недостижимые здания → рисуем.

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.cluster import DBSCAN

# 1. читаем X, Y, H
d = np.loadtxt("homework/files/input/buildings.dat.txt", skiprows=1)

# 2. кластеризуем: eps = длина прыжка, min_samples = 2
labels = DBSCAN(eps=300, min_samples=2).fit_predict(d)

# 3. находим недостижимые здания
mask = labels == -1
idx = np.where(mask)[0]
print("недостижимых зданий:", mask.sum())
for i in idx:
    print(f"  здание {i}: {d[i]}")

# 4. рисуем карту
plt.figure(figsize=(8, 6))
plt.scatter(d[:, 0], d[:, 1], c="lightgray", label="достижимые")
plt.scatter(d[mask, 0], d[mask, 1], c="red", marker="x", s=120,
            label="недостижимые")

vo = d[2]                       # самое удалённое здание
plt.annotate("Во", (vo[0], vo[1]), xytext=(vo[0] + 40, vo[1] + 30),
             arrowprops=dict(arrowstyle="->"))
plt.xlabel("X")
plt.ylabel("Y")
plt.title("Где спрятался Во")
plt.legend()
plt.show()
```

Результат: главный кластер `98` зданий, недостижимы два —

```
здание 2:  [ 185. 1336.  892.]
здание 15: [ 213.  225. 1061.]
```

Во — на здании `(185, 1336, 892)`, его ближайшая крыша в `374.9` фута (больше `300`).

Почему так:

- `DBSCAN` берёт все три столбца, расстояние считается с учётом высоты.
- `mask.sum()` считает число `True` — сколько зданий недостижимы.
- `d[mask, 0]` и `d[mask, 1]` дают `X` и `Y` только для красных крестиков.

!!! warning "Частая ошибка"
    Передать в `DBSCAN` только `d[:, :2]` — без высоты. Тогда кластер один, шума нет,
    ответ пропадает.

!!! warning "Частая ошибка"
    Забыть `skiprows=1`. `loadtxt` спотыкается о строку `X Y H`.
