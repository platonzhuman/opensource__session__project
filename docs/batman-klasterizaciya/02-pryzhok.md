# 2. Прыжок — это расстояние

Цель урока — научиться считать, долетает ли Бэтмен от одного здания до другого.

!!! abstract "Цель урока"
    Ты умеешь посчитать расстояние между двумя зданиями и сравнить его с `300`.

## Шаг 1 · Что значит «перепрыгнуть»

Бэтмен стоит на крыше здания `A` и хочет попасть на крышу здания `B`. Единственный
вопрос: **хватит ли прыжка в `300` футов**.

!!! tip "Правило"
    Если расстояние между крышами **не больше** `300` — перепрыгнет. Если больше —
    нет.

!!! question "Сделай"
    Два здания `(0, 0, 100)` и `(0, 0, 500)`. Стоят в одной точке карты, но разной
    высоты. Бэтмен перепрыгнет?

??? success "Проверить"
    Разница по высоте `500 − 100 = 400` футов. Это больше `300` — не перепрыгнет.

## Шаг 2 · Расстояние по одной прямой

Если здания отличаются только высотой, расстояние — это просто разница высот.
Например, `|500 − 100| = 400`.

!!! question "Сделай"
    Здания `(0, 0, 100)` и `(0, 0, 350)`. Перепрыгнет?

??? success "Проверить"
    Разница `250 ≤ 300` — да, перепрыгнет.

## Шаг 3 · Расстояние по трём координатам (Пифагор)

Когда отличаются и `X`, и `Y`, и `H`, расстояние считают теоремой Пифагора сразу по
трём разницам:

$$\text{расстояние} = \sqrt{\Delta X^2 + \Delta Y^2 + \Delta H^2}$$

где `ΔX`, `ΔY`, `ΔH` — разницы соответствующих координат двух зданий.

!!! question "Сделай"
    `A = (0, 0, 0)`, `B = (0, 0, 400)`. Чему равно расстояние?

??? success "Проверить"
    `ΔH = 400`, остальные нули. `√(0 + 0 + 400²) = 400`. Перепрыгнуть нельзя: `400 > 300`.

## Шаг 4 · Посчитай в Python

```python
a = np.array([0, 0, 100])
b = np.array([0, 0, 350])
dist = np.sqrt(((a - b) ** 2).sum())
print(dist)
```

`a - b` вычитает массивы поэлементно, `** 2` возводит в квадрат, `.sum()` складывает,
`np.sqrt` берёт корень.

!!! question "Сделай"
    Что напечатает код?

??? success "Проверить"
    `250.0`. Это `350 − 100`, как в шаге 2.

## Шаг 5 · Что решает исход

!!! tip "Правило"
    Бэтмен может попасть с `A` на `B` **только если `dist ≤ 300`**. Иначе крыша `B`
    для него недостижима напрямую.

!!! question "Сделай"
    Придумай две точки, расстояние между которыми ровно `300`.

??? success "Проверить"
    Например, `(0, 0, 0)` и `(300, 0, 0)`. Или `(0, 0, 0)` и `(0, 0, 300)`.

## Что здесь что

| Элемент | Что означает |
| --- | --- |
| `a`, `b` | координаты двух зданий как массивы `numpy` |
| `a - b` | поэлементная разность координат |
| `** 2` | возведение в квадрат |
| `.sum()` | сумма трёх квадратов |
| `np.sqrt(...)` | квадратный корень — итоговое расстояние |
| `300` | длина прыжка Бэтмена в футах |

## Откуда числа

- `300` — из условия задачи: длина прыжка.
- `400` — `500 − 100`, разница высот в примере.
- `250` — `350 − 100`, ещё один пример.
- `3` — число измерений: `X`, `Y`, `H`.

## Наивные вопросы

!!! question "Зачем возводить в квадрат и потом извлекать корень?"
    Так формула Пифагора складывает разницы «наугад», не теряя знак. Минус на минус
    даёт плюс, и корень не из чего извлекать не будет.

!!! question "А если расстояние ровно 300?"
    Перепрыгнет. Условие «не больше» включает равенство: `dist ≤ 300`.

!!! question "Нужно ли считать расстояние в обе стороны — от A к B и от B к A?"
    Нет, оно одинаковое. Расстояние симметрично.

!!! question "Проверка"
    1. Предскажи: перепрыгнет ли Бэтмен с `(0, 0, 0)` на `(300, 0, 0)`?
    2. Объясни словами: из чего складывается расстояние между крышами?
    3. Напиши строку, которая считает расстояние между `p` и `q`.

??? success "Проверить"
    1. Да: расстояние ровно `300`, а условие `≤ 300`.
    2. Из разниц по `X`, `Y` и `H`, возведённых в квадрат и сложенных под корнем —
       теорема Пифагора в трёх измерениях.
    3. `np.sqrt(((p - q) ** 2).sum())`.
