# 6. План решения ДЗ

Здесь мы не пишем решение. Мы собираем план: какие шаги выполнить и какие решения
принять. Код пишешь ты.

## Задание

Из заданного файла в предположении нормального распределения убрать все значения,
уровень значимости которых `p < 0.001`. Найденные значения-выбросы записать в файл.

Вход: `files/input/data.csv`, столбец `value`.
Выход: файл с выбросами (и, по желанию, файл с очищенными данными).

## Переводим задание на язык гипотез

Для каждого значения `x`:

- `H₀`: значение принадлежит распределению `N(μ, σ)`.
- `H₁`: значение — выброс.
- Считаем `p`. Если `p < 0.001` — отвергаем `H₀`, помечаем выбросом.

Это ровно тот механизм из урока 5, применённый к каждому значению сразу.

## Алгоритм

```mermaid
flowchart TD
    A[Прочитать файл в DataFrame] --> B[Посчитать mu и sigma]
    B --> C[Для каждого x: z = (x - mu) / sigma]
    C --> D[p = 2 * sf(|z|)]
    D --> E{p < 0.001?}
    E -->|да| F[Добавить в выбросы]
    E -->|нет| G[Оставить в чистых]
    F --> H[Записать выбросы в файл]
    G --> I[Записать чистые данные в файл]
```

## Решения, которые принимаешь ты

1. **Как считать `σ`.** `pandas` по умолчанию делит на `n − 1` (`ddof=1`), `numpy` —
   на `n` (`ddof=0`). Реши, какой вариант тебе нужен, и укажи явно.
2. **Двусторонняя или односторонняя проверка.** Выбросы бывают и слева, и справа,
   поэтому двусторонняя. Что это значит для формулы `p`?
3. **Куда писать результат.** Пути к входу и выходу — относительные от папки, где
   запускаешь код, или абсолютные. Проверь, что файл действительно находится.
4. **Что писать в файл.** Задание требует выбросы. Файл с очищенными данными —
   приятный бонус, но не обязателен.

!!! warning "Ошибка"
    Считать `μ` и `σ` заново после удаления выбросов. Порог поедет, результат не
    воспроизведётся. Сначала статистики по полным данным, потом фильтр.

!!! warning "Ошибка"
    Забыть про `2 *` и модуль в `p`. Тогда проверка станет односторонней, порог
    сдвинется с `3.29` на `3.09`, и часть выбросов потеряется.

## Проверь себя

!!! question "Почему μ и σ считаем один раз, до фильтрации, а не после?"
    Что изменится, если посчитать статистики заново на очищенных данных?

??? success "Ответ"
    Порог поедет: после удаления выбросов `σ` уменьшится, и границы сожмутся. Тот же
    файл при повторном запуске даст другой результат. Считаем один раз по полным
    данным — тогда решение воспроизводимо.

## Наивные вопросы

!!! question "Откуда взять путь к файлу?"
    Путь относительный от папки, где запускаешь скрипт, или абсолютный. Если
    запускаешь из `homework`, подойдёт `files/input/data.csv`. Проверь, что файл
    реально там лежит.

!!! question "Что делать, если выбросов ноль?"
    Ничего. Пустой файл с одним заголовком — нормальный результат. Не «дополняй» его
    руками.

!!! question "Нужно ли проверять, что данные действительно нормальны?"
    В этом задании — нет, нормальность дана в условии как предположение. В реальной
    работе её проверяют отдельно (гистограмма, QQ-plot).
