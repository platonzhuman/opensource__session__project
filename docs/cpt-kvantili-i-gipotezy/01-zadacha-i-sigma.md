# 1. Задача курса и что такое σ

В конце курса ты напишешь код, который находит выбросы в файле значений. Первый шаг —
понять, что значит «значение вписывается в норму». Для этого нужны две величины:
среднее `μ` и разброс `σ`.

## Задача, к которой ведёт курс

Есть файл с числами. Большинство — «обычные», но несколько явно выбиваются. Нужно
найти их и вынести отдельно, в предположении, что обычные значения распределены
нормально, а уровень значимости `p < 0.001`.

Аналогия: ты измеряешь рост группы людей. Все где-то `150–200 см`, и вдруг одно
значение `250 см`. Либо баскетболист, либо опечатка. Курс научит отличать такие
значения от обычных математически, а не на глаз.

## Нормальное распределение

Если построить график частот обычных значений, получится симметричный «колокол».
Его называют **нормальным распределением**.

!!! note "Определение"
    **Нормальное распределение** — распределение, которое задаётся двумя числами:
    центром `μ` и шириной `σ`. Обозначают `N(μ, σ)`.

- `μ` (μ, «мю») — центр
  колокола, среднее значение.
- `σ` (σ, «сигма») — насколько широко
  значения разбросаны вокруг центра.

Чем больше `σ`, тем шире и ниже колокол. Чем меньше — тем уже и выше.

$$N(\mu, \sigma): \quad \mu\ \text{— центр}, \quad \sigma\ \text{— ширина}$$

!!! question "Проверь себя"
    Что произойдёт с колоколом, если `σ = 0`?

??? success "Ответ"
    Все значения равны `μ`, разброса нет. Колокол превращается в вертикальную
    линию над точкой `μ`.

## Пример: рисуем колокол

```python
import numpy as np
import scipy.stats as ss
import matplotlib.pyplot as plt

d = ss.norm(loc=170, scale=10)      # рост: среднее 170, σ = 10
xs = np.linspace(140, 200, 500)

plt.plot(xs, d.pdf(xs))
plt.xlabel("рост, см")
plt.ylabel("плотность")
plt.title("N(170, 10)")
plt.show()
```

**Что здесь что:**

| Элемент | Что означает |
| --- | --- |
| `ss.norm(loc=170, scale=10)` | замороженное нормальное распределение `N(170, 10)` |
| `loc` | центр `μ`; здесь `170` |
| `scale` | ширина `σ`; здесь `10` |
| `d.pdf(xs)` | высота колокола в каждой точке `xs` |
| `np.linspace(140, 200, 500)` | 500 точек от `140` до `200` для рисования |
| `plt.plot(xs, d.pdf(xs))` | рисует колокол: по X — рост, по Y — плотность |

**Откуда числа:** `170` и `10` — параметры примера, я их задал. `140` и `200` — это
`μ ± 3σ = 170 ± 30`, диапазон, куда попадает почти всё.

!!! note "Определение"
    **Плотность** (`pdf`, PDF)
    — высота колокола в точке. Сама по себе не вероятность; вероятность — это площадь
    под кривой.

## Наивные вопросы

!!! question "Чем σ отличается от дисперсии?"
    Дисперсия — это `σ²`. σ удобнее, потому что измеряется в тех же единицах, что и
    данные: если рост в сантиметрах, то и σ в сантиметрах, а дисперсия — в см².

!!! question "Что значит запись `N(170, 10)`?"
    Это нормальное распределение со средним `170` и СКО `10`.
    В `scipy` то же самое записывается как `ss.norm(loc=170, scale=10)`.

!!! question "Почему площадь под колоколом равна 1?"
    Потому что это распределение вероятностей: сумма вероятностей всех исходов
    равна `1`. Площадь — та же сумма, только для непрерывной величины.

## Сделай сам

Построй колокол `N(5, 2)`. Назови центр, ширину и границы `μ ± σ`. **Сначала сам,
потом подсказки.**

!!! question "Сделай сам"
    Чему равны `μ`, `σ` и границы `μ ± σ` для `N(5, 2)`? Какой параметр `ss.norm`
    отвечает за центр, а какой — за ширину?

??? tip "Подсказка 1"
    В `ss.norm(loc, scale)` центр — это `loc`, ширина — `scale`.

??? tip "Подсказка 2"
    ```python
    d = ss.norm(loc=___, scale=___)
    print(___, ___, ___ - ___, ___ + ___)
    ```

??? success "Ответ"
    `μ = 5`, `σ = 2`, границы `μ ± σ = [3, 7]`. Центр задаёт `loc`, ширину — `scale`.

## Частые ошибки

!!! warning "Ошибка"
    Путать `σ` и `μ` при вызове `ss.norm`. Порядок — `ss.norm(loc=μ, scale=σ)`:
    сначала центр, потом ширина. Перепутаешь — колокол уедет и растянется не туда.
