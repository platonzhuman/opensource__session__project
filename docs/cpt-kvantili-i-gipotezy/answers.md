## Задание 1

Путь решения: центр — это `loc`, ширина — `scale`. Границы `μ ± σ`, долю даёт
разность `cdf`.

```python
import scipy.stats as ss
d = ss.norm(loc=12, scale=3)
print(d.cdf(15) - d.cdf(9))   # 0.6827
```

`μ ± σ = [9, 15]`, внутри `68,27%` значений.

!!! warning "Частая ошибка"
    Сложить вероятности `cdf(9) + cdf(15)` вместо разности. Нужна разность: доля
    справа от `9` и слева от `15`.

## Задание 6

```python
d = ss.norm(loc=50, scale=4)
iqr = d.ppf(0.75) - d.ppf(0.25)
print(iqr, 1.349 * 4)   # 5.3959 5.396
```

Совпадает, потому что `IQR = (z_{0.75} − z_{0.25}) · σ`, а `z_{0.75} − z_{0.25} =
1,349` для нормального распределения. IQR зависит только от `σ`, от `μ` не зависит.

## Задание 9

## Задание 11

Путь решения: читаем файл → считаем `μ` и `σ` один раз по полным данным → для каждого
значения `z = (x − μ)/σ` → двусторонний `p = 2·sf(|z|)` → маска `p < 0.001` →
пишем выбросы и чистые данные в разные файлы.

```python
import numpy as np
import pandas as pd
import scipy.stats as ss

df = pd.read_csv("files/input/data.csv")
s = df["value"]

mu, sigma = s.mean(), s.std(ddof=0)
z = (s - mu) / sigma
p = 2 * ss.norm.sf(np.abs(z))

mask = p < 0.001
outliers = df[mask]
clean = df[~mask]

outliers.to_csv("files/outpute/outl.csv", index=False)
clean.to_csv("files/outpute/clean.csv", index=False)

lo, hi = ss.norm.interval(1 - 0.001, loc=mu, scale=sigma)
print(f"μ = {mu:.3f}, σ = {sigma:.3f}")
print(f"выбросов: {mask.sum()} из {len(df)}")
print(f"границы: [{lo:.3f}, {hi:.3f}]")
print(outliers)
```

Почему так:

- `np.abs(z)` — модуль, потому что `sf` считает только правый хвост. Так один `sf`
  закрывает оба хвоста.
- `2 *` — двусторонняя проверка. Без него порог сместится на `3.09` вместо `3.29`.
- `df[~mask]` — `~` инвертирует маску, берём всё, что не выброс.
- `ddof=0` — делим на `n`, считаем `σ` по этим данным как по всей совокупности.

На файле из `input` (297 значений `N(10, 2)` плюс три искусственных выброса) находятся
ровно три точки: `25.0`, `21.5`, `−3.0`. Границы интервала — примерно `[1.93, 18.05]`.

!!! warning "Частая ошибка"
    Считать `p = ss.norm.sf(z)` без модуля и множителя `2`. Тогда левые выбросы не
    находятся, а порог сдвигается на `3.09`.
