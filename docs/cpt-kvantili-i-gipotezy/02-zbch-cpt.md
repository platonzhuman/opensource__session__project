# 2. ЗБЧ и ЦПТ

Одно измерение ничего не говорит: случайный прохожий может быть любого роста. А
среднее по сотне — устойчивая величина. Здесь два закона: почему среднее сходится и
почему оно распределено колоколом.

## ЗБЧ: среднее сходится к истине

ЗБЧ — закон больших чисел. Возьмём
независимые одинаково распределённые величины `x₁…xₙ` со средним `M₀`. Выборочное
среднее `x̄ = (x₁ + … + xₙ) / n` при росте `n` сходится к `M₀`.

Аналогия: монета. За `10` бросков орлов может выпасть `3`, может `8`. За `1000`
бросков доля орлов почти всегда около `0.5`. Больше данных — ближе к истине.

Причина в дисперсии. Дисперсия среднего в `n` раз меньше дисперсии одного значения:

$$D(\bar{x}) = \frac{\sigma_0^2}{n}$$

Здесь `σ₀` — СКО одного значения.
Корень из дисперсии даёт разброс среднего:

$$\text{SE} = \frac{\sigma_0}{\sqrt{n}}$$

`SE` (SE,
стандартная ошибка) показывает, насколько среднее «дрожит» от выборки к выборке.

**Откуда числа:** пусть `σ₀ = 0.29`. Тогда при `n = 10` разброс среднего
`0.29 / √10 ≈ 0.091`, при `n = 100` — `0.29 / √100 = 0.029`. Каждое новое значение
размывает случайность.

!!! question "Проверь себя"
    Во сколько раз сузится разброс среднего, если увеличить выборку с `10` до `40`?

??? success "Ответ"
    В `√(40/10) = √4 = 2` раза. Разброс пропорционален `1/√n`, а не `1/n`.

## ЦПТ: среднее распределено колоколом

ЦПТ — центральная предельная
теорема. Она говорит, **как** распределено среднее вокруг предела:

$$\bar{x} \sim N\!\left(M_0,\; \frac{\sigma_0}{\sqrt{n}}\right)$$

Расшифровка символов: `x̄` — выборочное среднее, `M₀` — истинное среднее, `σ₀` — СКО
одного значения, `n` — размер выборки. Читается так: среднее распределено нормально
с центром `M₀` и шириной `σ₀/√n`.

Аналогия: брось один кубик — выпадет `1…6`, все равновероятно, колокола нет. Усредни
три броска — появится холмик. Усредни тридцать — получится колокол. И неважно, что
сам кубик «не нормальный».

!!! warning "Ошибка"
    ЦПТ — про **среднее** многих значений, а не про отдельные значения. Одно
    наблюдение остаётся распределено как исходная величина, колоколом оно не
    становится.

## Пример: проверяем ЦПТ на равномерном

```python
import numpy as np
import scipy.stats as ss
import matplotlib.pyplot as plt

np.random.seed(42)
uniform = ss.uniform()
x = uniform.rvs(size=(1000, 10))   # 1000 выборок по 10 значений

plt.hist(x[:, 0], bins=30, density=True, alpha=0.6, label="одно значение")
plt.hist(x.mean(axis=-1), bins=30, density=True, alpha=0.6, label="среднее по 10")
plt.legend()
plt.show()
```

**Что здесь что:**

| Элемент | Что означает |
| --- | --- |
| `ss.uniform()` | равномерное распределение на отрезке `[0, 1]` |
| `np.random.seed(42)` | фиксирует генератор случайных чисел, чтобы результат повторялся |
| `.rvs(size=(1000, 10))` | генерирует случайные значения (`rvs` = random variates) |
| `size=(1000, 10)` | матрица 1000×10: 1000 выборок по 10 значений |
| `x[:, 0]` | первый столбец — 1000 «одиночных» значений |
| `x.mean(axis=-1)` | среднее **внутри каждой строки** — 1000 средних |
| `axis=-1` | усреднять по последней оси, то есть по 10 значениям строки |
| `bins=30` | число столбиков гистограммы |
| `density=True` | ось Y в долях (площадь `= 1`), а не в штуках |
| `alpha=0.6` | прозрачность столбиков: `0` — невидимо, `1` — плотно |
| `label="..."` | подпись для легенды |
| `plt.legend()` | показать легенду с подписями |

**Откуда числа:** `1000` и `10` — параметры эксперимента. `bins=30` — компромисс
между детализацией и шумом. `alpha=0.6` — чтобы две гистограммы просвечивали друг
сквозь друга.

!!! warning "Ошибка"
    `alpha` в `plt.hist` — это **прозрачность**, а не уровень значимости. Уровень
    значимости тоже обозначают `α`, но это другое. Контекст различает их: в
    аргументах функции — прозрачность.

## Наивные вопросы

!!! question "Почему `axis=-1`, а не `axis=0`?"
    `axis=-1` — последняя ось, то есть значения внутри строки. Нужно среднее по
    каждой выборке. `axis=0` усреднил бы по столбцам, то есть поперёк выборок.

!!! question "Что вернёт `x.mean()` без `axis`?"
    Одно число — среднее по всем 10 000 значений. Для проверки ЦПТ бесполезно: нужно
    1000 средних, а не одно.

!!! question "Почему в формуле корень `√n`, а не `n`?"
    Потому что усредняем, а не суммируем. Дисперсия среднего делится на `n`, а СКО —
    корень из дисперсии, отсюда `√n`.

!!! question "Что делают `rvs` и `seed`?"
    `rvs` генерирует случайные значения из распределения. `seed` фиксирует генератор:
    при одном и том же seed случайные числа воспроизводятся один в один, поэтому
    эксперимент повторяем.

## Сделай сам

Повтори эксперимент для `n = 25`. Во сколько раз распределение средних должно быть
уже распределения одного значения? **Сначала сам.**

!!! question "Сделай сам"
    Поменяй `size=(1000, 10)` на `size=(1000, 25)` и посчитай `x.mean(axis=-1).std()`.
    Сравни с `σ₀/√25`.

??? tip "Подсказка 1"
    СКО одного значения — это `x.std()`. Разброс средних — `x.mean(axis=-1).std()`.

??? tip "Подсказка 2"
    ```python
    x = uniform.rvs(size=(1000, ___))
    sigma0 = x.std()
    se = x.mean(axis=-1).std()
    print(se, sigma0 / np.sqrt(___))
    ```

??? success "Ответ"
    `se = σ₀/√25 = σ₀/5`, то есть в `5` раз меньше `σ₀`. Для равномерного `σ₀ ≈ 0.289`,
    значит `se ≈ 0.058`.

## Частые ошибки

!!! warning "Ошибка"
    Усреднить всю матрицу (`x.mean()`) вместо `x.mean(axis=-1)`. Получится одно
    число, и колокол средних не построится.
