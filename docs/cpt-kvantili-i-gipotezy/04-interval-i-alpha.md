# 4. Доверительный интервал и α

Среднее — одно число, но у него есть разброс. Чтобы не врать о точности, рядом со
средним ставят «вилку» — доверительный интервал. Здесь же появляется уровень
значимости `α`, который потом понадобится для порога выбросов.

## Зачем вилка

Аналогия: ты измерил средний чек по сотне покупок и получил `1000 ₽`. По другой
сотне выйдет `980 ₽`, по третьей — `1015 ₽`. Одно число врёт о точности. Честнее
сказать «где-то между `940` и `1060 ₽`».

!!! note "Определение"
    **Доверительный интервал** — диапазон вокруг оценки, в который с заданной
    надёжностью попадает истинное значение.

## Уровень значимости α

Задаём **уровень значимости** `α` — долю, которую согласны оставить за пределами
вилки. Надёжность при этом равна `1 − α`.

- `α = 0.05` → надёжность `95%`.
- `α = 0.01` → надёжность `99%`.

Если `α` не задан, берут `5%`.

!!! question "Проверь себя"
    Интервал построен с `α = 0.01`. Какова его надёжность и сколько вероятности
    уходит в каждый хвост при двустороннем интервале?

??? success "Ответ"
    Надёжность `99%`. В хвосты уходит `1%`, по `0.5%` на каждый.

## Формула

Для среднего по ЦПТ вилка строится так:

$$\bar{x} \pm z_{1-\alpha/2} \cdot \frac{\sigma_0}{\sqrt{n}}$$

Расшифровка: `x̄` — выборочное среднее, `z_{1−α/2}` — квантиль нормального
распределения уровня `1 − α/2`, `σ₀/√n` — стандартная ошибка. Для `α = 0.05`
квантиль `z = 1.96`.

**Откуда числа:** `α/2` и `1 − α/2` — потому что двусторонний интервал отрезает по
половине `α` с каждого хвоста. Для `α = 0.05` это уровни `0.025` и `0.975`, им
соответствуют `z = ∓1.96`.

```python
import scipy.stats as ss

xbar, sigma0, n = 42, 10, 100
se = sigma0 / n ** 0.5          # 1.0
d = ss.norm(loc=xbar, scale=se)

lo, hi = d.interval(0.95)
print(lo, hi)                   # 40.04 43.96
```

**Что здесь что:**

| Элемент | Что означает |
| --- | --- |
| `xbar` | выборочное среднее; здесь `42` |
| `sigma0` | СКО одного значения; здесь `10` |
| `n` | размер выборки; здесь `100` |
| `se = sigma0 / n ** 0.5` | стандартная ошибка; здесь `10 / 10 = 1` |
| `d = ss.norm(loc=xbar, scale=se)` | распределение среднего `N(42, 1)` |
| `d.interval(0.95)` | двусторонний интервал с надёжностью `95%` |

**Откуда числа:** `n ** 0.5` — это `√n`. `40.04 = 42 − 1.96 × 1`,
`43.96 = 42 + 1.96 × 1`.

!!! warning "Ошибка"
    `interval` принимает **надёжность** `1 − α`, а не `α`. `d.interval(0.05)` даст
    узенькую вилку шириной `5%`, а не `95%`.

## Наивные вопросы

!!! question "Чем `interval` отличается от двух `ppf`?"
    Ничем по сути. `interval(0.95)` внутри делает `ppf(0.025)` и `ppf(0.975)`.
    `interval` просто короче и читается лучше.

!!! question "Что значит «доверительный»?"
    Это свойство процедуры: если повторять эксперимент много раз, около `95%` таких
    вилок накроют истинное значение. Для одной конкретной вилки вероятность строго
    не определена — она либо накрыла, либо нет.

!!! question "Почему чтобы сузить вилку вдвое, выборку надо увеличить в 4 раза?"
    Ширина вилки пропорциональна `1/√n`. Чтобы уменьшить её в `2` раза, нужно
    `√n` увеличить в `2`, то есть `n` — в `4`.

## Сделай сам

Построй `99%`-й интервал для тех же данных (`x̄ = 42`, `σ₀ = 10`, `n = 100`) и
объясни, какой интервал шире — `95%` или `99%`. **Сначала сам.**

!!! question "Сделай сам"
    Найди границы `99%`-го интервала. Квантиль для `99%` — `2.576`.

??? tip "Подсказка 1"
    Либо `d.interval(0.99)`, либо `xbar ± 2.576 * se`.

??? tip "Подсказка 2"
    ```python
    lo, hi = d.interval(___)
    # или
    print(xbar - 2.576 * ___, xbar + 2.576 * ___)
    ```

??? success "Ответ"
    `[39.424, 44.576]`. `99%`-й интервал шире `95%`-го: множитель `2.576` больше
    `1.96`.

## Частые ошибки

!!! warning "Ошибка"
    Считать интервал по `σ₀`, а не по `σ₀/√n`. Вилка строится вокруг среднего, а
    разброс среднего — это `SE`, а не СКО одного значения.
