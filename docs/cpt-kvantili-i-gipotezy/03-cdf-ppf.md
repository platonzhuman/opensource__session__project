# 3. CDF/PPF и квантили

Колокол описан. Теперь две функции, которые переводят значение в вероятность и
обратно. Через них считаются границы интервалов и порог для выбросов.

## CDF: значение → вероятность

CDF
(`cdf`) отвечает на вопрос «какая доля значений меньше `x`?».

!!! note "Определение"
    **Функция распределения** `F(x)` — вероятность, что случайная величина меньше
    `x`: `F(x) = P(X < x)`.

Аналогия: таблица роста. Спрашиваешь «какой процент людей ниже `180 см`?» — это
`cdf(180)`.

```python
import scipy.stats as ss

d = ss.norm(loc=170, scale=10)
print(d.cdf(180))   # 0.8413
print(d.cdf(160))   # 0.1587
```

**Что здесь что:**

| Элемент | Что означает |
| --- | --- |
| `d.cdf(180)` | доля значений ниже `180`; здесь `0.8413` |
| `d.cdf(160)` | доля значений ниже `160`; здесь `0.1587` |
| `d.sf(x)` | доля значений **выше** `x`; точнее, чем `1 - cdf` |

**Откуда числа:** `180` — это `μ + σ = 170 + 10`. Слева от `+1σ` лежит `84,13%`
значений, справа — `15,87%`. `160` — это `μ − σ`, симметрично.

!!! tip "Хвост через `sf`"
    Долю справа от `x` считай как `d.sf(x)`
    (SF).
    Для больших `x` это точнее, чем `1 - d.cdf(x)`.

## PPF: вероятность → значение (квантиль)

PPF
(`ppf`) — обратная к `cdf`. Даёшь вероятность `q`, получаешь значение, слева от
которого лежит доля `q`.

!!! note "Определение"
    **Квантиль** уровня `q` — значение, ниже которого лежит доля `q` данных.
    Медиана — это `ppf(0.5)`, первый квартиль — `ppf(0.25)`, третий — `ppf(0.75)`.

```python
print(d.ppf(0.5))     # 170.0  — медиана
print(d.ppf(0.25))    # 163.26 — Q1
print(d.ppf(0.75))    # 176.74 — Q3
print(d.ppf(0.75) - d.ppf(0.25))   # 13.49 — IQR
```

**Откуда числа:** `ppf(0.5) = μ = 170`. `ppf(0.25)` и `ppf(0.75)` отстоят от центра
на `0.6745 σ = 6.745`. Значит `Q1 = 170 − 6.745`, `Q3 = 170 + 6.745`,
IQR `= 13.49`.
Проверка: `1.349 × σ = 1.349 × 10 = 13.49`.

!!! note "Правило IQR"
    Для любого нормального распределения `IQR = 1.349 σ`, независимо от `μ`.

!!! question "Проверь себя"
    Чему равен `d.cdf(d.ppf(0.9))`?

??? success "Ответ"
    `0.9`. `ppf` и `cdf` — обратные друг другу, поэтому применение одной после
    другой возвращает исходную вероятность.

## Наивные вопросы

!!! question "Чем `ppf` отличается от `pdf`?"
    `pdf` — высота колокола в точке (плотность). `ppf` — значение по вероятности
    (квантиль). Разные направления и разные смыслы.

!!! question "Почему в `ppf` пишут `0.025`, а не `2.5`?"
    `ppf` принимает долю от `0` до `1`, а не проценты. `2.5%` — это `0.025`.

!!! question "Откуда взялось `1.349`?"
    Это `ppf(0.75) − ppf(0.25)` для стандартного нормального распределения
    `N(0, 1)`. Число постоянное, поэтому для `N(μ, σ)` IQR равен `1.349 σ`.

!!! question "Откуда `0.6745`?"
    Это `ppf(0.75)` для `N(0, 1)`: квартили стандартного нормального распределения
    стоят на `∓0.6745`. Для `N(μ, σ)` они смещаются на `μ` и растягиваются на `σ`.

## Сделай сам

Для `N(170, 10)` найди медиану, `Q1`, `Q3` и IQR. Сверь IQR с формулой `1.349 σ`.
**Сначала сам.**

!!! question "Сделай сам"
    Посчитай `Q1`, `Q3`, IQR через `ppf` и сравни с `1.349 * 10`.

??? tip "Подсказка 1"
    Квартили — это `ppf(0.25)` и `ppf(0.75)`. IQR — их разность.

??? tip "Подсказка 2"
    ```python
    q1 = d.ppf(___)
    q3 = d.ppf(___)
    print(q3 - q1, 1.349 * ___)
    ```

??? success "Ответ"
    Медиана `170`. `Q1 = 163.26`, `Q3 = 176.74`, IQR `= 13.49`. Совпадает с
    `1.349 × 10 = 13.49`.

## Частые ошибки

!!! warning "Ошибка"
    Путать `cdf` и `ppf`. `cdf` идёт от значения к вероятности, `ppf` — от
    вероятности к значению. Если результат меньше `1` — это, скорее всего, `cdf`;
    если похож на значение из данных — `ppf`.
