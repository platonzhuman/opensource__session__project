# Шпаргалка

## Формулы

| Величина | Формула |
| --- | --- |
| Среднее выборки | `x̄ = Σxᵢ / n` |
| Дисперсия среднего | `D(x̄) = σ₀² / n` |
| Стандартная ошибка | `SE = σ₀ / √n` |
| ЦПТ | `x̄ ~ N(M₀, σ₀/√n)` |
| Доверительный интервал | `x̄ ± z_{1−α/2} · σ₀/√n` |
| `z`-оценка | `z = (x − μ) / σ` |
| `p` двусторонний | `p = 2 · sf(|z|)` |
| IQR | `Q3 − Q1 = 1,349 σ` |

## Множители `z`

| Надёжность | `α` | `z_{1−α/2}` |
| --- | --- | --- |
| 90% | 0.10 | 1.645 |
| 95% | 0.05 | 1.960 |
| 99% | 0.01 | 2.576 |
| 99.9% | 0.001 | 3.291 |

## scipy: что когда

```python
import scipy.stats as ss

d = ss.norm(loc=μ, scale=σ)

d.cdf(x)            # значение → P(X < x)
d.sf(x)             # правый хвост, точнее чем 1 - cdf
d.ppf(q)            # вероятность → квантиль
d.interval(1 - a)   # сразу двусторонний интервал
d.pdf(x)            # плотность, не квантиль
d.rvs(size=n)       # случайные значения
d.median(), d.mean(), d.std()
ss.zscore(x, ddof=0)
```

## Правила, которые спасают

- `ppf` ест вероятность `0…1`, не проценты: `0.025`, а не `2.5`.
- `interval` ест надёжность `1 − α`, а не `α`.
- Двусторонний интервал — это `α/2` и `1 − α/2`, не `α` и `1 − α`.
- `axis=-1` при усреднении матрицы выборок.
- `p` — про данные при условии `H₀`, не про вероятность `H₀`.
- `p < α` → отвергаем `H₀`.
- Выбросы ищутся двусторонне: `2 * sf(|z|)`.
- `p = 0.001` ↔ `|z| > 3.29` (двусторонний) или `3.09` (односторонний).
- `μ` и `σ` по данным с выбросами завышены — выбросы маскируются.
- `alpha` в `plt.hist` — прозрачность, а не уровень значимости.
